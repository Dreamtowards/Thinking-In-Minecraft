# docs-en · *Thinking in Minecraft* (English Edition)

English edition of the rewritten book. It adapts the reviewed chapters from `docs/v2/` (Chinese) — same structure, same claims, same footnoted sources — written as natural English prose rather than literal translation.

- The Chinese edition in `docs/v2/` is the spine: an English chapter is only written after its Chinese counterpart passes review.
- Chapter list and per-volume order mirror `docs/v2/PROGRESS.md`.
- Progress is tracked in `PROGRESS.md` in this folder.
- Components: only the registered set (`Note`, `Alternative`, `Memoir`, `Impl`, `Constraint`, `Figure`, mermaid). Site URLs keep the same slugs as the Chinese edition (`/history/servers`, etc.).
