> **本章命题**：词条只给可核对的指称。机制为什么长这样，到正编里看；这里不教搭建，不写图鉴。

## 问题

正编把口令写成论证。查词时，论证会挡在定义前面。本章按长度收：每词大约四十字到八十字，够用来指，不够用来代替某一章。

Java 与 Bedrock 若不是同一句话，词条里会拆开。拆不开的合写。

## 词条

**区块（chunk）**  
水平切片，Java 通常 16×16 格，高度随版本变。它是加载、模拟和存盘的代价单位。未生成、未加载、空气是三种法律，不要听成同一种空。[《体素世界的数据模型》](/impl/data-model)

**节（section）**  
区块在垂直方向再切的一段，常为 16 格高。调色板按节共享短表。改「一格是什么」的那天，账单按节乘柱子走。[《体素世界的数据模型》](/impl/data-model)

**刻 / 游戏刻（tick）**  
服务端推进一步世界的节拍。目标常为每秒二十拍；跟不上则 TPS 下降，熔炉和红石一起变慢。引擎认游戏刻。[《游戏循环与刻》](/impl/tick)

**TPS / MSPT**  
TPS 是每秒实际完成的拍数。MSPT 是一拍算了多少毫秒。维持 20 TPS，MSPT 不能超过约 50。数字来自服务端。[《游戏循环与刻》](/impl/tick)

**计划刻 / 随机刻**  
计划刻是可预期延迟。随机刻是每节抽签。Java 与 Bedrock 的配额和默认 `randomTickSpeed` 不是同一把尺。[《游戏循环与刻》](/impl/tick)

**红石刻**  
Java 社区用语，等于两游戏刻。Bedrock 把两游戏刻拆成产出与消费两段，并可与主循环分班。口令能说，内核仍按游戏刻记账。[《红石的实现》](/impl/redstone)

**NBT**  
带名字与类型的二进制树。文本面叫 SNBT。Java 多大端，Bedrock 世界记录多小端。没有版本字段，翻译器只能猜。[《存储与序列化》](/impl/storage)

**Anvil / LevelDB**  
Java 世界的区域信封（`.mca`）。Bedrock 世界主体在 `db/` 的 LevelDB 里。两套柜子。[《存储与序列化》](/impl/storage)

**扁平化（The Flattening）**  
Java 1.13 把多数数字 ID 收成 `命名空间:路径` 加方块状态。箱子里的护照按件重开。数据包从此能按名字说话。[《存储与序列化》](/impl/storage)

**组件化**  
Java 1.20.5 把物品上非结构化的 `tag` 收成有模式的组件。自定义数据进 `minecraft:custom_data`。按件计费。[《物品、库存与合成》](/impl/items)

**方块状态 / 方块实体**  
状态是有限键值，进调色板，活塞能推「这一格的法律」。装不下的账户（箱子内容、熔炉进度）进方块实体。空气海里不要挂任意字段。[《体素世界的数据模型》](/impl/data-model)

**数据包 / 资源包**  
数据包改内容与一部分规则，跟世界走，加不出第二种挖掘。资源包改看见和听见。官方扩展面故意停在系统之前。[《数据包、资源包与数据驱动》](/impl/datapacks)

**Mixin**  
基于 ASM 的字节码注入。正作没签稳定接口时，切开方法就变成接口。每个大版本可能全断。[《模组与插件架构》](/impl/mod-architecture)

**模拟距离 / 视距**  
模拟距离决定哪根柱子还在走拍。视距决定你看见多远。看见的城可以不怎么动——网格到了，拍不一定在。[《服务端与规模》](/impl/servers)

**准连接（quasi-connectivity）**  
Java 上活塞等会问「上方那一格若存在机构是否该亮」，即使该格是空气。MC-108 标 WAI。Bedrock 无此机制。[《红石：把物理做成编程》](/design/redstone)

**BUD**  
方块更新检测：该动却还没被通知，下一次更新才补课。与准连接常缠在一起，不是同一集合。[《红石的实现》](/impl/redstone)

**gamerule / 操作员**  
引擎立法的旋钮与钥匙。关掉落会改经济；权限档位决定谁能拧。拧完仍叫原版，玩的法律已经换了。[《规则由谁制定》](/design/who-makes-rules)

**创造 / 冒险 / 旁观**  
同一世界、同一物理上的权限，不是四个游戏。创造取消稀缺，不取消格子和身体。冒险收回挖和放。[《创造模式不是关卡编辑器》](/design/creative-mode)

**种子**  
生成器的输入之一。Java 与 Bedrock 不是同一把钥匙。同一数字在两边可以长出不同的山。[《世界生成管线》](/impl/worldgen-pipeline)

**pack_format**  
数据包 / 资源包的格式号，随游戏版本涨。旧地图要改文件才能继续用。它是内容层的版本字段。[《数据包、资源包与数据驱动》](/impl/datapacks)

**附加包 / Marketplace**  
Bedrock 的温和扩展与货架。审核、定价、跟账号走。不是 Forge 那种共同立法。[《两条产品线：Java 与 Bedrock》](/history/java-bedrock)

**ViaVersion**  
把不同协议号翻译成能握手的语言。能翻译，证明包形状是语言；必须翻译，证明没有官方稳定方言。[《网络协议》](/impl/protocol)

## 这一章留下什么

- **爱好者**：口令够用时不必下沉。下沉时，先看这个词指的是格子、拍、护照，还是作者席。
- **开发者**：能抄走的是指称。抄不走的是测试集。词条不作设计文档。设计在正编的命题里。
