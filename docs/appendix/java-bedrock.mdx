## 问题

收银台捆过。世界没有捆。查「两边差在哪」时，最容易把本表读成卷三缩写，或读成「哪边才是正作」。两边都是产品。本表只回答：同一项合同，两边各写了什么。

每行链到史实或实现。史实：[《两条产品线：Java 与 Bedrock》](/history/java-bedrock)。实现：[《Bedrock 作为另一次实现》](/impl/bedrock)。机制细节仍在各专题章，本表不重写。

## 这一章留下什么

- **爱好者**：买一份仍然不是全部。能联机的那条线占用了本名；模组河、准连接、十年存档各在各的护照上。
- **开发者**：能抄走的是分叉清单：柜子、协议、红石词、战斗手、扩展面、货架。抄不走的是两套测试集。本表不是合并规格。合并没有共同的怪癖宪法。
