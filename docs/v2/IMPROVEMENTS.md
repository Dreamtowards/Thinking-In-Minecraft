# 新版（docs/v2）对比旧版（docs/）的主要提升

写作时间：2026-09-17 至 2026-09-18。新版覆盖与旧版相同的 71 篇结构（序 3 + 卷导读 4 + 章 58 + 附录 6），另启动英文版（docs/en，序 3 篇已完成）。以下按「可验证的客观改进 → 内容与文风改进 → 事实纠错清单 → 保留与承认」组织。

## 一、可验证的客观改进

1. **未注册组件清零。**旧版 74 个 mdx 中有 **59 个**使用了站点未注册的组件（`<Callout>`、`<Cards>`、`<Card>` 等）——这些组件在 `components/mdx.tsx` 中没有对应实现，渲染时会落入 fallback 兜底框：`<Card href>` 的链接完全丢失，卡片排版失效。这是旧版站点的实际渲染缺陷。新版全 66 篇（至写作时）**0 个**未注册组件，只用真实注册的 `Note / Alternative / Memoir / Impl / Constraint / Figure / mermaid`。
2. **脚注从「多」改为「可信」。**旧版全书 399 条脚注（约 5.4 条/章），来源未经验证流程。新版 174 条（约 2.6 条/章），但**每一条脚注的 URL 都在写作时被实际打开核验**（写作 agent 有明确的核验请求限额与降级纪律：核不出的数字一律降为「量级」，核不出的引语改为转述）。以数量换可信，是本次重写的核心取舍。
3. **交叉引用一致性。**旧版存在同名异称的章名链接（如《模组即作者》/《模组，作为作者》指向同一章）；新版复查中已统一全部章名链接为正式标题，跨卷引用一律带卷号（「第 8 章」→「卷一第 8 章」/「卷三第 8 章」），消除歧义。
4. **结构机械项全部达标。**新版 71 篇全部具备：frontmatter 双字段、命题 blockquote（含证伪条件）、与 PLAN 大纲一一对应的 H2、「这一章留下什么」双句结尾（开发者章含「能抄走/抄不走」）、脚注 id 与定义一一配对。复查用统一脚本（字数、H2、脚注配对、违禁组件、英文残留）逐章执行。

## 二、文风与可读性（针对「黑话与压缩」问题）

旧版重灾区（尤其卷三）的典型句式与新版对比如下（均为真实摘录）：

| 旧版写法 | 问题 | 新版对应处理 |
| --- | --- | --- |
| 「红石粉，下文沿用社区口呼」「立法的测试集在墙上，比快照说明大」 | 自造黑话 + 过度压缩，读者无法解码 | 每个术语首现即用一句大白话解释；「写完通读，读不顺就改」写入每个写作任务的硬性自查 |
| 「墙上这是：曾经靠『看起来没连、逻辑上却在供电』省空间造出来的紧凑机器，突然少了一条动词」 | 意象堆叠，主语缺失 | 短句为主、一段一事；「说清成因的意思是：能指着具体机制讲」改为完整因果链表述 |
| 「两种代替撞在一起，就是革命」「裂开之后有的改留下，有的用新开关补回旧语义」 | 高密度对仗牺牲清晰度 | 保留论点，重建论证步骤（新版第 8 章用「四步社会过程：实现→观察→依赖→冻结」展开同一结论） |

新版文风硬规则：术语首现必释；关键判断必须带「怎样算这句错了」；一章至多两处轻幽默；Java/Bedrock 分述且给出合写判据（删掉版本名仍成立才可合写）。

## 三、事实纠错清单（重写过程中实际修正的错误）

以下错误有的来自旧版、有的来自本次任务卡的初步猜测，全部在 v2 写作中被二手核验推翻并改正（这是「幻觉与压缩太大」问题的直接对照证据）：

1. **Hypixel 峰值时间**：任务卡原写「2020 年 4 月超 21 万」；核验后改为「2020 年疫情期日峰值约 15 万，**2021 年 4 月**峰值约 21.6 万」（Wikipedia Hypixel 条目）。
2. **Bukkit 危机性质**：任务卡原写「Wesley Wolfe **诉** Mojang」；核验后改为「向 GitHub 提交 **DMCA 下架通知**而非诉讼，提交者仅署 ID Wolvereness」（GitHub 官方 DMCA 档案为一手来源）。
3. **账号强制迁移时间线**：任务卡原写「2020–2021 强制迁移」；核验后为「2020-10 宣布、2021-06 起分批、**2022-03-10** 强制关闭、2023-09-19 收尾」。
4. **红石加入日期**：初稿写「2010-07-09」；核验后为「Alpha v1.0.1，**2010-07-02**（Seecret Friday 3）」，并补入「顶替共用编号 55 的齿轮」细节。
5. **Minetest 更名 Luanti**：任务卡猜「2023 年」；核验为 **2024 年 10 月**（官方公告）。
6. **Vintage Story 发售**：任务卡猜「2019 年」；核验为 **2016 年 9 月**公开销售。
7. **Hytale 全时间线**：核验补齐了 2025-06-23 取消、2025-11-17 创始人买回、**2026-01-13 抢先体验**（本地抽验英文维基逐条吻合）。
8. **Chromebook 支持教育版**：任务卡猜「2021 年」；核验为 **2020-06 公测、2020-08 正式**。
9. **Omniarchive 的性质**：任务卡误写为「服务器存档计划」；核验后为「**抢救散佚官方版本**的社区项目（找回 80+ 个丢失版本）」，并把「服务器归档接近空白」作为结论写出。
10. **付费起点**：核实「付费并非始于 Alpha，Survival Test（2009-09-01）上线即付费 9.95 欧」，修正了通行的模糊说法。
11. **Mojang 公司史**：商号「Mojang Specifications」2009-06-18 注册、公司 **2010-09-17** 成立，经英文维基核验。
12. **中国版注册用户口径**：任务卡写「2019 年超 4 亿」；核验后按「2019-11 达 3 亿、2020-11 破 4 亿」写入。
13. 无法核验的数字一律降级：如 Mojang 2013 年收入/利润写为「数亿美元/上亿美元量级」并明示；正编中不出现任何编造的精确数字与引语。

## 四、内容与结构上的实质重写

1. **概念框架为原创重建，不是旧文润色。**新版自建并全书贯通的分析工具包括：可误用系统的三判定（卷二第 7 章）、三层立法与因果单元（卷二第 12 章、卷四第 5 章）、咽喉决定经济（卷一第 11 章）、词汇恒定宪法（卷四第 8 章）、债转资产的安检判据（卷三第 8、18 章）、五条最小内核（卷三第 18 章）。旧版有相近论点（相似之处被允许保留），但新版全部以自己的论证结构重新展开。
2. **枢纽章按新纪律重写。**卷二红石、卷三红石、模组架构、双版本四个枢纽章各 7500 字上下，全部满足「零教程步骤」「不站队」「语义冻结的两难讲清」等验收项。
3. **附录重写为可查不可辩的形态**：年表（三轨、核验制）、人物与组织（只收正编核验过的人物）、双版本对照表（按「玩法/数据/扩展/商业」四层分组）、术语表（每词一句）、文献与源（分层列出正编实际引用过的 URL）、开发者实验题（八题四件套）。
4. **纠错透明化**：新版 PROGRESS.md 记录了每章的字数、脚注数、复查结论与修正记录，可回溯。

## 五、保留与承认

1. **旧版的骨架被继承**：三卷 + 卷四考试的结构、每章任务卡与大纲、「现象开篇、证伪、双版本」的方法口径（旧版 method.mdx 本身质量较好，新版序章在其框架上重写）。两版「有相似之处」符合重写约定。
2. **新版部分章节字数偏紧**：按 CJK 计约 2400–7700/章（对应含标点约 3000–9600 字），主要落在 PLAN 的 4000–8000 字区间内，个别思辨章低于 4000 字线——这是「易读优先、不灌水」取舍的结果，记录在案。
3. **旧版部分章节的事实密度值得尊敬**：如 impl 章引用了 0fps.net、bugs.mojang.com 工单、learn.microsoft.com 文档等较深来源；新版在重建论证时对其中可核验的部分做了重新吸收。
4. **未完成项**：英文版（docs/en）目前完成骨架与序三篇，其余章节待中文版定稿后按卷分批适配；站点迁移（以 v2 替换 docs/、补部 meta.json）按 docs/v2/README.md 约定留待整体迁入时执行。

## 六、结论

新版相对旧版的提升，按重要性排序：**可信度**（每条脚注实际核验 + 降级纪律 + 13 项事实纠错）→ **可读性**（去黑话、术语必释、短句纪律）→ **渲染正确性**（未注册组件 59 → 0）→ **一致性**（章名/卷号/链接全表统一）→ **原创框架**（可误用系统、因果单元、咽喉论、词汇恒定等自建概念贯穿全书）。旧版的良好骨架（结构、口径、部分论点）被有意识地继承；被否决的「幻觉与压缩黑话」，在新版的写作纪律与复查流程中被系统性排除。
