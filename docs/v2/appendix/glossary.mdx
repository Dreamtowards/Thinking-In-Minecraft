> **使用说明**：每词一条定义，不展开论证。标注（本书）的词条是本书自建的分析概念，其余为社区或官方通用语。

## 世界与数据

**方块（block）**：世界的基本单元，一体积约一立方米的格子；一切建造、破坏与交互的对象。

**体素（voxel）**：三维的「体积像素」；本书用来指可操作的整数网格，而非某种渲染技术。

**空气（air）**：一种正式的方块。空处也占一格数据，所以世界才能被逐格记录。

**区块（chunk）**：世界在空间与读写上的裁切单位，16×384×16 的柱体；加载、保存与模拟按它结算。

**节（section）**：区块内 16×16×16 的子立方，存储与调色板的计量单位。

**调色板（palette）**：每节存一份「种类表」，方块只记表内序号——同类压缩的手段。

**方块状态（block state）**：一个方块的可变属性（朝向、水位、是否点燃）；1.13 扁平化后取代旧的数字元数据。

**方块实体（block entity）**：带私有数据的方块（箱子、熔炉、告示牌），有数据、会记账、不走动。

**实体（entity）**：一切「在世界里有位置、会自己动」的对象：生物、掉落物、船、箭。每刻都要计算，是性能的第一税种（本书用法）。

**组件（component）**：物品或方块的具名可定制属性；「具名清单优于自由字段」的落地形态。

**NBT**：Named Binary Tag，带标签的二进制数据格式，世界的通用收纳盒。

**命名空间（namespace）**：内容全名的前缀（`minecraft:` 与你自己的），防冲突的门牌号系统。

**数据转换器（DataFixerUpper）**：Mojang 的开源迁移库：把旧版本数据逐层翻译到新版本，只增不减。

**混淆（obfuscation）**：发布时把类名方法名替换成乱码的工序；2025 年 10 月起官方移除。

**远地（Far Lands）**：旧版本极远处因浮点精度耗尽而破碎的地形；「无限」露出的工程马脚，被社区供成圣地。

## 时间与模拟

**刻（tick）**：模拟的时间步。Java 版每秒 20 刻，一刻预算 50 毫秒——世界的时钟。

**TPS**：每秒刻数。掉 TPS 时画面不卡、世界变慢——熔炉真的慢了。

**计划刻（scheduled tick）**：方块预约的「到点必办」：水流、沙落、火焰蔓延。

**随机刻（random tick）**：每刻随机抽查方块执行生长与衰变；世界的生命感由它供给。

**准连接性（quasi-connectivity）**：活塞能被「上方一格」的电源激活的实现怪癖；MC-108，已被社区当地基（Java 版特有）。

**BUD**：方块更新侦测器——利用「被供电却没被通知」的悬置状态做的开关；后来被官方收编为观察者方块。

**连锁更新**：一格改动触发邻居响应、邻居再触发邻居的图计算；卡顿与复制漏洞共同的温床。

**模拟距离 / 渲染距离**：前者管多远的世界「运转」，后者管多远的世界「可见」；1.18 起分离。

## 扩展与生态

**模组（mod）**：改客户端和/或服务端程序本身的扩展；能加新系统，通常要装加载器。

**插件（plugin）**：只改服务端、原版客户端即可加入的扩展（Bukkit/Spigot/Paper 一系）；改的是「这台服务器的法律」。

**数据包（datapack）**：官方的数据层扩展，随存档走；能填插槽，不能造新机制。Java 版特有。

**资源包（resource pack）**：换表征不换规则的官方层：贴图、音效、模型。

**附加包（add-on）**：Bedrock 版的数据扩展格式（资源 + 行为 + 脚本），可进 Marketplace 审核。

**加载器（loader）**：管理模组装入与冲突的框架：Forge、Fabric、NeoForge 一系。

**Mixin**：把一小段逻辑「缝合」进官方方法的字节码织入技术；轻量模组的地基。

**事件监听**：插件在「方块被破坏」等事件发生前抢先表态的机制；领地、经济、小游戏全长在这一个切口上。

**整合包（modpack）**：把几十个模组调配成整体的策展作品；作者被称为「第三层作者」。

**原版（vanilla）**：不装任何修改的 Minecraft；这个词因模组生态的繁荣而被发明。

## 版本与产品

**快照（snapshot）**：Java 版每个正式版之前的公开测试版本；Bedrock 的对应物叫预览版（Preview）。

**基岩版（Bedrock Edition）**：非 Java 平台共享的那份 C++ 实现；从口袋版一路统一而来。

**Marketplace**：Bedrock 内置的官方内容商店；签约审核制，用 Minecoin 结账。

**Realms**：官方出租的月费小型服务器；省心的代名词，能力刻意弱于第三方。

**语义分叉**：同一机制在两版行为不同（如战斗冷却）；比性能差异更致命的品牌债（本书用法）。

## 社区与分析（含本书概念）

**Griefing（搞破坏）**：以破坏他人作品为乐的行为；开放世界默认政治状态的产物。

**Pay-to-win（付费变强）**：花钱买到影响平衡的优势；2014 年 EULA 划定的红线。

**可误用系统（本书）**：交付物理而非玩法清单、正解由社区发明并反哺规则、误用不受惩罚——三条同时成立的系统。

**兴趣管理（本书）**：模拟资源按「谁在关注」分配的制度；原版欠账、社区补齐的重写核心题。

**因果单元（本书）**：以连通图为界的严格序结算区；兴趣调度的并行不以它为代价。
