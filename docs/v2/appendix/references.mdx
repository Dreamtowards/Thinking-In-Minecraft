> **使用说明**：按可信度分层列出正编引用的主要来源类型与代表条目。各章的逐条脚注是第一手对照，本页是分类速查。

分层的口径与[《体例与方法》](/prelude/method)的材料分层一致：先问一句话能不能靠实测复现，再看官方材料，再看维基与社区文档，最后才是新闻与行业报道。本页只收正编各章脚注里实际出现过的来源，不新增条目。

## 一、可复现的机制

这一层的可信度不来自谁写的，而来自可复现：游戏里搭一遍就知道对错。正编的机制表述以 minecraft.wiki 的机制页为准，代表条目：

- minecraft.wiki，《Tick》（游戏循环、刻的种类与随机刻速度），https://minecraft.wiki/w/Tick
- minecraft.wiki，《Lighting》（光照的传播与 1.14 的多线程重写），https://minecraft.wiki/w/Lighting
- minecraft.wiki，《Breaking》（挖掘进度与工具的关系），https://minecraft.wiki/w/Breaking
- minecraft.wiki，《Chunk format》（区块数据的构成），https://minecraft.wiki/w/Chunk_format
- minecraft.wiki，《Quasi-connectivity》（准连接性的成因与 MC-108 的「按预期工作」判定），https://minecraft.wiki/w/Quasi-connectivity

## 三、维基与社区文档

玩家维护的机制与版本记录，以及官方开源仓库的自述。条目随版本更新，引用时注明检索日期：

- minecraft.wiki 的版本与格式页，如《Bedrock Edition》（https://minecraft.wiki/w/Bedrock_Edition ）、《Anvil file format》（https://minecraft.wiki/w/Anvil_file_format ）、《Bedrock Edition level format》（https://minecraft.wiki/w/Bedrock_Edition_level_format ）、《Marketplace》（https://minecraft.wiki/w/Marketplace ）
