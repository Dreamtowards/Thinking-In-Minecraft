> **本章命题**：Minecraft 的社区创作同时是游戏史上最开放的 UGC 生态、和最难被平台抽成的 UGC 生态。这不是矛盾，而是同一件事的两面：作者席建立在官方拿不到技术咽喉的位置上——Marketplace 卖的是商品，模组卖的是作者席。

## 问题

先摆两个真实存在的职业，它们属于同一个游戏。

第一个是模组作者。他的作品可能被下载了上千万次，装在全世界几百万台电脑上；他的全部收入渠道，通常是下载页上的一个捐赠链接，以及下载站按月结算的一笔积分折现——多数月份，这笔钱不够付一张 office 的工位租金。第二个是服务器运营者。他运营的网络可能养着几万名日活玩家，卖会员、卖外观、卖赛季通行证，年流水以百万美元计——而 Mojang 的账上，从他这里一分分成也拿不到。

把这两个职业并排放着，会看出一个奇怪的结构：离官方内容最近的人（做内容的）几乎不挣钱，离官方内容最远的人（开服收门票的）反而挣得多；而官方自己，两头都插不进手。直到 Bedrock 版的 Marketplace 出现，官方才第一次在自家的商店里对玩家创作抽上了成——但那是在另一条产品线上，用的是另一套内容格式。

本章要回答的是：为什么 Minecraft 的社区创作既是最开放的生态，又是最难被抽成的生态？这两个形容词为什么偏偏长在一起？这不仅是社区八卦，它是一个平台问题：**当你把作者席让给用户，你还剩下哪些收钱的合法位置？**Minecraft 用十几年时间把这道题的正反两面都演示了一遍。

先把范围说清。本章讨论的三层经济——模组的、服务器的、以及游走在许可协议边缘的灰色层——都属于 Java 版主导的世界；Bedrock 版的 Marketplace 经济和中国的区域版合同是另一套制度，分别在[《Java 与 Bedrock》](/history/java-bedrock)和[《收入结构》](/history/revenue)里写，本章只在对照时借用。

## 免费模组养活了付费游戏

先立一个反直觉的判断：**Minecraft 的销量里，有相当一部分是免费模组间接卖出去的。**

道理不复杂。一个 2012 年犹豫要不要花十几欧买这款游戏的玩家，他在网上看到的是什么？是装了几十个工业、魔法模组的整合包实况，是红石计算机的演示视频，是「你甚至可以把这个游戏变成宝可梦」的传说。这些内容没有一条来自 Mojang 的宣传预算，全部来自免费分发的社区创作。社区内容把「这个游戏能玩出多少花样」的问题回答得越夸张，正版的转化就越顺。模组生态是这款游戏事实上的免费市场部，也是它对「内容会玩腻」这个长寿游戏第一杀手的长期保险。

这条因果链有个可检验的反面：如果免费模组对销量不重要，那么官方最合理的做法是尽早把模组收编进收费体系——本书写到这里，历史给出的答案已经知道收编没发生（为什么没发生，本章最后一节给机制解释）。而「免费创作撑高游戏价值」这个结构，最硬的旁证来自官方自己：Bedrock 版的商店里，玩家为社区作者的内容付了超过十亿次、累计三亿五千万美元以上——玩家愿意为「更多内容」掏钱这件事，被官方商店实打实验证过。[^payout] 付费意愿存在，只是 Java 版的结构让官方收不上来。

这个结构其实有家学渊源。游戏早期，免费开放本身就是增长引擎：Classic 阶段免挂在网页上随便玩，付费的 Survival Test 才要掏钱——先给一个不要钱的入口，等人上了瘾再谈转化。模组生态等于把这个漏斗延长到了游戏的一生：正版玩家买完游戏，内容消费不封顶；观望玩家隔着免费的模组视频看热闹，随时可能跳进漏斗口。别的游戏把「免费试玩」做成一个 demo 文件，Minecraft 把它做成了一个持续生产了十几年的创作者阶层。

## 模组劳动：无偿、捐赠与打赏

Java 版模组生态的默认价格是零。这不是谦虚，是结构。

先看劳动的规模。一个中等以上的模组是几万到几十万行代码的工程，持续维护十年是常态；每个 Java 大版本发布，生态里所有模组都要跟着迁移一遍（第 4 章写过这场没有尽头的返工）。这些劳动的报酬结构，社区里长期只有三种：**一分不拿**是多数；**捐赠**是少数，从「置顶一个捐赠链接」到运营 Patreon 订阅；**平台折现**是第三种——下载站把广告收入拿出一部分分给作者。最后一种值得单独看一眼，因为它最接近「平台抽成」的反面：不是作者给平台交钱，而是平台把广告费分作者。

最有规模的是 CurseForge。它从 Twitch 手里转到 Overwolf 名下之后，运行着一套作者积分制：按下载与热度把每月的奖池折成积分分给作者，作者可以把积分换成钱；对签约项目另有更高比例的分成安排。[^curseforge] 后来居上的 Modrinth 也向创作者开放了广告分成式的变现。这些渠道真实存在，也要如实标注它们的天花板：能靠模组收入全职的是极少数头部，绝大多数作者挣扎在「服务器账单报销」的水平线上——按用爱发电的比例算，这可能是全游戏行业里最悬殊的头部与长尾。

为什么不干脆收费？不是作者不想，是**技术上收不了**。模组是自由分发的文件，一旦发布，就没有任何机制阻止复制、转发、二次上传；下载站之间互相搬运是社区常态，「请去原帖下载」的道德呼吁拦不住镜像站。在一个没有技术围栏的市场里，定价权归零。头部作者真正保得住的资产只有两样：署名和社区声望——这也是为什么这个生态的名誉机制（更新勤不勤、答复快不快、有没有偷偷埋后门）比商业机制发达得多。

把这套劳动制度看清楚，「第二作者席」这个词才显出它真实的分量：那不是荣誉称号，是一份没有底薪、按爱计酬、却撑起产品半边内容的合伙制。第 4 章说过官方十余年「不禁止、不付钱、不接管」的态度；本章补上它的经济含义——**免费劳动是这款产品最大的成本外部化**。Mojang 不用雇内容团队就能有全球最大的内容生态，因为生态自己养自己，顺便替游戏卖了几亿份拷贝。

没有工资，不等于没有产权制度。这个生态用「授权文化」替代了版权执法：整合包作者想把别人的模组打进自己的包，按礼俗要先获得原作者同意——下载站把这套礼俗做成了功能，授权状态挂在模组页面上，白纸黑字。大型整合包发布页上常见一整段「致谢与授权清单」，像一份合同附件。整套制度的执行靠的不是法院，是社区记忆：谁曾未经允许搬走别人的作品，论坛会记得很多年。用声誉执法的成本极低，效果出奇地好——因为它结算的本来就是声望，而声望恰好是这个市场唯一的硬通货。

## 服务器变现与 Pay-to-win

服务器的经济比模组直白得多：它有技术围栏。玩家想玩你的服，必须连你的机器——这一条就足以让运营者收钱，方式是卖「特权」：更快的出生装备、额外的领地格数、专属称号、飞行能力，通行的叫法是 Rank 或 VIP。

这门生意的规模曾经过度繁荣。2010 年代中期，卖影响平衡的优势（Pay-to-win，花钱变强）几乎是行业默认：大服靠这个支付机器与人力，小服靠这个回血电费。转折发生在 2014 年：Mojang 更新最终用户许可协议（EULA），给服务器变现划线——可以卖外观、卖不影响平衡的便利，不能卖「花钱就比免费玩家强」[^eula2014]。那场风波的来龙去脉、三方各自的道理，[《服务器即新游戏》](/history/servers)已经细写过，本章只记它的经济后果：**大服活下来了，而且活得更好。**

原因值得拆开。EULA 并没有禁止收费，它只是把可卖的品类从「优势」改判为「外观与便利」。头部网络本就拥有全游戏最阔的受众和最强的美术与工程团队，管制反而把灰色竞争者清出了场：合规成本只有大玩家付得起。皮肤、粒子特效、宠物、开箱钥匙——这些不碰平衡的商品填上了优势商品的空位，大服的收入结构变得更像免费网游的 cosmetics 模式，而不是赌场模式。对小服来说，日子确实变难了；对一个生态来说，这是一次「用监管集中度换秩序」的典型案例，谁吃亏谁受益，取决于你站在流水线的哪一环。

同样要写清的是合法性与分成的关系：服务器收钱完全合法（在 EULA 框架内），但它**不分成**。一台年入数百万美元的服务器网络，Mojang 从中获得的是零——原因是技术上的：服务端软件人人可以下载，开服不需要经过任何审批，官方没有可以从技术上卡住的那一环。第 5 章把它叫作「地方政府」，本章补上财政学的说法：这是全世界规模最大的无税经济体之一，中央政府只握着一部宪法（EULA），没有税务局。

这门生意还长出了一个容易被忽略的就业层。一台像样的中型服务器背后，往往不止服主一个人：建筑师按图纸拿佣金，插件开发者接定制订单，美术画皮肤和宣传图，管理员按月领「工资」——人民币、美元或服务器内的特权。围绕服务器还长出了真正的外包市场：不会建大教堂的服主花钱请建筑团队，想要独占玩法的服务器买断开发者的插件。换句话说，服务器经济不只是「向玩家收钱」，它是 Minecraft 世界里的雇主部门——相当一部分年轻人的第一笔技术或美术收入，来自一台游戏服务器。这笔账任何官方报表里都没有，但它是这个生态里最像「正经经济」的部分。

## 灰色层：生态事实，不提供指南

任何写实的经济章节都绕不开灰色地带。本节按事实写，不提供任何操作指南。

Java 版生态里长期存在三样东西，游走在许可协议之外。**盗版客户端**：不付费的登录途径，社区对它们的态度从来分裂——多数玩家视之为偷窃，也有相当一部分人引用 Notch 本人早年公开表达过的宽容立场：多数下载盗版的人原本就不会付费，其中一部分日后会成为买家。**离线模式服务器**：服务端软件里存在一个允许不校验正版的选项，它原本是给局域网联机准备的合法功能，被挪作他用的那部分构成了盗版的联机层。**搬运与转载**：模组、地图、皮肤被搬运到各处，原作者的署名与授权意愿经常丢失——这是创作侧的灰色层，规模比前两者都大，杀伤却最安静。

官方对这三样东西的实际策略，十几年来可以概括为「边界清晰、执法克制」：EULA 和账号体系把合法边界画清楚，但大规模追索盗版用户的事从未发生；真正的打击集中在两端——假冒正版的商业性山寨 launcher 和侵权商店，以及 2020 年代起账号迁移后收紧的在线验证。这不是心软，是计算：Minecraft 的销量结构里，新兴市场的渗透靠的恰恰是「先玩到，后补票」的文化；把灰色层赶尽杀绝，砍到的是自己的未来客源。这个判断可证伪：如果灰色层纯粹是损失，官方逐年收紧的验证本应伴随销量的下滑——观测到的走势相反。

还要老老实实写一句：灰色层不是浪漫故事。它同时滋养着服务器的恶意攻击、作者作品的未授权商用、以及一堆把「免费」当诱饵的捆绑软件。开放生态的代价从来是双向的——好东西传播得快，坏东西也是。

## 两种 UGC：Marketplace 卖商品，模组卖作者席

现在可以回答开头的问题了：为什么同一个品牌下，长出了两种完全相反的创作经济？

判据只有一个：**官方手里有没有技术咽喉。**

Bedrock 版有。它的扩展格式是官方定义的数据文件，它的玩家账号长在微软的账号体系里，它运行的平台（主机、手机商店）本身就要求审核分发。三样加起来，官方卡住了内容到达玩家的每一条必经之路，于是商店成立：签约、审核、代币、抽成、分成，平台经济的标准零件一个不缺，玩家为内容累计付了数亿美元，官方与创作者各取所需。[^payout]

Java 版没有。模组改的是字节码层面的东西，分发走的是任何人都能架设的网站，账号和内容之间没有绑定。官方想抽成，找不到那个能拧上的阀门——总不能给整个互联网装一个计费器。于是 Java 版的 UGC 走出了另一条路：不收费的作者席，用声望和捐赠结算；不抽成的服务器经济，用 EULA 划边界而不分成。这条路上不是没有钱，钱很多，只是钱流经的每一条管道都不经过官方。

所以这两种经济不是同一件事的两种做法，而是两种不同的商品。**Marketplace 卖的是内容商品**：皮肤、地图、材质，一次性消费，买了就用，作者与平台的关系是供应商与渠道。**模组卖的是作者席**：它出售的是「参与定义这个游戏是什么」的位置，作者与游戏的关系是合伙人与平台。商品经济里，平台最大的焦虑是库存；作者席经济里，平台最大的资产是那些不领工资的合伙人。Mojang 在 Bedrock 上学的是前一种，在 Java 上靠的是后一种——同一个公司，两种身份，界线由技术咽喉的位置划定，不由情怀划定。

「给 Java 模组抽成」不是没人试过，是每次都在同一个地方摔倒。2012 年，Mojang 曾公开谋划官方模组仓库与官方接口，结论是没有下文；此后的十年里，「官方商店收编模组」作为提案反复被社区讨论，每次都卡在同样的三件事上。其一，格式：任何进入官方渠道的内容都必须符合官方格式，而 Java 模组的价值恰恰在突破官方格式——把模组塞进审核管线，等于只收录「不重要的那类模组」。其二，作者：模组作者的号召力来自自由分发与开放源码，接受抽成意味着交出分发权，最头部的作者第一个不答应——而没有头部内容的商店只是个空货架。其三，玩家：十几年「免费、自由、先试后捐」的惯例已经把付费预期清零，商店里标价的那个模组，隔壁的搬运站里就有同款免费下载。三道墙里没有一道是法律墙，全是结构墙；法律墙翻起来最快，结构墙根本不需要防守。

## 这一章留下什么

- **爱好者**：你硬盘里那几十个模组、你常驻的那台服务器，背后是一整层不领工资却撑起半壁江山的经济——下次见到模组作者，捐赠链接不点开也该点个赞。
- **开发者**：能抄走的是咽喉论：设计 UGC 平台前，先画「内容到达用户的必经之路」，数一数自己卡住几环——卡几环，就决定你能抽几成、社区能自由几分；抄不走的是 Java 版那个历史形成的例外位置：没有咽喉还能繁荣，靠的是二十年社区攒下的声望结算体系，那不是设计出来的，是长出来的。
