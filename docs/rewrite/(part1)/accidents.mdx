> **本章命题**：语言运行时、全局恰好二十拍、两条产品线、某一份怪癖词，都不是骨头。抛弃它们必须仍保住上一章的七条不变量。保不住，你不是在抛偶然，你是在拆迁规则。偶然很贵。贵，仍然可以进兼容层，而不进内核。

## 问题

有人把卡写成「因为 Java」，于是重写的第一天就要换语言。有人把万人服写成「因为 20 TPS」，于是第一天就要拆掉主循环。有人把灯不亮写成「因为有两个 Minecraft」，于是第一天就要合并产品线。三句都指向真痛。三句都还没问：痛的下面，哪一块是规则，哪一块是 2009 年到今天的走法。

要回答：哪些不是本质？可被证伪的说法是：现在仓库里难养的东西都是本质，抛掉就会不像；或者反过来，凡是让你疼的都是偶然，清掉就会更像。只要还存在换掉 Java 却丢掉模组河、只要还存在拆掉全局拍却让飞行器无法复述、只要还存在合并双端却没有共同测试集，这句话就不成立。

上一章把骨头钉成七条。[《必须保留的设计不变量》](/rewrite/invariants) 卷三已经把语言标成偶然候选，并禁止提前毕业。[《Java 版运行时》](/impl/java-runtime) 本章判毕业。判的方式不是「可以扔」。判的方式是：扔的时候，不变量从哪条路活下去。活下去的路，常常叫兼容层或仿真层。层可以很厚。厚，不是把偶然偷渡回内核。

不得从本章读出开工用的语言。抛弃 Java 不等于指定 C++。Bedrock 证明过：指定过一次，因果会分叉。

## 语言运行时

Java 是 2009 年的正确：一份字节，多家操作系统，一个人能迭代，后来字节能被切开，模组河才有河床。正确会过期。过期的是「必须用这门语言」。不过期的是：扩展面必须真能加动词。切开是一种实现。稳定 API、脚本加原生双层、经过认证的沙盒，是别种实现。实现可以换。席位不能换。席位是不变量第 6 条。

抛弃语言运行时，要保住的是：

- 第二作者仍能在系统层立法，而不仅是换皮和换掉落。
- 数据层仍能随世界走。
- 旧的切口河若要继续活，必须有兼容层把 class 文件和 Mixin 认成客居者——否则你走的是继承，不是兼容。走继承，要写在封面上。[《我们到底在重写什么》](/rewrite/what-to-rewrite)

Bedrock 用 C++ 抛弃了 Java。它保住了格子、许多动词、一份权威。它没有保住同一条模组河，也没有保住同一台墙上的 VM。这不是「C++ 失败」。这是抛弃运行时时，把第 6 条和第 4 条的形状一起换掉，又用品牌假装没有换。考试判的是：语言可抛。抛完若只剩审核友好的调度，你抛的就不只是语言。

虚拟机税——GC、JIT、启动——是这门语言的账单，不是格子的账单。账单可以换。换账单时，不要把「启动更快」写成「因此更本质」。更快是性能曲线。本质在能不能指、能不能改、能不能再开发。

<Constraint name="运行时可抛席位不可抛" verdict="待定" chain="换语言 → 必须另写系统层扩展面 → 旧切口进兼容层或宣布继承">
抄走「不必用 Java」，丢掉「必须有人能加新动词」，你会得到原生客户端和空空的第二作者席。客户端可以很光。光不是完整产品。完整产品含再开发。再开发的形状允许换。再开发的缺席不允许用性能来辩。
</Constraint>

## 全局 tick 与兴趣管理

不变量要的是共享真实：有一份结算，熔炉、活塞、白天认它；客户端可以先演，不能另结账。[《游戏循环与刻》](/impl/tick) 全球所有实体抢同一条 50 毫秒，是把共享真实写成一种调度。调度在十人生存里诚实。在万人网络里，诚实变成所有人的炉子一起慢。[《服务端与规模》](/impl/servers)

所以 **20 这个整数**可以抛。抛的不是「不要拍」。抛的是「全世界必须同一条拍」。兴趣管理、分片、区域循环，是已经发生的局部抛弃。Folia 把证词写进崩溃日志：假设主线程的插件会直接死。死，说明偶然已经焊进 API。焊进 API 的偶然，抛弃时要付矩阵税。税可以付。付完，第 4 条必须仍能复述：红石玩家还要能指着某一格说，这一拍谁先说话。不能复述，飞行器不是变快了，是语言散了。语言散了，可误用系统只剩脚本。脚本是另一条河。

抛弃全局 20 的活法：

- 内核承认「兴趣」是调度单位，单人档的兴趣可以是整份世界，万人服的兴趣可以是许多个圈。
- 红石与流体若需要比实体更严的因果，给它们专用的、可解释的班次——班次仍要能被指、能被教，不能黑盒到只有引擎作者懂。
- 兼容层可以假装仍是 20 TPS 的旧世界，给旧机器一条仿真拍。仿真会慢。慢是读旧程序的价格。价格写进兼容，不写进「新内核必须永远 20」。

一天仍可以是两万四千拍的修辞。修辞能教。教的是节奏，不是主线程拓扑。拓扑不是骨头。

<Callout type="warning" title="抛拍不是抛因果">
TPS 掉了，玩家失去的是结算，不是帧。重写若用更高的帧率掩盖更乱的班次，你会得到好看的演示和无法教科书化的红石。演示通不过第 4 条。
</Callout>

## Java / Bedrock 双端

双端是产品史：一条河要进模组与 PC，一条河要进房间、进商店、进主机认证。史可以理解。理解不等于「Minecraft 本质是两个引擎」。本质若需要两个引擎，总命题会写成两句。它没有。一句已经够难。

抛弃双端，不是命令官方合并。合并没有共同测试集。抛弃的是把「必须维持两份因果」写成设计不变量。继承之路上，你可以只做一份内核。兼容之路上，你可以在一份内核外面挂两套仿真：一套认 Java 的词，一套认 Bedrock 的词。挂仿真，是承认口音贵。贵，仍然是口音。

不得从「双端可抛」读出「Bedrock 是错误」或「Java 是错误」。两边都是完整到某一格、残缺到另一格的产品。Java 残在进房间。Bedrock 残在切开。残，是产品选择。选择可以改。改的时候不要说「我们终于做成真正的那一个」。真正的那一个是七条规则，不是某一条产品线的仓库。

账号、Marketplace、EULA，是双端之外更外一圈的偶然。它们塑造能做什么，但不是格子。格子不认收银台。收银台认格子能不能被审核。审核反向约束扩展面，卷三写过。约束可以进产品伦理后文。本章只判：双端分裂不是骨头。骨头是扩展面还在不在。在的形状，允许只有一条河。

## 特例与未定义行为如何安置

特例方块和怪癖词，是最容易被错判的一层。它们看起来像灵魂。它们常常只是口音长在规则上。

**安置原则。** 内核留可误用：建造度量上的离散因果，稳定、可观察、官方不必教完。某一条具体 opcode——准连接、某一端更新顺序、火把过载熄灭、船的某次碰撞——进仿真层或兼容层。新内核可以没有准连接，只要它仍允许墙上长出新词，并且修词时承认自己在立法。若新内核又干净又不许长词，第 4 条死了。若新内核把 Java 的词焊死、不许仿真之外的因果，继承之路死了。

**仿真层。** 给旧机器一条「按某一版 Java 红石说话」的模式。模式可以慢，可以可选，必须可复述。可复述，Wiki 才能当这一层的说明书。说明书若只能对着已经删除的官方仓库，兼容就是空头支票。

**新语义。** 观察者、合成器那种加法：把民间需求收成方块，不注销旧词。旧词走仿真。新词走内核。两条路在 1.11 和 1.16 已经彩排过：收编是加法，诚实对齐要减压阀。[《红石的实现》](/impl/redstone) 彩排证明偶然能挪。挪，不是擦。

**特例物理。** 床在下界爆炸、水在下界蒸发、船的碰撞、某一格含水的 schema，逐条问：它增加的是可误用的动词，还是一份必须背下来的菜单？增加动词的，可以留在内核附近。必须背下来的，进数据或进仿真。卷二停手原则会把这句写全；本章只要安置权：特例不是自动的不变量。自动升格，内核会变成方块图鉴。图鉴不是规则。

Java 与 Bedrock 在这一层最不能合写。准连接删掉 Java 不成立。抛弃的句子必须带护照：抛的是「某一边的词必须进内核」，不是「两边的红石已经是同一门语言」。同一门语言从来没有过。没有过，所以双端不是本质；也没有过，所以兼容层不能只有一份。

<Impl title="兼容层不是内核的垃圾桶">
把所有不想养的东西丢进「仿真」会得到一个无限厚的假官方。层要有边界：只救测试集里已经稳定、可复述、被当材料的行为。个人存档里的奇迹不成 API。不成 API 的，不配进层，也不配进内核。
</Impl>

<Alternative title="若把怪癖全部焊进内核">
飞行器永不会停。你得到一份考古级兼容。你失去继承：任何新调度、任何新表示，都要先通过 2012 年某次通知顺序的海关。海关会让四格产品停在同一夜。停在同一夜，不是尊重玩家时间。是让时间不能再往前住。
</Alternative>

<Memoir title="修了，所以革命">
快照说明写着修复。墙上的那一层停了。口令不说谢谢。口令说语言被删。下一章若开始画新调度，请把这句口令放在验收里：你抛的若是偶然，教科书应当能翻译；翻译不了，你抛到了骨头。
</Memoir>

## 这一章留下什么

- **爱好者**：Java、整整二十拍、两个版本、某一次「红石 bug」，都可以不是命。命是：格子还能指，世界还能改，目标还空着，墙上还能长出语言，存档还能打开，别人还能接着改。命还在，换引擎叫继承。命还在又要旧飞行器还飞，才需要一层翻译。翻译可以很烦。烦不是「所以什么都不能动」。
- **开发者**：能抄走的是四条可抛（运行时、全局 20、双端必然、具体 opcode 与特例清单）以及对称纪律——每一抛都要写清七条不变量的活法；活法常常是兼容层 / 仿真层，不是「删掉就变干净」。抄不走的是测试集本身，以及 Bedrock 已经交过的卷：换语言不等于换本质，也不等于本质自动跟过来。你不得从本章带走指定语言。你现在只配做一件事：把偶然和骨头分成两叠。分完，后文才许画世界表示和调度。画的时候若把准连接写进内核当骄傲，或把扩展面写进商城当进步，请回到上一章重考。
