> **本章命题**：同一套可寻址的格子，必须同时服务「住十年的家」和「十二分钟一局的战场」。差的不是度量衡，是实例的寿命政策。把小游戏做成另一份物理，口令会裂；把生存做成不可重置的唯一实例，大厅会把家拖死。旧档是第一等公民，不是导入向导里的可选项。

## 问题

生存档的山要能走一辈子。起床战争的岛要能一局清一次。两边都在挖、都在放、都在认两格门。原版用同一份柱子硬扛两种寿命：家付无限的流式账单，大厅用多进程假装是一个国家。[《服务端与规模》](/impl/servers) 硬扛会裂。裂的不是方块好看不好看。裂的是：重置和居住抢同一份表示法。

要回答：怎样同时服务生存与小游戏？可被证伪的说法是：只要格子还在，一份世界文件就能当所有产品；或者反过来，小游戏应当另做一套连续关卡，生存单独用体素。只要还存在大厅和主世界抢同一条拍、只要还存在「换一张图等于换物理」的地图、只要还存在十年档打不开而赛季服无所谓，这句话就不成立。

上一章把表示法里的偶然松开：语言、全局 20、某一格 schema。[《可以抛弃的历史偶然》](/rewrite/accidents) 本章提案只动柜子，不换一米尺。[《必须保留的设计不变量》](/rewrite/invariants) 不是某语言的伪代码大全。是原版怎么装，提案怎么分装。兼容的梯子留给后文伦理。本章先把「旧档必须能被指着说还在」写成表示法的职责，而不是售后。

## 表示法要服务两种产品

两种产品都要格子。不要把它们收成两种引擎。

**居住实例**要稀疏、要流式、要旧。人走远了，柱子可以卸盘；人回来，墙还在。空气海必须便宜，否则无限是自杀。方块实体是账户，不是每一格的行李。这份实例的成功标准是：十年后仍能指着某一格说「这是门」。

**对局实例**要密、要短、要可丢。岛很小，实体很多，十二分钟后整份世界可以作废。成功标准是：重置便宜、因果在这一局里可复述、下一局不欠上一局的光照债。原版把对局塞进居住实例里，用插件清场。清场是在虐待表示法。表示法若认识「实例」，清场是生命周期，不是半夜回档。

共用的是度量：一米、可破坏、可放置、可计数、空气也是状态。不共用的是：**这一份格子活多久、卸盘策略是什么、要不要进旧档梯子。** 大厅进程和主世界进程，是原版用运维做的多实例。提案把它收进内核：同一个模拟认同一套状态，世界 ID 不同，寿命政策不同。政策是数据。数据可以是「永续」「赛季」「这一局」。政策不是另一套碰撞箱。

创造服的展览、小游戏的战场、家庭生存档，于是可以跑在同一内核上，而不必假装是同一份 `region/`。四产品矩阵里，这是原版体验和服务器平台共享骨头、分开实例。[《我们到底在重写什么》](/rewrite/what-to-rewrite) 共享失败的样子是：起床战争的重置删了别人的家，或家的无限柱子让大厅的 MSPT 一起烂。

Java 的 Anvil 与 Bedrock 的 LevelDB 是两套柜子，不是两种产品需求。[《两条产品线：Java 与 Bedrock》](/history/java-bedrock) 提案不要求合并柜子。提案要求：无论哪套柜子，都要能表达「永续实例」和「可丢实例」。表达不了，你只服务了其中一格产品。

## 稀疏与调色板

无限的修辞，账单在区块上。[《世界生成即内容生产》](/design/worldgen) 原版已经做对了大半：节、调色板、空气也占位、重复的石头共享短表。[《体素世界的数据模型》](/impl/data-model) 提案不是改成八叉树以示现代。八叉树可以当偶然实现。不变量要的是：地址仍是整数格，I/O 仍按柱子切，空的法律仍在。

稀疏的意思是：没人去过的柱子可以不在内存里，甚至可以还没有生成。生成是管道，不是表示法的反面。表示法要允许「尚未存在」和「存在但是空气」是两种法律——原版用未加载和空气状态大约做到了。提案把这两种法律写进第一等：未生成不是空指针漏洞，是生命周期。小游戏实例可以整图预生成、整图丢弃。居住实例必须允许走出去再生成。两种生命周期共用调色板，不共用「必须先铺满」。

调色板的边界仍是：一格的法律必须可数。不可数的属性——任意 NBT 挂在每一格上——会把短表胀成每格一份行李。活塞就推不动「这一格的法律」。原版把库存从状态里赶进方块实体，是对的。提案保持这道墙。墙的这边：朝向、开合、水位、含水，进状态，进调色板。墙的那边：箱子内容、熔炉进度、刷怪笼名单，进账户。账户可以组件化。格子不能。格子一组件化到任意字段，稀疏会死在空气海里。

流式 I/O 是居住实例的呼吸。对局实例可以不呼吸：整图在内存，结束即删。内核若只有一种呼吸，万人大厅会按十年生存的方式存盘。那是用错政策。政策写在实例上，算法可以共享。

## 状态 vs 组件

原版走了两次改革：扁平化把数字号收成名字加状态；组件化把物品的任意 `tag` 收成有模式的字段。[《物品、库存与合成》](/impl/items) 两次都对，对象不同。提案把对象写死，免得再混成「一切皆组件」。

**方块状态**服务活塞、命令、调色板、口令。它必须是有限键值。有限，才能被推、被数、被指。含水可以是状态上的一位，也可以是 Bedrock 那种另层——口音。不变量是：无论哪一种，都必须可点名、可进表。

**物品组件**服务财产。剑要能对账、能移交、能迁。任意模组私货走显式逃生口，不能污染官方字段。原版的 `custom_data` 是这个方向。提案保持：组件有 schema 版本，迁移按件计费，计费是伦理不是性能彩蛋。

**方块实体 / 实体**服务账户和税。实体贵，方块便宜，卷三写过。[《实体与碰撞》](/impl/entities) 提案不把展示用的装饰默认做成实体海。装饰能进状态或短寿命对象的，不要进万人广播名单。表示法在这里为协议省税。省税不是优化指南。省税是：看见的流畅，不该强迫每一片落叶都有一份权威生命。

对照不是选型。对照是职责。职责一混，生存的山会像物品一样难迁，小游戏的剑会像空气一样不可数。

| | 原版 | 提案 |
| --- | --- | --- |
| 空间单位 | 区块 / 节；调色板压重复状态 | 仍是可寻址格；区块仍是 I/O 与兴趣的骨。实现可换，单位不换 |
| 空气 | 合法状态 | 合法状态；与「未生成」分家 |
| 方块法律 | 可数状态 + 方块实体账户 | 同左。禁止每格任意组件 |
| 物品法律 | 1.20.5 起组件 | 组件 + 版本化 schema；私货走逃生口 |
| 生存 | 一份永续世界，流式柱子 | **永续实例**：稀疏、流式、进旧档梯子 |
| 小游戏 | 同一世界清场，或多进程联邦 | **对局实例**：可预生成、可丢弃、重置是生命周期 |
| 多世界 | 维度是特例；大厅靠代理 | 实例是第一等。维度是实例上的规则变体，不是唯一的多世界 |
| 旧档 | DataFixer 梯子，像内部细节 | 梯子是产品职责。读不起 = 宣布过去作废 |

## 多世界、确定性回放

多世界不是「再加几个维度」。下界和末地是规则变体。[《维度、进度与终局》](/design/dimensions-endgame) 提案里，变体仍是实例上的一份规则包：重力、床、水、生成器。大厅、战场、剧场、测试用的红石平板，也是实例。实例可以共享种子推导，也可以完全手摆。共享种子的，是可能世界的口令。手摆的，是地图作者的文本。

确定性回放服务两件事：调试与伦理。调试：这一拍谁改了哪一格，飞行器为什么停。伦理：回滚不是神话，是对玩家时间的手术。表示法要留下足够的因果钩子——哪一个实例、哪一节、哪一份状态版本——调度章才能把钩子收成可解释的班次。钩子不是全量录像。全量录像是另一种产品。钩子是：状态迁移带着版本，事件可以按实例重放一小段。小游戏用它做「这一局的录像」。生存用它做「回档到熊之前」。两份用法认同一套版本字段。

Java 与 Bedrock 的种子本就不是同一把钥匙。[《世界生成管线》](/impl/worldgen-pipeline) 提案不假装一份噪声两边通用。确定性是实例内部的合同：同一版本、同一规则包、同一输入，应得到可复述的柱子。跨产品线的确定性，是兼容层的谎或翻译。谎要标明。

## 旧档

旧档不是导入。导入假定过去是别人的格式。Minecraft 的过去是玩家的时间。表示法若把「新世界」当默认、把旧世界当转换器插件，第 5 条不变量已经假了。

提案把旧档写成第一等公民：每一份实例带着 schema 版本；加载即走梯子；走不动的格变成显式的未知状态，而不是空气假装没发生。未知状态能指、能被活塞当障碍、能被翻译器以后再认。空气假装，是拆迁。未知，是诚实。

小游戏的对局实例可以声明「不进梯子、可丢」。声明必须是实例政策，不能变成引擎默认。默认仍是居住：读得起昨天。读得起的代价，后文兼容策略会写成伦理账单。本章只要表示法不把账单赖掉——赖掉的形状是：新柜子没有版本字段，于是没有地方挂梯子。

大厅会很快，家会很稳。你会失去同一口令、同一套模组、同一只手从工地走进战场。分家是两个游戏共用一个启动器。启动器很方便。方便不是四格共享的内核。

## 这一章留下什么

- **爱好者**：你家和大厅可以不再挤在同一份硬盘脾气里，但门仍应是两格。一局结束可以丢岛，不能把丢岛做成默认——默认仍是墙比你命长。
- **开发者**：能抄走的是「同一度量、多种实例寿命」：永续实例走稀疏调色板和流式 I/O，对局实例走可丢生命周期；状态可数，组件在栈和账户上，不在每一格空气里。能一起抄走的还有对照表：旧档是职责，未知状态比假空气诚实。抄不走的是二十年 Anvil / LevelDB 梯子，以及大厅已经用进程联邦补上的那一层。你不得从本章带走八叉树或某门语言。你若用两套物理服务两种产品，口令会先死。口令一死，四格产品只剩启动器还在一起。
