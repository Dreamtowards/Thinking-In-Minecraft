> **本章命题**：能读旧档首先是伦理，其次才是工程特性。伦理不是要求「每一个怪癖都必须进内核」，而是两条底线：走兼容，梯子的代价必须写进产品范围；走继承，必须把「不读你的家」印在封面上。假装无代价，就是用特性话术宣布玩家的过去作废。

## 问题

点开一个十年前的世界，启动器先提醒一句：存档来自旧版本，必须转换。墙还在。漏斗还衔着昨天的物品。装过的工业模组变成了未知方块——未知方块占着位置，总好过空气假装什么都没发生。这一声提醒报的不是新内容。它报的是：你的时间要被翻译一遍，而翻译按已经写下的对象计费（机制见[《存储与序列化》](/impl/storage)）。

要回答：能读旧档是伦理还是特性？可被证伪的说法有两个方向。一个方向说：读旧档只是导入向导里的可选项，做不做看工期。另一个方向说：尊重玩家，就必须把 2012 年的某一次通知顺序焊进新内核，否则就是背叛。只要以下现象还存在，这两个说法就都不成立：商店页写明 Java 与 Bedrock 互不兼容；扁平化让箱子里的东西整体换一次护照；封面写着兼容，红石却被清成一门电路课。[^store]

本卷第一部把兼容和继承分成两条路（[《我们到底在重写什么》](/rewrite/what-to-rewrite)）；第二部把旧档写成世界表示法的职责（[《世界表示》](/rewrite/world-rep)），把模拟节奏与结算顺序留给调度章（[《模拟调度》](/rewrite/scheduler)）。本章把账单收进产品范围：梯子怎么挂，红石走哪一条路，命名空间承诺什么，哪些代价必须印在封面上。本章不写转换器源码。它要回答的是：你到底在救谁的时间。

## 玩家的时间存在存档里

关卡游戏的存档是进度指针：第几关、几条命。指针很短，赛季清空在商业上说得通。Minecraft 的存档是世界本身：哪一格是门，哪一只箱子还认你的名字，哪一段红石粉还认某一版的行为怪癖。[《必须保留的设计不变量》](/rewrite/invariants)的第 5 条——世界比引擎活得更久——不是工程偏好。它说的是：居住把时间写成了格子和状态，格子和状态就必须能被下一版引擎认回来。认不回来，居住就塌成一句「请开始新游戏」。开始新游戏对关卡像下一季，对家像拆迁。

所以「能读」不是情怀开关。开关可以关。关开关的人，必须承认自己走的是继承：新引擎认新世界，旧家请停在旧客户端里。这样承认可以很体面，体面的前提是封面诚实。封面印着同一只苦力怕、同一句「你的世界还在」，读起来却是另一份物理——那是用品牌把特性话术做成欺骗。Bedrock 已经示范过商店页上的诚实：两边都叫 Minecraft，存档迁不走。[^store] 诚实没有取消悲剧，诚实让悲剧可以被指出来。

这条伦理还有一截容易被听成无底洞：是不是每一份玩家的奇迹都必须被下一版当成官方 API？不是。遗产章（[《作为文化遗产的 Minecraft》](/history/heritage)）写过：层没有单一主人，模组世界常常打不开。官方的梯子救的是原版对象；第二作者的语义挂在当时的加载器和当时的默契上，默契散了，考古是社区的活。把所有历史版本的 jar 都焊进第一作者的范围，兼容会变成一层无限厚的「假官方」。假官方养不起；养不起之后，往往会反过来连原版那条梯子一起赖掉。

纪律是三条：

- **原版对象必须有梯子。** 方块、物品、实体、玩家、结构、游戏规则——凡是第一作者写下的对象，升级是翻译，不是清空。
- **第二作者对象必须有逃生口。** 读不懂的状态要作为未知方块、未知物品留在原地：能被指认，能继续当障碍，留给以后的翻译器再认。用空气假装什么都没发生，是拆迁。
- **对局实例可以声明不进梯子。** 小游戏大厅可以宣布「每一季重开」，但声明必须是实例自己的政策，不能变成引擎的默认行为——[《世界表示》](/rewrite/world-rep)定下的默认仍是居住：读得起昨天。

Java 的梯子挂在 `DataVersion` 和 DataFixerUpper 上；Bedrock 的柜子是 LevelDB，护照是另一份。[^dfu] 可以合写的句子是：版本字段是伦理的句柄——每一份存档都要答得出「我是哪一版 schema」。必须分写的句子是：两套柜子之上没有一部共同的翻译宪法。宪法不存在，跨产品线的「全兼容」就只是口号，口号进不了产品范围。

<Constraint name="读旧档是伦理不是开关" verdict="地基" chain="时间写成格子 → 升级必须翻译 → 读不起等于宣布作废">
特性可以延期，伦理不能改名叫性能彩蛋。延期必须出现在范围里：这一版读到哪一级，下一级什么时候付。不写出来，就是赖账。
</Constraint>

## 转换器与协议适配

存档的梯子和协议的梯子不是同一根。把它们混成一件事，会出现两种冒充：用「能进服务器」证明「家还在」，或用「世界能打开」证明「模组还活着」。

**世界转换器**认树。它按 schema 阶梯改写已经落盘的对象：数字 ID 收成名字，非结构化的 `tag` 收成组件，世界高度从 256 接到 384。账单按「对象数 × 跨过的级数」算（细账见[《存储与序列化》](/impl/storage)）。还没生成的区块柱子可以晚一点付；箱子里的每一件物品不行。转换器成功的标准不是「新表示更正确」。标准是：玩家能指着某一格说「这还是我那扇门」；指不着的，要变成显式的未知，而不是空气。

**协议适配**认包。Java 的单人游戏内部也跑着一个服务端，接头从进入世界的第一包就开始（[《网络协议》](/impl/protocol)）。ViaVersion 一类翻译器证明：包的形状可以被当成一门语言来翻译。[^via] 必须靠翻译才能互通，恰恰证明这门语言没有稳定方言。生存服不敢更新，原因有时是红石，有时就是这一层：插件把字段焊进了某一版的字节里。适配成功的标准不是「所有客户端都能进所有服务器」。标准是：翻译层被写进产品范围，协议版本号被当成 ABI 一样对待、只涨不裂，而不是让第二作者在每个快照里从零重新找接口。

两条梯子可以共享「版本字段」的精神，不能共享同一张表。存档的 `DataVersion` 和协议版本号常常一起跳，但跳的对象不同。扁平化那一年，落盘的柱子要换护照，进服的包也要换形状。两笔账都按已经写下的时间计。计完账，才允许说「我们做了一次正确的内部重构」。如果重构只改内存表示、不动落盘和接头，那是你自己的仓库卫生。卫生很重要。卫生不是兼容。

数据包是第三条较轻的梯子。`pack_format` 跟着游戏版本涨，旧地图要改文件才能继续用，[《数据包、资源包与数据驱动》](/impl/datapacks)写过这条梯子。轻，是产品上的优待：优待关卡作者，不优待想加新系统的人。轻仍然是账。账不写进范围，教育包和冒险地图就会卡死在某一个号上，而发行说明只写一句「数据驱动更强了」。变强的是旋钮；旋钮拧到底，旧包仍需要一级一级能走的版本号。

```mermaid

  W["世界转换器"] --> T["已经写下的树"]
  P["协议适配"] --> B["正在握手的包"]
  D["数据包号"] --> C["可热更新的内容"]
  T --> S["同一份实例还能指"]
  B --> S
  C --> S
```

<Impl title="梯子必须一级级走">
能跳级的改革看起来现代。被跳过的那几级里，藏着已经住进去的护照。官方的 DataFixerUpper 选择一级一级串着走，不是因为工程师喜欢慢，而是因为跳级会把十年前的箱子收成空气。空气很干净。干净等于宣布过去作废。
</Impl>

Java 与 Bedrock 在这里最不能合写。一边是 Anvil 对 LevelDB，一边是 wiki.vg 记载的协议对 RakNet，内容扩展一边是数据包、一边是行为包。翻译器必须同时懂两套柜子；就算懂了地形映射，仍不懂准连接。跨线迁移可以当研究做，也可以当商业工具卖。把它当成产品承诺——「一个引擎读所有护照」——你买到的是两份测试集，而两份测试集之上没有一部共同的未定义行为宪法（哪些偶然可以抛，[《可以抛弃的历史偶然》](/rewrite/accidents)写过）。

## 红石双路径：仿真层 / 新语义

红石是兼容清单里最贵的一笔，因为墙上的程序没有印刷说明书：这些机器的行为由更新顺序决定，写在一版一版的实现里，而不是任何一页文档里。历史反复演过这一幕——官方照着电路图的「正确」修掉某个怪癖，社区不会道谢，他们会说：一门语言被删了（现象见[《红石：把物理做成编程》](/design/redstone)，实现见[《红石的实现》](/impl/redstone)）。所以本章禁止出现第三条路：假装无代价——内核既干净，旧飞行器照飞，封面还写着「我们更诚实，所以还是 Minecraft」。

**仿真层。** 给旧机器一条「按某一版、某一端的红石规则说话」的模式。这个模式可以慢，可以是可选项，但必须可复述——行为要能被写成文档、被 Wiki 收录、被玩家复核。可复述，Wiki 才能当这一层的说明书。[《模拟调度》](/rewrite/scheduler)已经把「全局恰好 20 刻」降级成默认节奏、把可复述的结算顺序留给内核，正是给这条路径留的台阶。仿真层救的是测试集：准连接、某一端的更新顺序、红石火把的过载熄灭，这些已经被写进教科书的口音。救测试集，不等于把口音焊进新内核。焊进内核，继承之路就变成考古。考古可以很动人，动人的是博物馆；博物馆不是四格产品里的原版体验。

**新语义。** 内核可以没有准连接，只要第 4 条不变量还在：建造所用的那把度量上，仍嵌着一份够脏、够稳、够被误用的因果。新语义允许长出新词；修旧词时承认自己在立法，不假装在擦灰。新语义的成功标准不是「灯更像电」。标准是：玩家还能在格子上发明新词，发明还能被复述。把红石清成一门电路课，编程还在，居住者的编程不在。

两条路径都合法，合法的前提仍然是封面。封面写兼容，仿真层就必须是范围里的产品，而不是周末项目级的插件。封面写继承，新语义可以扔掉 Java 的那套词汇，但必须同时扔掉「你的 2012 年飞行器还在」这句话。两条都写、两条都做满，等于同时背两份测试集。两份都做满还宣称无代价，是把偶然偷渡回内核，再把内核的利息记成诚实。

Java 与 Bedrock 从第一天就不是同一份指令表：准连接只活在一边，两边的更新顺序也不同，同一张原理图在两边的灯可以不一样亮。因此仿真层不能只有一份。走兼容的人必须说清：仿真的是哪一端、哪一版、哪一套通知顺序。说不清，玩家就会把「红石还能亮」听成「我的机器还在」。亮和在，差的是语言。

<Callout type="warning" title="禁止假装无代价">
仿真会慢，会是可选项，会让新调度先通过旧顺序的检验。新语义会让旧程序停下。停下是一种立法。立法可以；用「正确」把「停」遮住不行——那样产品范围里就少了一行：我们删掉了哪些词。
</Callout>

<Alternative title="若把怪癖全部焊进新内核">
飞行器永不会停，你得到考古级的兼容。你失去的是继承：此后任何新的表示、任何新的结算顺序，都要先在某一夜的旧通知顺序下证明旧机器还认得。这场考试永远考不完，时间没法再往前住。尊重玩家时间，不是把时间冻在测试集里。
</Alternative>

## 命名空间的长期兼容

扁平化把冲突从数字 ID 挪到了前缀：`minecraft:` 仍是第一作者的词根，自定义前缀仍是社区口头约定，没有中央登记处——[《数据包、资源包与数据驱动》](/impl/datapacks)写过只在加载时报错的冲突。长期兼容要承诺的不是「永远不改名字」，而是：改名字必须走梯子，梯子必须把旧名字认成翻译，而不是认成另一件东西。

三条纪律。

**不复用。** 一个标识符退休之后，不要把同一字符串立刻发给另一种对象。复用会让旧档箱子里的旧物品摇身变成合法的新物品，比未知更糟——未知至少诚实，复用是伪造护照。

**未知优于空气。** 表示法已经把这句话写成职责；兼容策略要把它写成验收标准：迁移完成之后，指认不出的格必须仍能被活塞当成障碍、被检查器点名、被以后的翻译器再认一次。空气假装没发生，是把第 5 条不变量听成一次导入失败。

**前缀是政治，也是范围。** 两个数据包抢同一个名字、冲突在加载时报错，这是进步。但进步没有取消产权问题。做模组平台这一格产品的，必须把「名字怎么活过版本」写进作者体验：映射词典、弃用警告、示例包（[《脚本与模组的双层》](/rewrite/scripting)）。不写，命名空间就只是一堆字符串。字符串很便宜，便宜的冲突会在十年后的整合包深夜爆炸。

`pack_format` 是内容层的 `DataVersion`。号要涨，旧包要有一条一级级能走的路，或一条明确的「停在此号」。停可以，但停点必须能让地图作者指着说清楚。指不清楚，教育包会在某一学年集体失效，而发行说明只在庆祝新旋钮。

皮肤层——默认材质、背景音乐、主菜单——不在这条梯子上。换皮已经发生了十几年，换皮不是重写。把皮肤当成兼容对象，会把「复制博物馆」听成第 5 条不变量。第 5 条管的是规则对象：格子、状态、因果、扩展面的护照。皮肤留给美术，口音留给仿真层，规则留给内核。

## 把代价写进范围

范围是产品文件，不是心情。走兼容，下面每一行都不是彩蛋：

| 代价 | 不写进范围会怎样 |
| --- | --- |
| 世界转换器按对象计费 | 改革夜把箱子收成空气，却写「内部重构」 |
| 协议翻译或冻结 ABI | 第二作者每个快照都要从零重新找接口，模组比引擎先死 |
| 红石仿真层（含哪一端、哪一版） | 封面写兼容，墙上的程序停了，还说更诚实 |
| 命名空间梯子与未知状态 | 旧名字变成另一件东西，或变成假空气 |
| 对局实例可丢、居住实例默认可读 | 大厅重置删了别人的家，或家的无限柱子拖死大厅 |

走继承，范围里必须出现另一行：**我们不承诺读你的旧档、不承诺旧飞行器还飞、不承诺能进某一版的服务器。** 这一行出现了，继承就是考试允许走的路。不出现，启动器的皮肤会替你说谎。

四格产品矩阵在这里再次分开（[《我们到底在重写什么》](/rewrite/what-to-rewrite)）：原版体验付居住的梯子，模组平台付切口与 schema，服务器平台付协议与法律快照，创作工具付结构文件与检查器读同一份树的承诺。一格付清、三格赖账，仓库的灯仍然是绿的；但住在另外三格里的人会听见：过去作废了，只是作废发生在他们那一层。

「先卖再修」证明过循环可以先于柜子（[《技术债作为产品策略》](/impl/tech-debt)），它没有证明梯子可以永远不进范围。梯子出现之后，每周更新就变成立法窗口。立法窗口的测试集在墙上、在整合包里、在十年没人动过的箱子里。测试集比 CI 大。大，所以贵。贵，也必须写下来。不写下来的贵，会在封面上变成「特性可选」。可选，就是宣布有人的时间不算数。

<Memoir title="Must be converted!">
选世界的屏幕会先喊一句。喊的不是新生物群系，是：你的柱子要换内部布局。点下确认，才是翻译。翻译完，旧文件有时还躺在旁边。官方不敢立刻烧掉上一份文本；不敢，是因为那份文本比这一次更新更珍贵。本章把那一声喊收成范围里的一行：喊过，就要付。不喊就迁，或喊了不付，都是同一类赖账。
</Memoir>

下一章问谁有权重写。梯子是职责，职责不是许可证：能读旧档，不等于能用商标去卖这份阅读；能开源规则，不等于能复印默认资源包。三件东西会在下一章拆开。拆开之前，本章只要钉死一句：伦理在存档里，特性在范围里。范围不写，伦理会变成营销。

## 这一章留下什么

- **爱好者**：你的家不在启动器的皮肤里，它在一份能被下一版认回来的树上。认不回来，无论画面多新，都是在对你说：过去作废了。作废可以，作废必须写在封面上，不能藏在「我们更现代」里。
- **开发者**：能抄走的是三根梯子（世界转换器、协议适配、数据包版本号）和红石双路径（仿真层救测试集，新语义保住可误用）。能一起抄走的还有两条判准：未知优于空气；代价必须出现在范围里。抄不走的是二十年攒下的 fixer 表、两套柜子、以及墙上已经写下的那套指令集。你不得从本章带走「无代价的全兼容」，也不得把读旧档听成一个开关。走兼容，付仿真税；走继承，封面诚实。两条路都正经，正经的前提是别骗那一份已经住过的时间。
