> **本章命题**：开发者能拿走十二条约束，拿不走窗口。抄皮会像。像但不长，是因为原则被当成功能清单，时机、口语和工具链仍留在 2009 到 2012 年那一扇已经关上的门里。

## 问题

每年都有 Minecraft-like。格子在，镐在，第一夜在，最好再加一句「这次我们会做对」。十年后，口语没有换人。[《竞争、模仿与产业影响》](/history/competition) 把这件事写成产业史：像，可以做到；媒介，不行。本章是卷二收束。要回答：开发者到底能拿走什么？

可被证伪的说法是：十二条写清之后，按表施工就能长出下一个 Minecraft。只要还看见按表做出的体素生存停在「像」，Roblox 长成另一代人的入口，而方块口语仍叫原来那个名字，这句话就不成立。原则可迁移。窗口不可复制。两者必须分开写。混在一起，开工令会写错对象。

卷四才会把偶然从本质里剥开，并禁止把「再做一遍」写成开工令。本章不代答语言和架构。本章只把卷二的尺收成可带走的十二条、抄不走的条件、以及三种把皮抄走、把骨留下的机制类型。

## 为什么 Minecraft-like 总是「像但不长」

像，因为皮好抄。一米格的外观、第一人称、挖和放、第一夜、合成表，都能进预告片。长，需要另外三样：空隙被一代人住过，误用被收成口语和 API，再开发有河。皮是渲染和循环。骨是约束怎么空、怎么硬、怎么把枚举权交出去。

描摹最常见的动作，是把 Cave Game 减掉的东西加回去：更明确的目标、更密的模拟、更像作者关卡的进程、更专业的编辑器。[《从 Infiniminer 到 Cave Game》](/history/infiniminer) 加回去之后，得到的是一款更像「游戏」的游戏。这不丢脸。丢脸的是还把它叫做下一个 Minecraft——那个词指的是可居住、可误用、可再开发的规则，不是一箱更好的系统。

Java 的模组河和 Bedrock 的货架还常被画成同一个座位。抄海报的人把两个 Minecraft 当成一个冠军。要长，先要说清你继承的是哪一份合同。说不清，只是在抢一张被说混了的皮。

所以「像但不长」不是执行力不足。是对象认错。认错之后，十二条会被听成功能清单：我们也有体素，我们也有生存，我们也有 UGC。清单能做出像。骨在「不加」里：不加建造模式，不加技能树，不把目标写回说明书，不把完整文明收成默认，不把编辑器叫做游戏模式。不加，预告片难看。难看是深度的价格。

谱系对照能把这句话钉死。Terraria 承认父亲，长成冒险；Vintage Story 从模组出走，带走深度，留下的空洞变窄；Luanti 证明引擎可以开源，开源不等于口语。[^ars-clones] [^vs] [^luanti] 它们可以很好玩。好玩不自动等于占住那一个已经被家庭说会的座位。描摹停在「像」，是因为抄走了格子和第一夜，把 Cave Game 减掉的目标、密度和编辑器加了回去。加回去，更像游戏。更像游戏，空隙更窄。空隙一窄，十二条里最贵的那几条——外包、可误用、默认仍空——就先死。

## 十二条原则

十二条是核，不是口号。表述可以改，核不能换。每一条都能在前十五章找到证伪句。这里只写：能抄走的那一句，以及一抄就变味的那一侧。不要把十二条做成十二个组件。它们是一张合同。

**1. 最小动词，深度来自组合。** 看、走、挖、放、合成、攻击、使用，已经够用。工具放大动词，不更换作者。深度不写在技能页上，写在格子上的组合。[《最小动词集与手感》](/design/verbs-feel) 抄成连招表或建造模式，组合要跨过一道门。

**2. 世界即库存。** 地上的方块和背包里的方块是同一种对象的两种位置。水进桶、桶放回世界，仍是这一句。[《体素作为设计原语》](/design/voxel-primitive) 抄成「舞台上的道具」，搬运会变成摆设。

**3. 目标外包。** 游戏提供动词和节奏，玩家提供叙事和终局。迷茫可以是好评。[《留白、涌现与玩家作者性》](/design/emergence) 抄成任务栏和通行证，居住塌成消费。

**4. 可误用系统。** 留下物理和因果，不留下玩法清单。官方要是按「正确行为」修掉一种用法，社区觉得游戏坏了，误用才成立。[《红石：把物理做成编程》](/design/redstone) 抄成脚本机关包，机器变少。

**5. 成长附着于物。** 强弱能丢掉、能交给刚进来的人、能放回世界。人几乎透明。[《合成、物品与库存》](/design/crafting-inventory) 抄成天赋树，口述从「用这把镐」变成「你点了哪一系」。

**6. 程序内容合同 = 可探索。** 生成器给可去的地方，不给必走的关。「找不到」可以是好下午。[《世界生成即内容生产》](/design/worldgen) 抄成保底结构和收集清单，探索变成打卡。

**7. 约束即深度；不真实可以更好玩。** 沙掉石不掉、水占格、信号十五档，是可数的法律，不是没做完的真物理。[《约束即深度》](/design/constraints) 抄成连续模拟，口语变贵，误用变窄。

**8. 模式是权限，不是四个游戏。** 生存、创造、冒险、旁观拧的是稀缺、牙齿、改写权、可见性；世界还是那一份。创造必须寄生生存的尺。[《创造模式不是关卡编辑器》](/design/creative-mode) 抄成四个子系统或离线编辑器，家变成文件。

**9. 社会契约是设计的一半。** 缺省公共；引擎给旋钮，插件写法典，不成文宪法真正生效。单人是延迟的多人。[《多人是默认状态》](/design/multiplayer) [《规则由谁制定》](/design/who-makes-rules) 抄成「联机开关」，家具的朝向会丢。

**10. 模组 / 数据驱动是第一公民。** 第二条作者席不是周边。数据层收关卡作者，程序层加动词；完整文明对选择负责，默认继续空。[《模组作为设计方法》](/design/mods-as-method) 抄成创意工坊抽成或「官方工业包」，主语会换。

**11. 世界比引擎活得更久。** 存档、种子、模组世界和服务器法律，寿命长过一次客户端更新。兼容是对玩家时间的伦理。[《作为文化遗产的 Minecraft》](/history/heritage) 抄成赛季清空，居住塌成通行证。卷三会把这句话写成格式与迁移；本章只要设计合同：世界不是可以换季的关卡包。

**12. 新系统必须增加动词，不增加菜单。** 下一刀雇的是那只手，还是界面与图鉴。停手不是冻结，是保护默认里的空隙。[《约束即深度》](/design/constraints) 抄成「每年一个主题内容包」，满是债。

<Constraint name="十二条是合同不是清单" verdict="地基" chain="能抄的约束 → 交出去的枚举权 → 默认仍空">
十二条要一起住。抽走外包，留下体素，得到主题乐园。抽走可误用，留下生存，得到第一夜循环。抽走再开发，留下格子，得到每年都有的那一页。
</Constraint>

Java 与 Bedrock 让同一条原则长出两种口音：红石因果、战斗手感、插件河对货架、创造会不会被虚空杀死。原则合写。口音分写。抄的人若把两边听成一个冠军，会抄到一张被说混了的海报。

## 不可复制条件

原则是尺。条件是历史里的一次性对齐。尺可带走。对齐抄不走。[《竞争、模仿与产业影响》](/history/competition) 已经钉过窗口。卷二要补的是：即使你把十二条都做对，仍可能只做出「像」。像，因为尺对了。不长，因为窗口关了。

**时机。** 2009 到 2012，独立游戏还能靠论坛和付费 Alpha 活成共同作者；YouTube 正把实况收成说明书。[《Alpha 的公开开发》](/history/alpha) 窗口关了。今天再公开施工，面对的是商店算法、已经会说方块的一代人。他们不会把你的 Alpha 听成创世。他们会听成又一个方块游戏。

**媒介窗口。** 影像、课室、家庭把格子教成通用语。通用语一旦教完，座位就被占了。你可以做更好的物理、更美的光、更干净的 API。你很难让家长在说「孩子在玩方块」时，指的是你。微软 2014 年买的是这个入口，不是又一种生存循环。[《微软收购》](/history/acquisition)

**工具链。** Forge、Bukkit、Fabric、数据包、二十年把断裂当成生存条件的河。发一张 SDK 不等于有河。Luanti 证明引擎可以开源。开源不等于口语。没有那条被版本年年打断仍有人续命的河，再开发只是功能列表上的「支持模组」。

**未定义行为被收编为 API。** 准连接、更新顺序、碰撞的小数、1.8 的连点，社区当法律用。[《红石：把物理做成编程》](/design/redstone) 你无法在第一天设计出「将被误用的那一页」。那一页是被住过之后长出来的。清成正确，灯老实；留下，像不专业。不专业是资产。资产需要时间，不需要第一版就写进设计文档。

**买断标本。** 一次购买、商品停在门口，让礼物河在伦理上说得通。[《收入结构》](/history/revenue) 没有标本，抽成是正经生意。有了标本，抽成像背叛。性格抄不像。你可以宣布买断。你抄不走那句已经被超过三亿份入场券听成性格的话。

这些条件与十二条必须分栏。混进原则里，会把运气写成方法论，或把方法论写成宿命。方法论是：你可以做可居住的规则。宿命是：你很难再占那一个已经被说会的儿童语言座位。两边都真。坐错栏，开工令会疯。

卷四将把十二条里哪些是不变量、哪些是 2009 年的偶然再剥一层。本章不代剥。能说的只有：剥的时候，不要把窗口误当成原则，也不要把原则误当成只要换语言就能再生的窗口。

## 反面教材：抄了皮、丢了骨

至少三种机制类型。不是点名某款游戏必须失败。是指出：皮抄对了、骨抄反了，会长成什么。点名只为把类型钉死。

**把目标加回去。** 任务标记、技能树、季节通行证、保底的关键结构、必做的第二幕。皮还是格子和第一夜。骨换成作者关卡。迷茫从好评变成漏做的引导。生存合成浪潮里很多「第一夜更狠」的游戏走这条路：循环更像游戏，空隙更窄。Terraria 承认父亲并长成冒险，那是谱系。把冒险听成「修正版 Minecraft」，是认错对象。

**把世界做成文件，把工具做成编辑器。** 皮还是体素。骨换成 Studio：造是专业姿势，玩是消费姿势。创造一旦离开身体，家变成导出物。Bedrock 官方编辑器肯说那不是游戏模式，是因为它看见了这条线。跨过线，你会得到更强的内容管线。管线很值钱。管线不是那只边走边改的手。

**把再开发收成商城。** 皮还是 UGC。骨换成平台：世界是 SKU，工具在编辑器里，分成在收银台。Roblox 把这条路走完，诚实而且能长生态。[^rb-rdc] 它赢的是平台的座位，不是 Minecraft 的座位。Marketplace 是局部实验。整条走完，对象变了。[《全书的命题》](/prelude/thesis)

**把战斗做成核心循环。** 皮还是第一人称和碰撞箱。骨换成动作游戏：冷却、连招、赛季武器、必须学会的第二套节拍。Java 1.9 已经把这件事做成过一次身份撕裂；Bedrock 长期不跟，两边都还在玩，说明「更像战斗」不是唯一的现代。[《生物、战斗与威胁》](/design/mobs-combat) 威胁足够用，是为了催你回家点灯。威胁一旦雇走整晚，挖和放会变成过场。过场可以很好看。过场不是这套规则的主语。

四种可以叠。叠完仍可以很好玩。好玩不自动等于长成媒介。媒介要三条骨同时在：目标仍外包，世界仍是可住的库存，作者席仍不能被一张覆盖全部的抽成单收走。丢任何一条，皮可以继续方块。骨已经换了。战斗若再把动词从建造里雇走，皮会更像「游戏」。主语会换。

<Alternative title="若十二条当功能清单施工">
体素渲染 + 生存循环 + UGC 工坊 + 战斗更新 + 赛季。预告片会像。三个月后，玩家会问「我该干什么」，你会补任务栏；造得慢，你会补编辑器；创作者要吃饭，你会补分成。每一步都合理。合理走完，你得到一款当代沙盒。当代沙盒可以赢。它很难再叫这本书里的那个词。词指的是规则，不是标签。
</Alternative>

## 卷二结语

卷二从一米格写到停手尺。路径不短。收束可以短。

**Minecraft 不是被消费的关卡，是一套允许被居住、误用、再开发的规则。** 序章写下这句话。卷一用产业与史实证明它如何变成媒介。卷二证明它为何有效：深度来自极少数规则在格子上的组合爆炸；目标外包给玩家；系统做成可被误用的工具；模式是权限；社会契约是设计的一半；完整文明对选择负责，默认必须空着一块。

有效不是永恒。有效寄生在约束上。约束被现代化填满、被真物理还清、被菜单雇佣，有效会变成「我们曾经空过」。空过，口语还在一段时间。口语在、机器不转，媒介就开始只剩 IP。卷一的遗产章写过保存。卷二补的是：保存之前，先别拆梁。

开发者能拿走十二条。拿不走窗口，拿不走已经被收成 API 的不真实，拿不走两个 Minecraft 不是两个皮肤这件事。能做的，是认清对象：你要做可居住的规则，还是可上架的平台，还是更像游戏的游戏。三条路都能长生态。三条路不是同一个冠军。把「下一个 Minecraft」写成开工令的人，坐错了路。

卷三要把这些规则拖进规模：区块、刻、协议、双端、模组架构。拖的时候会碰到债。债与自由同源——那是下一卷的命题。卷四会考试：哪些是偶然。考试不是开工。卷二交卷的是尺。尺还在，空还在，那只手还抓得住格子，这本书的对象就还在。

## 这一章留下什么

- **爱好者**：你觉得「像 Minecraft」的那些游戏，往往抄走了格子和第一夜。你真正住进去的那些晚上——不知道干什么、却给自己派了活——抄不走。那是空隙，不是功能。
- **开发者**：能抄走的是十二条合同：最小动词、世界即库存、目标外包、可误用、成长在物上、可探索的生成、不真实的可数法律、模式即权限、社会契约、再开发为第一公民、世界长过引擎、新系统加手不加菜单。抄不走的是 2009–2012 的窗口、二十年工具链、已被收成 API 的未定义行为、以及已经被家庭说会的入口。你若把十二条当功能清单，会加入每年都有的那一页。你若做成平台，赢的是另一个座位。两个座位都真。对象认清，尺才有用。
