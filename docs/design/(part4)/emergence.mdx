> **本章命题**：涌现不是幸运事故。格子、七个动词和故意留空的目标叠在一起，玩法必然从玩家手里长出来。官方若把「你该干什么」写回说明书，涌现会退化成彩蛋，作者性会退化成对发放目标的感激。

## 问题

「我不知道这游戏要干什么。」这句话在别的游戏里是差评。在这里，它可以是好评。不知道，是因为没有人发给你一张必做清单。知道的人，是你自己：今晚盖屋顶，明天挖到岩浆，后天把种子发给朋友。叙事是你的。游戏只提供动词和一份会催你、却不指定你该成为谁的世界。

上一章把收编停在「加手不加文明」。[^prev] 文明留在院子里，正是为了让默认继续空着。空着不是还没做完的内容包，而是本章要分析的地基。本章要回答：涌现是意外，还是必然？可被证伪的说法是：红石计算机、冰道、刷怪塔、一周目生存系列，都是官方藏在关卡里的高级玩法，社区只是先发现了。只要还存在一次「修复」，让半个社区觉得游戏坏了、而不是更诚实了——就像红石社区对待准连接那样（见[《红石：把物理做成编程》](/design/redstone)）——这句话就不成立。

玩具对游戏的旧官司，也在这里结束。不是因为它更像玩具，或更像游戏。是因为它把玩具的「没有指定目标」和游戏的「硬约束」焊在同一套格子上。焊完，玩家就是作者。作者权不只盖在房子上。红石、地图、影像，是同一只手的四个出口。

## 「我不知道这游戏要干什么」为何可以是好评

关卡游戏把「干什么」写在任务栏上。写清楚，是一种礼貌：你花钱，我带路。Minecraft 的礼貌反过来：一旦由游戏带路，住就会塌成通关——通关有句号，住没有（终局为什么必须空着，见[《维度、进度与终局》](/design/dimensions-endgame)）。「通关 Minecraft」是一句空话，因为不存在那最后一步，能把你盖好的房子和修好的机器收进一份致谢名单。这句空话对外人有用，它给宣传提供一个高潮；但高潮不能当宪法——游戏内部的结构并不围绕它运转。

于是出现一种听起来像迷茫的赞美。第一晚之后，没有人告诉你「现在去解锁第二幕」。饥饿还在催，黑夜还在来，岩浆还烫。催你的力量只是把手从闲置里拽回去，不把你变成某一种英雄——生存的节奏本身在供给意义，而不供给剧本，这一点[《生存作为意义机器》](/design/survival)已经论证过。迷茫于是成了材料。材料足够硬，你就会给自己派任务：这座山要挖通，这片海要填，这台机器要亮。派完，游戏看起来很满。满的是你写的。官方写的仍是那一套穷动词。

进度系统是建议，不是强制。Java 的进度按世界存取，像一份可折叠的清单：不去做「冒险时间」那一页，夜晚也不会被没收——进度为什么留得出这个空位，[《命令、数据包与地图》](/design/commands-datapacks)写过。Bedrock 的成就跟账号和平台走，更像挂在墙上的奖章，同样不拦路。建议一密，迷茫会少。少到某一天，打开世界先看下一格该勾哪一项，好评就会从「我不知道要干什么」变成「清单还没做完」。清单还没做完，是另一款游戏的好评。

影像把迷茫教成方法。有人把「第一天不知道干什么」拍成系列的第一集，后面九十集都是自己找事做——这种授权如何被拍成一整代人的默认姿势，[《影像、教育与一代人的媒介》](/history/media-education)写过。观众学会的不是攻略，是授权：你可以给自己派活。授权能传播，因为格子能说，失败能指。迷茫若只是情绪，拍不出来。迷茫是设计位置：目标不在软件里。

可被证伪的说法是：玩家其实讨厌迷茫，官方只是还没把新手引导做完；做完之后居住会更友好，而不是更稀薄。只要还存在关掉进度、不打龙、把家建成十年的存档，而当事人不觉得游戏坏了，这句话就不成立。引导可以有。引导若变成必走的第二幕，迷茫就从好评变成 bug。

## 目标外包

外包不是放任。放任是没有约束。外包是：动词和物理由官方提供，叙事和终局由玩家提供。官方若连叙事一起做，你得到的是主题乐园。主题乐园可以很好。主题乐园的「下一步」在作者手里。

七个动词已经够短（[《最小动词集与手感》](/design/verbs-feel)）。短，是为了让复杂的输出发生在世界上，而不是发生在技能页上。成长附着于物：镐可以丢进岩浆，也可以交给刚进服的人（机制见[《合成、物品与库存》](/design/crafting-inventory)），人本身几乎透明。透明，叙事才不会被职业锁死。你今晚是矿工，明天是建筑师，后天是服主。身份是你派的，不是天赋树派的。

生成器也在外包。程序内容的合同是可探索，不是可通关：错过一座林地府邸，仍可能是好下午——这份合同，[《世界生成即内容生产》](/design/worldgen)里已经写过。若每个关键结构都保底刷在路上，探索会变成收集。收集是作者把目标收回去的一种方式：你不是不知道干什么，你是还没找齐。

服务器把外包做成政体。创造、生存、小游戏，三种社会共用同一套动词，却不共用「今晚干什么」——服务器如何各自立法，[《服务器即新游戏》](/history/servers)写过。Hypixel 把目标写成再来一局。十人生存服把目标写成今晚谁上线。2b2t 把目标写成还能不能离开出生点。三种目标都不是 Mojang 写进客户端的。外包成功的证据，是同一张门票通向无数个游戏。

<Constraint name="目标不在软件里" verdict="地基" chain="短动词 → 硬物理 → 玩家派活">
官方提供能指、能挖、能放、能疼的世界。叙事若写回说明书，动词会变成过场。能抄的是外包；抄不走的是：一代人已经习惯自己给自己派活，你一发任务栏，他们会觉得被降职。
</Constraint>

<Alternative title="若把目标写回说明书">
主线、季节通行证、必做的第二幕、保底的关键结构。你得到更好卖的「内容」、更低的退款率、家长听得懂的进度。你失去的是十年存档里那些没有通关价值的树和箱子。居住会塌成消费。消费可以很赚钱。赚钱的对象，不再是这本书写的那个。
</Alternative>

## 涌现 = 约束下的必然

涌现常被写成奇迹：「没想到还能这样玩。」奇迹叙事对官方客气，对设计不公平。真正的结构是：约束够硬、空隙够空，组合必然爆炸。爆炸看起来像意外，是因为作者没有枚举。没有枚举，不等于没有原因——Mojang 的设计文档里没有「刷怪塔」这一条，它是「怪物在黑暗的格子里出现」加上「出生范围可以被玩家改造」的必然推论。文档没写，不等于规则没写。

硬的那一侧：一米格、可破坏、可放置、可计数（[《体素作为设计原语》](/design/voxel-primitive)）。水按格流，沙会掉，信号按格衰减，活塞推格。人在格子里连续地走。失败显形：灯没亮，人人能指数哪一格。显形，才有共同阅读。阅读，才有超出说明书的用法。

空的那一侧：没有建造模式把造锁门外，没有技能树把人锁进职业，没有主线把今晚锁进第二幕。红石不教编程。官方留下物理。玩家把物理读成逻辑，再误用成计算机。水电梯、冰道、刷怪塔、船的碰撞、凋灵破家，都是同一类必然：规则比作者的想象力更硬，也更空。硬，保证因果可复述。空，保证因果不必指向某一关。

所以涌现不是「系统聪明到超出设计」。涌现是设计把枚举权交出去。交出去之后，官方若按「正确信号」把准连接和更新顺序清干净，社区会认为游戏坏了，而不是更诚实了——这正是红石章的那个证伪装置（[《红石：把物理做成编程》](/design/redstone)）。被当成 API 的未定义行为，已经是约束的一部分。修掉它，不是擦掉意外，是拆掉必然里的一根梁。

Java 与 Bedrock 把这句话拆成两套必然。准连接只活在 Java 一边；水流、活塞时序、碰撞的小数也不共用一份。涌现无法完整跨产品线传播，不是社区不够努力，是约束分叉了。分叉的债，卷一写过。本章只要承认：必然寄生在具体约束上。换一套流体，水电梯会换一种盖法，或者盖不出来。盖不出来，不是涌现消失，是这一种涌现的梁断了。

可被证伪的说法是：只要系统够复杂，涌现会自己来，约束是次要的。复杂而没有空隙的模拟，会把玩家训成操作员。Vintage Story 这类把模拟做得更密的出走者，把深度带走的同时，也把空隙收窄了（产业对照见[《竞争、模仿与产业影响》](/history/competition)）。密可以很好玩；但密起来之后，「我不知道要干什么」会变少。变少，涌现就从必然变成彩蛋：只留给读完百科的人。Minecraft 的涌现发生在第一晚之后的普通手里，正因为约束穷、空隙大。

## 对照：不像的那一点

对照不是评测谁更好。对照是指出：三款也被拿来当「开放」样本的游戏，各在哪一点上不像 Minecraft。不像，涌现的形状就不同。

**《塞尔达传说：旷野之息》** 把物理交给玩家：火、风、金属、化学，组合能超出关卡作者的枚举。它像在涌现。不像的那一点是：**世界不是库存**。山搬不进背包，神庙是作者写好的遭遇，克洛格种子是内容。你在物理里发明解法，你不能把海拉鲁挖回家当仓库。Minecraft 的涌现发生在「地上的方块和背包里的方块是同一种对象」之后。没有这一句，误用停在解谜，住不进搬运。[^botw]

**《动物森友会》** 把日常和生活感做得很满：邻里、季节、收集、布置。它像在居住。不像的那一点是：**地形不是可任意改写的物理，造和玩也不完全是同一只手**。岛是给定的舞台，地形改造是游戏发放的权限，不是那种把世界当库存、挖下来就搬走的搬运。朋友来访是社交事件。Minecraft 的朋友来访，是另一具身体走进同一份可破坏的格子。社交可以很像。格子能不能被你整座搬走，不像。[^acnh]

**《Dwarf Fortress》** 把模拟做得很密：地质、历史、情绪、液体、遗忘兽。目标也常常外包给玩家。它像在涌现。不像的那一点是：**尺度不是那只一米的手**。你管理的是要塞和人口，不是第一人称里对准的那一格。玩家讲述它时，说的是「这个矮人」「这条河流」，很少是「再往左三格」。密带来另一种必然：故事从模拟里长出来。Minecraft 的必然从穷约束里长出来。穷，才能被儿童和影像用同一把尺学会。密，需要另一代人的阅读能力。[^df]

三款都不该被写成失败的 Minecraft。它们各有自己的必然。把它们写成 Minecraft-like，会看丢那一点不像——而那一点，往往正是涌现寄生的梁。

## 同一权利：建造 / 红石 / 地图 / 影像

作者性常被收成「会盖房子」。房子只是出口之一。同一套约束，至少长出四种被承认的作者权。承认它们是同一种权利，才不会把红石说成漏洞、把地图说成 DLC、把影像说成周边。

**建造**改地形。家、纪念碑、超平坦上的城市、创造服出生点的展览。改完还能走。走得了，才是居住，不是渲染图。

**红石**改因果。灯、门、时钟、飞行器、计算机。官方不教，教材是社区写的。写教材的人，是第二作者——即使他们从没碰过 jar 文件。

**地图**改遭遇。冒险、CTM、解谜、RPG 图、小游戏大厅。寄生同一物理，用冒险权限把挖锁上（机制见[《命令、数据包与地图》](/design/commands-datapacks)）。关卡设计师被请回原版，仍是玩家作者性：作者席在世界里，不在公司排期表上。

**影像**改口语。教程、一周目、梦核、延时、音乐。影像把迷茫教成方法，把格子教成通用语。拍的人没有改存档，改的是下一批人以为 Minecraft 长什么样。那也是作者权。没有这条权，居住和误用传不出去。

时间轴上的编辑器和地形工具是同类。Replay、动画模组让你在时间里选区：摄像机、关键帧、回放。[^replay] 它们不该被写成「不是真玩」。如果「真玩」只承认第一人称的当下，延时摄影和红石教学都会被贬成外围。外围叙事会看错的是：这些工具仍要写回同一份世界、同一套格，才仍然是 Minecraft 的作者权。写不回去，它们就毕业成别的软件——那条边界，与「把创造做成离线视口」是同一条（[《创造模式不是关卡编辑器》](/design/creative-mode)）。

VRChat 提供另一种不像。那边也可以住、也可以造。造常常发生在 Unity 里，住发生在已经编译好的房间里。住和造不共用运行时。Minecraft 坚持共用：工地就是家，红石就在墙上，地图就在这份存档里。共用让冲突可见，也让作者权便宜。分开会更专业。专业不是这套权利的形状。[^vrc]

<Note>
四种出口可以叠在同一个人身上：盖一座机房，用红石让它亮，把世界存成地图发给别人，再拍成教程。叠，不是四款游戏。叠，是同一只手。
</Note>

可被证伪的说法是：只有改 jar 的人才算作者，盖房子和拍视频只是玩。只要教程、地图站和创造服仍在定义「Minecraft 能做什么」，这句话就不成立。作者性是权利，不是职称。权利来自约束把枚举权交了出去。

下一章把空隙写成必须保住的东西。空隙看起来像还没做完。做完，必然会少。设计者何时该停手，有判据，不能只凭口味。

## 这一章留下什么

- **爱好者**：你不知道要干什么，往往是这套规则在正常工作。房子、机器、地图、视频，不是四种爱好，是同一种作者权的四个出口。官方没写的那一页，本来就该由你写。
- **开发者**：能抄走的是「目标外包 + 硬约束」——短动词、可指的物理、不写第二幕，涌现会从普通手里长出来，不必靠奇迹。抄不走的是：一代人已经把迷茫听成授权，把未定义行为收成 API。你若把清单写回软件，会得到更像游戏的游戏，失去必然。必然不是意外。必然是你肯把枚举权交出去。
