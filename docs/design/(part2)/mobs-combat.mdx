> **本章命题**：战斗不够好，却足够用。威胁的职责是驱动建造、移动和回家，不是成为动作游戏。把它做成核心循环，格子上的那只手就得让位给连招表。

## 问题

有人把 Minecraft 的战斗说成笑话：冷却尴尬，弓很素，Boss 花哨但不像讨伐。笑话听过之后，同一批人仍在挖、仍在跑、仍在为夜里那一声苦力怕回头。战斗若真是笑话，回头不会那么稳。

本章要问：为什么战斗不够好却足够用？可被证伪的说法是：玩家其实一直在等一款「真正的战斗更新」，做完之后 Minecraft 会更好，而不是更不像。只要还存在 1.9 把社区撕成两半、而 Bedrock 长期不跟这套手感、两边都还在玩的经验，这句话就不成立（两条线的分账见[《两条产品线：Java 与 Bedrock》](/history/java-bedrock)）。

不要武器数值表。要写威胁在整台机器里的职位：它催谁，不催谁。

## 攻击冷却为什么撕裂社区

Java 1.9 把近战收成冷却：伤害按蓄力算，没蓄满的挥砍只剩零头，连点不再滚出成倍的输出；满蓄一击附带范围横扫；盾从「按住剑格挡」改成独立装备，剑的格挡被移走。喜欢的人得到更像战斗的战斗——出手有重量，抢手速变成抢时机。不喜欢的人把 1.8 做成一种政治：连点才是这只手。[^combat] Bedrock 长期更接近冷却前的手感。于是有了这样一本「护照」：看还能不能连点，就知道你在哪条产品线上。

撕裂有一个精确的着力点：左键。对着方块，左键是挖，连点效率不受影响；对着生物，左键是打，连点突然亏伤害。同一个键、两套经济学，冷却只改了其中一套。挖矿的手被留着，战斗的手被改了——所以吵的从来不是「战斗更新好不好」，是「我的另一只手被换掉了」。满蓄横扫是给「一对多」的补偿：冷却惩罚手速，横扫奖励站位——单挑与群战从此是两门手艺。

撕裂还证明战斗被当成身份，不是补丁。身份会撕裂，是因为战斗从来不是核心循环，却被很多人用核心循环的标准来审。用动作游戏的标准看，冷却是现代化。用「同一只手」的标准看，冷却是把攻击从连着挖和放的节奏里摘出去，单独做一小节拍器。摘出去，PvP 变了，打块还在，挖还在。变的是那一小节拍。整台机器没改名。没改名，有人就觉得被背叛：我不是来打动作游戏的。也有人觉得被成全：我终于能打了。两种人认的不是同一份职位描述。服务器把这份分歧做成了菜单：想打连点，有把版本停在 1.8 的竞技服；想打时机，有 1.9 之后的服。十年过去，两种服都还开着。十年里，战斗还在小修——盾的时序、斧对盾的克制——但没人等来「撤销 1.9」。回不去的手感，后来成了传统。

动词章把攻击列为七个动词之一，并且说工具只放大动词、不更换动词（[《最小动词集与手感》](/design/verbs-feel)）。冷却改的是放大器的时间形状，不是动词表。时间形状足以分裂社区。分裂本身说明：足够用的东西一旦被当成主菜来炒，油温会过头。

<Note>
Java 的冷却和横扫、Bedrock 的连点，合不成一句「Minecraft 的手感」。能合写的是职位：攻击存在，但不雇佣整晚的注意力。
</Note>

## 节奏装置：黑夜、苦力怕、亡灵

怪物不是图鉴主角。主角是你盖的那堵墙。黑夜把光线收走，敌对生成跟黑暗走——你插下的每一支火把，都是从黑暗手里买回的一格安全。每一种怪再负责一格规则：僵尸慢、成群，困难难度下会动手砸门，把「门」从装饰变成防线；骷髅隔着十几格放箭，教你第一课——直线冲锋会死，掩体才有价值；苦力怕不出声地贴上来，嘶声一响，倒计时已经开始；末影人立在那里，你一盯着它看，它先动手——注视本身就是挑衅。蜘蛛白天中立，天一黑就翻脸；苦力怕怕猫，于是养猫成了城墙的一部分。村庄还自养卫兵：铁傀儡巡村，袭击来了先顶上——你修你的墙，村子自己还有一层。亡灵在白天烧，把太阳变成排程，夜里攒的仗，天亮自动清场。这些都是[《生存作为意义机器》](/design/survival)里那台生存节拍器的鼓点。Java 版还有「区域难度」这层暗账：一片地方住得越久，夜里的怪越凶——威胁连居住时间都记账。

鼓点后来还在加密。村庄与掠夺把节奏装置升级成事件：你带着不祥之兆回村，袭击上门，村庄要墙、要钟、要铁傀儡——威胁第一次有了「上门讨债」的形状。连着几天不睡，天上开始掉幻翼，游戏把「睡觉」从安全的仪式变成强制节拍，晚睡有账单。

鼓点驱动建造和移动。你为了灯而挖矿，为了床而养羊，为了别被炸而把走廊做成两格，为了白天赶路而看天空。威胁若消失，和平仍能玩，只是少一轨鼓点——和平模式就是整条鼓轨的静音键，静音之后游戏照样转，这恰是证据：威胁的职位是节奏，不是主角。威胁若变成核心循环，你就会为了打而打，墙变成掩体系统，挖变成刷材料。刷材料的动作游戏很多。它们不需要苦力怕认得你的房子。

苦力怕认得房子，是因为爆炸改地形。这条咬合紧到官方给了开关：把生物破坏地形关掉，苦力怕只伤人、不动土——鼓点还在，牙被拔了。开关的存在，反证了默认值才是设计。疼可以在人身上，记忆在地上。打块作为 PvP 手段，也是这口咬合——建造动词临时借给伤害。借得到，因为没有战斗模式把建造锁门外。

## Boss 克制：龙、凋灵、监守者的不同职责

官方 Boss 很少，而且职责分开。不要把它们读成「三个关卡」。

**龙**是仪式。末地、爆炸、出口传送门、致谢字幕。龙撞过的方块会碎，它飞过哪里，战场就在哪里被改写；高塔上的末影水晶替它回血，拔掉水晶，仪式才真正开始——连 Boss 战都先是地形战。打完结算一笔全游戏最大方的经验，留下一颗只能得到一次的蛋。仪式给外人一个「通关」。打完，世界不收回，出口的门常开着，末地水晶甚至能把龙请回来、把仪式再办一次——能重开的仪式，不是消耗的关卡。职责是给产品一个可纪念的节点，不是给循环一个句号。下一章（[《维度、进度与终局》](/design/dimensions-endgame)）写终局。

**凋灵**是可选基础设施。召唤要你自己动手：几格灵魂沙或灵魂土，摆上三颗凋灵骷髅的头。搭出来的 Boss，选在你自己选的地址开战；它见活物就打，连你的农场也拆——一台需要先圈好场地的工厂。打完掉下界之星，星能点亮信标，信标给一片被你圈起来的强。它不像拦路的门。它像一台你决定要不要造的工厂的钥匙。克制在于：不打也能活，打了得到的是地址上的增益，不是新职业。

**监守者**是反战斗。深暗之域里，幽匿尖啸体听声音：你吵得够多、够久，它就把监守者从地里召出来。监守者不靠眼睛，靠振动找人；近战极重，还能隔空发出一道音波；黑暗一层一层压下来，让你躲无可躲。而它几乎不掉战利品——打赢了，奖品是「你可以继续安静走路了」。你不该打。职责是让深处的城市不是另一场讨伐，是另一种走法。做成讨伐，监守者就只是更大的僵尸。做成「请安静」，威胁才再次驱动移动而不是连招。

克制的总原则：Boss 可以很响，但不能雇佣游戏剩下的时间。一旦雇佣，生成、合成、红石都会退化成 Boss 战前的刷材料流程。刷材料是动作 RPG 的正确，不是这台机器的正确。

<Constraint name="威胁驱动建造" verdict="地基" chain="黑暗 / 爆炸 / 稀有 Boss → 回家、点灯、移动 → 不成为主循环">
怪物的成功，看它有没有让你改地形或改路线。看它有没有让你打开技能树，是看错了栏目。
</Constraint>

## PvP 作为社区竞技

官方没把 Minecraft 做成竞技核心。社区做成了，而且做成了好几套兵器谱。1.8 流派练药水、钓鱼竿拉人、连点与走位；1.9 之后的流派练蓄力时机、斧破盾、末影水晶——水晶流派把「放方块、打水晶」练成秒级手艺，人称打块；服务器再把床战、空岛战争做成脱离生存的比赛项目。[^pvp] 竞技没有一种自带引擎：格子让掩体可造、失败可指、重置可脚本。成立之后，它仍寄生在原版动词上：看、走、挖、放、打。搭方块是掩体动作，挖方块是拆掩体——建造动词直接借给伤害。还有人把自然回血关掉办比赛，UHC 让一场对战变成资源战——竞技连血瓶经济学都自己写。寄生一拆——禁止挖、禁止放——就变成另一种射击。

所以 PvP 不是正作失败的证据，是正作够薄的证据。薄到能被写成比赛，而且不止写成一个流派。比赛可以很严肃。严肃也不等于官方该把「继续调战斗」当十年的主线。主线一调成竞技，居住那一半会变成大厅。大厅已经有了。不必让单人档也变成大厅。

## 不能做成动作游戏的原因

动作游戏要的是专精的手：取消、帧、连招、镜头、受击硬直。Minecraft 的手已经雇给挖和放。同一只手兼动作主角，两边都会不够——左键挖了半辈子的矿，突然被要求练出格斗游戏的精度，谁先让？冷却是一次想兼的尝试。尝试留下护照，也留下「足够用」：能打跑、能射、能用环境杀，不必成为魂类。

刻也装不下动作游戏的舞步。动作手感建在帧上：取消、硬直、零点几秒的窗口。Minecraft 的判定跟着刻走，一秒二十格——帧里的花招，刻里记不了账；要做真，就得动刻，那等于动整台机器的地基。格子同样拒绝动作游戏的光滑：对准的对象是格子和碰撞箱，位移的主角是 0.6 格宽的人在 1 格宽的缝里。跑酷比连招更像这具身体的运动语言。把预算砸进战斗现代化，会和跑酷、红石、建造抢那只手。抢赢了，得到一款更好的战斗游戏、一款更差的 Minecraft。何况威胁同时上缴材料：苦力怕掉火药，骷髅掉骨头——怪物也是可再生资源站。资源站不该当主角：主角不该掉零件。

可被证伪的说法是：只要把战斗做得「配得上 2020 年代」，新玩家会留下，老玩家会回来。留下的人会来打。回来的人未必还盖。盖才是这台机器的税基——时间花在世界上，世界比命长。战斗花在人身上。人身上的深度，前文刚拒绝写成技能树。

<Alternative title="做成动作游戏会得到什么">
你会得到更公平的 PvP、更像 Boss 战的 Boss、更配得上宣传片的刀光。你会失去挖和打之间那道平滑的衔接：同一只手刚从墙上收回，就伸向了人。这道衔接本身就是误用空间——苦力怕炸开你家之后，你用「放」把洞补上，而不是打开一张战斗结算画面。
</Alternative>

<Memoir title="夜里那一声">
不一定看见。先听见。然后你回头，看走廊的灯够不够。这一秒里没有连招。有的是家。那一声提醒你：家还可能被改掉。这就够了。
</Memoir>

## 这一章留下什么

- **爱好者**：战斗笑话可以笑。笑完你仍会为苦力怕回头。回头说明威胁在催建造，不在催你成为武士。1.9 的架，是在争攻击该不该单独成为一小节拍器。
- **开发者**：能抄走的是「足够用的威胁」——少 Boss、职责分开、爆炸和黑暗改的是地形与路线，PvP 交给社区寄生。抄不走的是：二十年里玩家已经用这只兼职工手盖完了家；你把战斗做成主循环，等于解雇这只手的主职。不够好是职位描述。把它做够好，可能就做错过了。

[^combat]: Java Edition 1.9（2016 年 2 月 29 日）加入攻击冷却、盾、双持等。Bedrock 近战长期无这套冷却。见 [Java Edition 1.9](https://minecraft.wiki/w/Java_Edition_1.9)、[Weapon](https://minecraft.wiki/w/Weapon)。

[^pvp]: 社区把 PvP 做成服务器规则与地图类型（包括床战、水晶流派等），寄生原版动词。机制概述见 [Player versus player](https://minecraft.wiki/w/Player_versus_player)。
