> **本章命题**：战斗不够好，却足够用。威胁的职责是驱动建造、移动和回家，不是成为动作游戏。把它做成核心循环，格子上的那只手就得让位给连招表。

## 问题

有人把 Minecraft 的战斗说成笑话：冷却尴尬，弓很素，Boss 花哨但不像讨伐。笑话听过之后，同一批人仍在挖、仍在跑、仍在为夜里那一声苦力怕回头。战斗若真是笑话，回头不会那么稳。

本章要问：为什么战斗不够好却足够用？可被证伪的说法是：玩家其实一直在等一款「真正的战斗更新」，做完之后 Minecraft 会更好，而不是更不像。只要还存在 1.9 把社区撕成两半、而 Bedrock 长期不跟这套手感、两边都还在玩的经验，这句话就不成立。[《两条产品线：Java 与 Bedrock》](/history/java-bedrock)

不要武器数值表。要写威胁在整台机器里的职位：它催谁，不催谁。

## 攻击冷却为什么撕裂社区

Java 1.9 把近战收成冷却：空挥变弱，满格才是一击，盾和双持捆进来。喜欢的人得到更像战斗的战斗。不喜欢的人把 1.8 做成一种政治：连点才是这只手。[^combat] Bedrock 长期更接近冷却前的手感。于是护照出现了——「还能连点」辨认你在哪条产品线上。

撕裂证明战斗被当成身份，不是补丁。身份会撕裂，是因为战斗从来不是核心循环，却被很多人用核心循环的标准来审。用动作游戏的标准看，冷却是现代化。用「同一只手」的标准看，冷却是把攻击从连着挖和放的节奏里摘出去，单独做一小节拍器。摘出去，PVP 变了，打块还在，挖还在。变的是那一小节拍。整台机器没改名。没改名，有人就觉得被背叛：我不是来打动作游戏的。也有人觉得被成全：我终于能打了。两种人认的不是同一份职位描述。

上一章把攻击列为七个动词之一，并且说工具只放大。[《最小动词集与手感》](/design/verbs-feel) 冷却改的是放大器的时间形状，不是动词表。时间形状足以分裂社区。分裂本身说明：足够用的东西一旦被当成主菜来炒，油温会过头。

<Note>
Java 的冷却和横扫、Bedrock 的连点，合写不了成一句「Minecraft 的手感」。能合写的是职位：攻击存在，但不雇佣整晚的注意力。
</Note>

## 节奏装置：黑夜、苦力怕、亡灵

怪物不是图鉴主角。主角是你盖的那堵墙。黑夜把光线收走，敌对生成跟黑暗走。苦力怕把「我在你背后」写成倒计时，倒计时结束不是掉血那么简单，是你家缺一块。亡灵在白天烧，把太阳变成排程。这些都是生存节拍器的鼓点。[《生存作为意义机器》](/design/survival)

鼓点驱动建造和移动。你为了灯而挖矿，为了床而养羊，为了别被炸而把走廊做成两格，为了白天赶路而看天空。威胁若消失，和平仍能玩，只是少一轨——上一章写过。威胁若变成核心循环，你就会为了打而打，墙变成掩体系统，挖变成刷材料。刷材料的动作游戏很多。它们不需要苦力怕认得你的房子。

苦力怕认得房子，是因为爆炸改地形。威胁咬合原语：疼可以在人身上，记忆在地上。打块作为 PVP 手段，也是这口咬合——建造动词临时借给伤害。借得到，因为没有战斗模式把建造锁门外。

## Boss 克制：龙、凋灵、监守者的不同职责

官方 Boss 很少，而且职责分开。不要把它们读成「三个关卡」。

**龙**是仪式。末地、爆炸、出口传送门、致谢字幕。仪式给外人一个「通关」。打完，世界不收回。职责是给产品一个生日，不是给循环一个句号。下一章写终局。[《维度、进度与终局》](/design/dimensions-endgame)

**凋灵**是可选基础设施。召唤要你自己摆头，打完给星，星给信标，信标给一片被你圈起来的强。它不像拦路的门。它像一台你决定要不要造的工厂的钥匙。克制在于：不打也能活，打了得到的是地址上的增益，不是新职业。

**监守者**是反战斗。黑暗、声音、你不该打。职责是让深处的城市不是另一场讨伐，是另一种走法。做成讨伐，监守者就只是更大的僵尸。做成「请安静」，威胁才再次驱动移动而不是连招。

克制的总原则：Boss 可以很响，不能雇佣游戏剩下的时间。雇佣了，生成、合成、红石都变成刷前夕。刷前夕是动作 RPG 的正确。不是这台机器的正确。

<Constraint name="威胁驱动建造" verdict="地基" chain="黑暗 / 爆炸 / 稀有 Boss → 回家、点灯、移动 → 不成为主循环">
怪物的成功，看它有没有让你改地形或改路线。看它有没有让你打开技能树，是看错了栏目。
</Constraint>

## PvP 作为社区竞技

官方没把 Minecraft 做成竞技核心。社区做成了。服务器规则、插件、地图、1.8 与 1.9 的分流、打块、水晶、床战，全是第二作者的竞技。[^pvp] 竞技能成立，因为格子让掩体可造、失败可指、重置可脚本。成立之后，它仍寄生在原版动词上：看、走、挖、放、打。寄生一拆——禁止挖、禁止放——就变成另一种射击。

所以 PvP 不是正作失败的证据，是正作够薄的证据。薄到能被写成比赛。比赛可以很严肃。严肃不等于官方该把冷却再调十年当主线。主线一调成竞技，居住那一半会变成大厅。大厅已经有了。不必让单人档也变成大厅。

## 不能做成动作游戏的原因

动作游戏要的是专精的手：取消、帧、连招、镜头、受击硬直。Minecraft 的手已经雇给挖和放。同一只手兼动作主角，两边都会不够。冷却是一次想兼的尝试。尝试留下护照，也留下「足够用」：能打跑、能射、能用环境杀，不必成为魂类。

格子也拒绝动作游戏的光滑。对准是格或碰撞箱，位移是 0.6 宽的人在 1 格缝里。跑酷比连招更像这具身体的运动语言。把预算砸进战斗现代化，会和跑酷、红石、建造抢那只手。抢赢了，得到一款更好的战斗游戏、一款更差的 Minecraft。

可被证伪的说法是：只要把战斗做得「配得上 2020 年代」，新玩家会留下，老玩家会回来。留下的人会来打。回来的人未必还盖。盖才是这台机器的税基——时间花在世界上，世界比命长。战斗花在人身上。人身上的深度，上一章刚拒绝写成技能树。

<Alternative title="做成动作游戏会得到什么">
你会得到更公平的 PVP、更像 Boss 战的 Boss、更配得上宣传片的刀光。你会失去挖和打之间那层滑：同一只手从墙滑到人。滑是误用。误用是苦力怕炸开你家之后，你用放把洞补上，而不是打开战斗结算屏。
</Alternative>

<Memoir title="夜里那一声">
不一定看见。先听见。然后你回头，看走廊的灯够不够。这一秒里没有连招。有的是家。家被一声提醒它还可能被改掉。足够了。
</Memoir>

## 这一章留下什么

- **爱好者**：战斗笑话可以笑。笑完你仍会为苦力怕回头。回头说明威胁在催建造，不在催你成为武士。1.9 的架，是在争攻击该不该单独成为一小节拍器。
- **开发者**：能抄走的是「足够用的威胁」——少 Boss、职责分开、爆炸和黑暗改的是地形与路线，PVP 交给社区寄生。抄不走的是：二十年里玩家已经用这只兼职工手盖完了家；你把战斗做成主循环，等于解雇这只手的主职。不够好是职位描述。把它做够好，可能就做错过了。

[^combat]: Java Edition 1.9（2016 年 2 月 29 日）加入攻击冷却、盾、双持等。Bedrock 近战长期无这套冷却。见 [Java Edition 1.9](https://minecraft.wiki/w/Java_Edition_1.9)、[Weapon](https://minecraft.wiki/w/Weapon)。

[^pvp]: 社区把 PVP 做成服务器规则与地图类型（包括打块、床战等），寄生原版动词。机制概述见 [Player versus player](https://minecraft.wiki/w/Player_versus_player)。
