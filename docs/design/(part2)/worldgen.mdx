> **本章命题**：程序内容的合同是可探索，不是可通关。生成器给的是可去的地方，不是必走的关。找不到一座庙，仍可能是好下午；把世界做成清单，探索就变成收集。

## 问题

同一颗种子，两个人走反方向，看见的不是同一个下午。一个人碰上村庄，一个人掉进洞穴。没有人做错。生成器没有安排谁该看见什么。它只是把一份能走很远的地形铺开，让你自己决定何时回头。

生存章把目标外包给玩家（[《生存作为意义机器》](/design/survival)）。外包要有材料。材料不能全是玩家自己垒的——那就没有「外面」。程序生成负责外面：一份事先不认识、却仍认一米格的地方。本章要问：这份内容的设计合同是什么？可被证伪的说法是：好的程序世界应当保证每个玩家都「玩得到」关键结构，像关卡一样公平。只要还存在有人玩了三年没见过林地府邸、却不觉得游戏坏掉的经验，这句话就不成立。

公式放到卷三。本章不写噪声怎么叠加。要写的是玩家能感到的合同：去、找、错过、再去。

## 为什么同样的山可以看一辈子

因为山不是关卡。关卡看完就消耗掉了。山不走剧本：走掉的是你的位置、火把和腿力，山还在原地。你第二次路过，季节没有变（除非你自己改），变的是你：家里有没有床，箱子里有没有地图，你知不知道后面那条河能通船。生成器提供的是可返回的物质，不是一次性演出。

而且山上还留着你的笔迹。第一次路过时挖的矿道口、搭歪的桥、没拆的脚手架，第二次路过都还在。生成器写的是底稿，你写的是批注；重游读的是自己那层字。关卡给不了这个，因为关卡不允许批注。可返回，要求地形稳定。种子一旦定了，这块地方应当还是这块地方——至少在同一版本、同一套生成器里。版本一换，同一块地可能换一种长法；更新怎么对待旧存档，是后话，是更新政治。合同的核心是：在一次游玩里，世界不是老虎机，不会每走十格就刷新一张新关。无限若变成每一步都是新关卡，居住会消失——你没法在一台每按一次就重摇一次的老虎机前面安门。

礼仪也会变。第一次下矿，火把插得东一支西一支，原路摸黑退回来；第二次，每走几格一支，岔路口摆一块记号的石头。山没变，你在山里的举止变了——可返回的地形，才养得出这种举止。对照一下肉鸽游戏就分清了：那边每层都是新的，新鲜度是燃料；Minecraft 的地形不刷新，新鲜度来自你还没走到。两种预算都成立，但只有第二种养得出「家」——家需要一块明天还在的地皮。

影像把这件事拍成风景。梦核、延时、种子分享，靠的是「那座山还在」（[《影像、教育与一代人的媒介》](/history/media-education)）。教学链便宜，因为格子能说；风景能传，因为种子能复述。复述不是通关。复述是「你也来看看」。

## 噪声 / 群系 / 结构的职责

三层不要混成一句「随机地图」。

**噪声**负责连续的起伏：哪高、哪低、哪是空的。它不讲故事。它给走路和挖矿一个地板：坡是你爬得上去的坡，崖是你掉得下来的崖。没有噪声，世界是超平坦——创造的摄影棚，不是生存的外面。

**群系**把起伏涂上气候和调色：沙漠、丛林、雪原。它换的不只是方块种类，是整套色板和天气：草的颜色从雨林的浓绿到稀树草原的枯黄，同一场降水，雪原落成雪、丛林落成雨，树也从橡树换成云杉、金合欢。群系之间往往有过渡带——草原渗进森林，森林褪成雪原——你可以站在一条看不见的气候线上，左脚一种草，右脚另一种；边界的连续，是「外面」可信的一部分。群系是可指的地方种类。「往南是沙漠」能说。能说，探索才有口语。群系也分派住户：北极熊认雪原，鹦鹉认丛林，骆驼认沙漠。群系不是关卡名。它不保证你在沙漠里赢一场。它保证沙漠和森林长得不是一副样子。

**结构**是稀疏的作者痕迹：村庄、要塞、神殿、传送门。结构给远行一个可能撞上的名词——一个能说出口的地名。稀疏让地名能用：「顺着河走，过两座山，第三个村庄往东」，这句话能用，是因为村庄不多也不少。名词一密，世界变成主题乐园，每个路口都有任务，你说的其实是编号；名词一稀，错过是常态。有些结构还是废墟：沉船、雪屋、埋了半截的遗迹。废墟是一种不打扰的叙述——沉船讲了一桩沉没，却不派任务。稀疏是合同的一部分。官方越把结构当版本卖点，稀疏就越容易被填满。填满的风险留给第 15 章；本章先承认结构的职责是点，不是网。

三层共用一米格。程序内容必须能被动词接住：生成出来的墙仍要能让两格门通过，湖仍要能被桶舀。接不住，生成就是背景图。

## 无限的修辞：种子、远地、边界

种子把「另一份世界」收成一串能念的符号。无限是修辞：你走不完，不等于没有尽头。远地是这份修辞最出名的事故：老版本的生成器在大坐标上会崩，走到极远处，地形叠成几十格高的墙和无底的裂缝，像被拉扯坏的画。社区没有把它当漏洞处理，而是给它命名，然后有人朝它走，一走好几年，把「走到远地」走成一场公开的直播远征。Beta 1.8 换了地形算法，墙消失了；Java 默认世界边界在约三千万格外，命令能改。[^border] Bedrock 在极远坐标仍有自己的条带地貌，和 Java 的远地不是一回事，不能混成一句传说。[^far] 崩坏被清掉之后，边界变成明确的墙。墙很诚实：修辞是无限，实现是有限。

<Figure src="/images/farlands.png" alt="Java 版远地地形：极远处生成器数值崩坏拉出的高墙、孔洞与裂缝" caption="远地：浮点精度在大坐标上崩坏后，地形被「拉」出的墙与裂缝。它被社区命名、朝圣、最终被算法更新抹去——一次生成器事故如何长成公共地标。图源：Minecraft Wiki。" />

有限不是背叛。居住需要有限——存档要落盘，区块要加载，服务器要算税。大坐标还有一笔暗账：走得极远，浮点会先于边界开始抖，实体和方块的动作在大数上先变糊。墙立在那里，一部分就是为了挡住抖。合同是：在你还愿意走的尺度里，世界显得像没有作者画完的边。显得，就可以。走到数字爆炸的地方，游戏有权说停。停了，种子仍然能再开一份。种子还是社交货币：同一个种子号，能同时开起十个人的讨论组——你们走不同的路，看的是同一座山。无限发生在「再开」上，不发生在「这一份永远走不到头」上。

可被证伪的说法是：取消边界、恢复远地，游戏会更 Minecraft。更怪的地形很好看。但好看的崩坏会撕碎可复述性：那里不再是「再往东七格」，而是「引擎开始胡说」。胡说可以当朝圣景点，朝圣不是默认合同。

## 生成当卖点：洞穴与山崖的设计含义

有些版本把生成器本身当成内容。洞穴与山崖分两批兑现：2021 年中的一批先往旧地形里塞新料——铜、紫水晶、山羊、美西螈；2021 年底的一批才动地形本身——可玩的高度向上、向下都推开一大截，洞穴从一人宽的走廊变成藏得下一座基地的洞厅，山从背景变成目的地。同一轮思路还捎带了深暗之域——给洞穴配一套「安静」的法律，它计划在这一轮、实际晚到一个版本才落地：生成器开始连行为规则一起卖。[^caves] 卖点不是新剑。卖点是外面又换了一种。这说明生成已经是产品，不只是 2009 年的铺地板。

生成一动，老经验就要重估。矿在哪些层、哪种地形出什么怪，熟练工背下来的口诀跟着作废一层；旧存档的旧区块不重算，新区块按新规矩长，版本边界在地形上看得出来——生成器把「你是哪个版本的人」写进了地图。当生成成为卖点，合同会被拧紧一格。玩家开始期待「每一颗种子都更壮观」，壮观密了，稀疏的结构会显得不够，下一次更新就再加名词。名词加到能列清单，探索就接近收集。收集能很好玩。收集不是「同样的山可以看一辈子」那种好玩。两种好玩可以并存。设计者要知道自己在卖哪一种。

Java 与 Bedrock 的生成长期不是同一份算法，同一种子跨产品线，山可以对不上（见[《两条产品线：Java 与 Bedrock》](/history/java-bedrock)）。分叉让「来我世界看看」有时要先问版本。问版本，说明生成已经是身份，不只是背景。身份是有代价的，代价的形状仍暴露原语：两边争的是哪一座山，不是要不要格子。

## 「找不到」作为探索燃料

找不到是内容。林地府邸、海底神殿、那个刚好的裂谷，本来就不是人手一份。稀有一旦变成保底，生成器就开始扮演公平的关卡设计师。关卡设计师会消灭「我撞见了」。撞见是探索的高潮。保底是进度的高潮。两种高潮认的不是同一份合同。

官方给的工具都守着这条线，它们把「找不到」改成「可玩的寻找」，而不是把对象塞进出生点附近。制图师村民卖探险家地图，图上只画一个记号，路要自己走。末影之眼朝要塞的方向飞——因为它是仪式的入口，游戏对它网开一面，肯给你指路，但路还是你自己跑。磁石指南针把一块坐标钉成锚点。每个工具给的都是方向加距离，不是传送：游戏拒绝替你取消距离。稀疏也不是随机稀疏：要塞藏在地下，林地府邸埋进黑森林——最难找的，恰恰是进度线的入口。

进度系统会把「去过某某群系」写成建议（下一章[《维度、进度与终局》](/design/dimensions-endgame)细说）。建议可以指方向，不该改生成器的稀疏。寻找仍可能失败。失败了，下午仍可能很好——你盖了路，你认识了河。路和河是生成器给的材料，不是任务奖励。速通社区把「找」推到另一个极端：他们不在世界里找，在种子列表里找——用工具筛出出生点旁边就齐了关键件的世界，再把它跑给直播镜头。筛选在游戏外，奔跑在游戏里，两件事共用同一份合同。种子地图网站把「找」整个外包给工具，想看哪里翻哪里——玩家有权这样作弊式地找，只要不把工具当成官方的合同。

模组和数据包能加结构、加传送、加「必出」。加完，世界更像图鉴。图鉴有用。正作若把图鉴当默认，外面会变薄。外面一旦变薄，换种子就只是换一张皮肤。

<Constraint name="可探索不是可通关" verdict="地基" chain="稀疏结构 → 可错过 → 可返回">
生成器提供可去之处，不提供必完成清单。错过必须合法。合法，山才值得看一辈子；非法，世界会变成待办事项。
</Constraint>

<Memoir title="这颗种子">
把种子念给别人听，比把存档打包更轻。对方听见的是一份可能，不是你的家。可能足够让人再开一局。家仍只存在于你改过的那一份里。生成给可能，玩家给家。两件事不要颠倒。
</Memoir>

## 这一章留下什么

- **爱好者**：找不到不是你不会玩。是合同允许你错过。种子是邀请，不是攻略书的目录。
- **开发者**：能抄走的是「程序内容当可探索材料」——连续起伏、可指的种类、稀疏的名词，错过合法，返回仍在。抄不走的是：一米格已经让生成出来的墙能被口述、被挖、被住；你换一套更漂亮的噪声，若对象不能搬进库存，风景就只是天空盒。不要把保底当成公平。保底改的是合同。

[^seed]: 世界种子是生成器的输入。同一种子在不同版本、以及 Java 与 Bedrock 之间不必得到同一地形。见 [Seed](https://minecraft.wiki/w/Seed_(world_generation))。

[^border]: Java 默认世界边界中心在原点、半径约 29999984 格，可用命令改。见 [World border](https://minecraft.wiki/w/World_border)。

[^far]: Java 的远地地形在 Beta 1.8 被替换；Bedrock 在极远坐标仍有条带等地貌。见 [Far Lands](https://minecraft.wiki/w/Far_Lands)。

[^caves]: 「洞穴与山崖」分两步：Java 1.17 加内容，1.18 改世界高度与洞穴生成。见 [Caves & Cliffs](https://minecraft.wiki/w/Caves_%26_Cliffs)。
