> **本章命题**：深度不加在角色上，是因为成长必须能被丢掉、交给别人、放回世界。物品是格子的可搬运切片；人几乎透明。技能树能做出「我更强了」，做不出「这座山是我挪来的」。

## 问题

两个人都能挖、都能放，一个拿着钻石镐，一个拿着木镐。差别不在天赋页。差别在手里那块东西：挖得动什么、还能用多久、附过什么字。换手，强弱对调。人还是那个人。

动词章把七个动词钉死，生存章把生存写成节拍器（见[《最小动词集与手感》](/design/verbs-feel)与[《生存作为意义机器》](/design/survival)）。本章要问：没有技能树，深度写在哪？可被证伪的说法是：玩家真正要的是角色成长，物品栏只是还没做完的背包。只要还存在「把镐丢掉就变回普通人」、以及模组把技能树加回去之后立刻觉得自己在玩另一款游戏的经验，这句话就不成立。

不要列合成表。表是 Wiki 的事。这里只问网格为什么不是检索，物品为什么不是装备栏里的加成数字。

## 没有技能树怎么「变强」

变强的主路径是换物，不是换人。第一个证据新手第一晚就撞见：木镐敲铁矿石，矿石碎成粉末，什么都不掉。世界检查的是你手里的工具，不是你的等级。于是路只有一条：做石镐，挖到铁，做铁镐，才轮得到钻石。木石铁钻这条假进度，其实是真教学：每一步动词不变，放大器变——这正是[《生存作为意义机器》](/design/survival)里那台节拍器的走法。

假进度能走完，人却没有点出新职业。对照一下角色扮演游戏就清楚了：同样的四小时，那边把你从「不会挖矿」升成「挖矿大师」，天赋页多两行，从此固定；这边把那四小时换成一把更快的镐。镐可以丢、可以借、可以传给下一个进来的人。真 RPG 不允许你把等级脱下来交给队友。Minecraft 允许。允许，是因为强写在物上。

身体本身也长成一组格子：四个甲槽、一排快捷栏、一只副手。最贴身的「装备」在这个游戏里也只是几格库存——盔甲可以脱、可以换、可以掉，和箱子里的方块记同一本账。工具家族说同一句话：铲对土快，斧对木快，剑对怪快——它们不发明新动词，只是把同一次挥击放大到不同对象上。

死亡是这条设计最诚实的演示。人死了，物掉一地，等级掉一截——掉的全是财产，不是人格。你跑回原地，看见的还是那些可捡的切片；就算来晚一步，物没了，损失的也还是物，而不是一个养了三年的角色。死亡不掉人的游戏，才敢让人把强全写在物上。

看起来像反例的东西，大多仍附着于物。经验条涨在人身上，花出去却是给附魔台、铁砧、砂轮。等级是货币，不是职业。状态效果会过期。信标的力量来自你放在那里的金字塔，不来自你的血统。鞘翅是一件衣服。图腾是一次不死，而且只在举着它的那一刻算数。全部可掉落、可交易、可被抢。可掉落的成长，才和「世界即库存」咬合：地上的方块和背包里的方块是同一种对象；地上的镐和身上的镐也是。

模组爱加技能树、职业、法力。加完，共同语言会裂：有人点了「更好的矿工」，口述从「用钻石镐」变成「你学了哪一系」。第二作者可以违背这份合同；也正因为有人违背，合同才显形——你得先看见有人破坏它，才知道它一直在。官方把配方书、进度、锻造模板加进来，仍不肯把「采矿」收成天赋。不是做不出菜单。是菜单会把那只手改成角色表。

<Callout type="warning" title="人几乎透明">
后文凡是说成长，默认问：这东西死了掉不掉、能不能放进箱子、能不能交给一个刚进来的人。掉不了、交不出，它就开始往角色上爬。爬到角色上，居住会变成养成。
</Callout>

## 网格合成：空间记忆 vs 检索菜单

2×2 在背包里，3×3 在工作台上。这道门槛是硬的：没有工作台，你连熔炉都合成不了，因为熔炉的配方要八块圆石围一圈，2×2 摆不下。「第一晚先做工作台」不是教程的规矩，是格子的规矩。

配方是形状，不是关键词。你记得镐头横在顶行、两根木棍竖在中间那一条竖线上；斧是把镐歪过一格；剑是一块材料压两根棍。学过一次，剩下的是手熟——老玩家不看配方书，几秒钟就能摆出一把镐，像打字的人不看键盘。九格还有社交的一面：你能从别人工作台上摆了一半的形状认出他在做什么。合成因此是一门可读的手势——服务器里，递过去一把刚出炉的镐，和递过去一份说明书，是两件事。空间记忆让合成寄生在前文的格子上：还是那把尺，只是从世界收进九格。

检索菜单更快。配方书已经把检索加回来了，尤其在触屏上，书往往先于形状。[^recipe] Java 的书可以当索引，形状仍能用手摆；Bedrock 的触控合成更常把形状收成按钮。分叉证明：官方自己也觉得形状贵。贵不是缺陷。贵换来的是可教、可误、可发明——摆错形状，格子里什么都出不来，错得明明白白；但形状本身是开放的语法，后来每一种模组新工具，仍然用同一张 3×3 摆出来。检索菜单的失败是「没搜到」。没搜到不是发明。

工作台是世界上的家具，不是角色菜单。你要放下它、对准它、使用它。合成因此仍是现场动词，不是暂停页里的生产。创造模式取消了稀缺，物品栏才更像一台带搜索框的目录；生存把合成留在家具上，是为了让「做一把镐」仍发生在家里，而不是发生在 HUD 里。

可被证伪的说法是：配方书才是现代正确，形状是过时 UI。若有一天官方取消手动摆放、只留搜索，社区觉得更清爽而不是少了一种语言，这句话要改。至今，教程视频仍在拍那九格。九格能上镜头，因为它和房子用同一套整数。

## 物品即世界的切片

挖不是特效。挖是把某一格变成可带走的一份。这份切片掉在地上不是图标，是一个会转的小方块，你看得见它躺在门口；几分钟没人捡，它才消失。世界给你一段时间回去拿，但不替你保管。这条纪律决定了玩家全部的搬运行为：远征要带储物，搬家要跑很多趟，坠崖之前先看脚下有没有可以丢东西的箱子。

切片可以叠、可以嵌。64 个一份叠成一组，组进格子，格子进箱子，箱子进潜影盒。潜影盒本身又是一件物品，可以再丢、再卖、再抢——但装了东西的潜影盒不能再塞进另一只潜影盒，游戏亲手堵死了盒中盒，否则库存会无限递归。物品也能反向陈列。展示框把切片钉回墙上，告示牌写明箱子里有什么——库存的语法一直延伸到房间的装饰，陈列用的还是同一份清单。开卷第一章说世界可计数（[《体素作为设计原语》](/design/voxel-primitive)）；这份可计数在这里变成可搬，而且搬得有上限。

切片有厚度。方块在地上占一格；进背包变成图标。熔炉、工作台、箱子反过来：图标再变成家具，家具再占格。往返必须可逆，世界即库存才不是修辞。不可逆的东西——知识、技能点、账号成就——开始不像切片。Bedrock 的成就绑账号，Java 的进度绑世界。[^adv] 绑账号的那一份，已经有一点不像库存了。那是后文终局章的裂缝，本章先记下：物品必须能放下。

切片还听物理的使唤。掉落物是实体：会被水流推着走，会浮在水面，掉进岩浆就没了。玩家把这套脾气用成流水线——引一段水，把田里的收获冲到一个点上，人站在收口伸手。搬运因此是可以设计的：怎么让东西自己走到箱子跟前，是后期基建的第一课。

特殊容器是切片的加强，不是例外。末影箱让同一份库存跨空间出现，仍是格子。潜影盒让箱子自己变成物品。潜影盒是「世界即库存」长出的翅膀：家可以背着走。翅膀仍认 27 格，不认无限的文件夹。无限文件夹是操作系统。27 格是这款游戏。

## 成长在物上：耐久、附魔、锻造

耐久把时间写进物。镐会钝，不是因为你累了——耐久条就画在图标下面，短一截是短一截，谁捡到都看得见。钝了可以修：两把残镐放进格子，残值相加；或者上铁砧，花材料换命。修要花材料或经验，经验来自你改过的世界。循环闭合：世界养成物，物改世界。

附魔把偶然和选择写进物。附魔台给出的是几条不透明的报价：你看得见大概是什么，看不见确定是什么，选一条，翻页再来。符文在书页上飘，连起来也不成一句说明书。你花等级，物品长出词条；词条跟着物品走，不跟着玩家走。后来加的「经验修补」把循环推到底：带着这条附魔的工具，你捡到的经验会先拿去修它——日常劳动直接变成物的寿命。词条甚至可以是负面的。消失诅咒让物品在死亡时蒸发，缚咒让盔甲穿上就脱不下来。负面也写在物上，不写在人身上——中招的是那件装备，不是你的属性页。词条还能单独上市：附魔书把「词条」从工具上拆下来当货物，你买的不是某把剑，是词条本身，装到哪把剑上是后话。词条可交易，成长就进一步脱离了「人」。铁砧可以合并、改名、付出越来越高的代价。Java 的「过于昂贵」和 Bedrock 的代价数字并不同一套；[^anvil] 两边都把成长焊在那把镐上，不焊在角色卡上。锻造模板后来把「升级」收成配方：钻石甲加模板加下界合金锭，得到下界合金，原附魔一样不少。升级的是甲。人还是那个人。

武器和工具因此能成为遗产。服务器上别人用过的神器、影像里展示的附魔剑、交易里流出的村庄装备，全是可移交的强。铁砧改的名字跟着物品走：一把叫过名字的剑，故事也一起进箱子。技能树移交不了，除非你做账号系统。Minecraft 默认不做那种账号养成——Bedrock 成就是平台层的例外，不是生存循环的主路。

<Constraint name="成长可移交" verdict="地基" chain="物可变强 → 物可掉落 → 人可换手">
深度若不能交给下一个进来的人，共同作者会少一种共同财产。角色养成把财产收成隐私。物品把财产留在世界上。
</Constraint>

</Note>

## 反 RPG：选择而非缺失

几乎没有职业、没有天赋、没有「你是战士所以不能挖」。这不是做不完。这是选择。选择的代价是后期像是「更好的镐」而不是「新的我」。选择的收益是：任何一个刚进来的人，捡起你的镐就能接上手。共同语言活在物上，不活在存档深处的技能 JSON 里。

最像 RPG 的官方系统其实已经做了职业——但职业发给了村民。农民、图书管理员、铁匠，各守各的工作站，穿着各穿的袍子，你和他们做买卖，他们不跟你换天赋。官方宁可把职业做成 NPC 的生态，也不把它做成你的技能页。这个观察任何玩家都能核对。

经验值、饥饿、进度，都在往角色上探了一寸。探一寸可以。探成主循环，物品就变成装备栏里的加成，世界就变成刷经验的地图。刷经验的地图很多。它们不需要一米格。Minecraft 需要一米格，所以必须克制角色。这种克制看起来像功能缺失。缺失换来的是：模组可以加 RPG，正作不必先变成 RPG；正作留出的空洞，正好是第二作者席的结构空洞——那是第 13 章的事。本章只要钉死：空洞是故意的。

可被证伪的说法是：玩家已经用附魔、锻造、村民把 RPG 做完了，官方只是不好意思写技能树。若技能树进正作，社区觉得「终于有成长了」而不是「这还是不是同一只手」，这句话要改。至今，最像 RPG 的官方系统——进度、配方、村庄——仍把奖励写成物、写成地址、写成建议，而不是写成你是谁。

## 这一章留下什么

- **爱好者**：你变强，是因为你搬过世界、修过镐、附过字。人几乎透明，所以死人的箱子仍是故事，不是作废的角色卡。
- **开发者**：能抄走的是「成长写在可移交的物上」——耐久、词条、升级都跟着物品走，空间合成用形状而不是检索当主路。抄不走的是：二十年教程已经把九格和工作台教成常识；你若先做技能树再做背包，玩家会的是养成，不是搬运。菜单能做出深度。它做不出「这座山在箱子里」。

[^recipe]: 配方书在 Java Edition 1.12 加入，后与数据包中的配方数据相连。Bedrock 触控界面更常把合成收成配方按钮。见 [Recipe book](https://minecraft.wiki/w/Recipe_book)。

[^adv]: Java 进度按世界存储，可用数据包改写。Bedrock 成就按账号 / 平台记录，开作弊或创造通常使该世界无法再解锁成就。见 [Advancement](https://minecraft.wiki/w/Advancement)、[Achievement](https://minecraft.wiki/w/Achievement)。

[^anvil]: 铁砧用于合并、附魔、改名，代价随使用上升。Java 有「过于昂贵」上限；Bedrock 的经验代价规则不同。见 [Anvil](https://minecraft.wiki/w/Anvil)。
