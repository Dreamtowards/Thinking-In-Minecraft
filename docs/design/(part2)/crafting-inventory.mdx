> **本章命题**：深度不加在角色上，是因为成长必须能被丢掉、交给别人、放回世界。物品是格子的可搬运切片；人几乎透明。技能树能做出「我更强了」，做不出「这座山是我挪来的」。

## 问题

两个人都能挖、都能放，一个拿着钻石镐，一个拿着木镐。差别不在天赋页。差别在手里那块东西：挖得动什么、还能用多久、附过什么字。换手，强弱对调。人还是那个人。

上一章把七个动词钉死，把生存写成节拍器。[《最小动词集与手感》](/design/verbs-feel) [《生存作为意义机器》](/design/survival) 本章要问：没有技能树，深度写在哪？可被证伪的说法是：玩家真正要的是角色成长，物品栏只是还没做完的背包。只要还存在「把镐丢掉就变回普通人」、以及模组把技能树加回去之后立刻觉得自己在玩另一款游戏的经验，这句话就不成立。

不要列合成表。表是 Wiki 的事。这里只问网格为什么不是检索，物品为什么不是装备栏里的加成数字。

## 没有技能树怎么「变强」

变强的主路径是换物，不是换人。木石铁钻是假进度、真教学：动词不变，放大器变。[《生存作为意义机器》](/design/survival) 假进度能走完，人却没有点出新职业。真 RPG 不允许你把等级脱下来交给队友。Minecraft 允许。允许，是因为强写在物上。

看起来像反例的东西，大多仍附着于物。经验条涨的是人，花出去却是给附魔台、铁砧、磨制。等级是货币，不是职业。状态效果会过期。信标的力量来自你放在那里的金字塔，不来自你的血统。鞘翅是一件衣服。图腾是一次不死。全部可掉落、可交易、可被抢。可掉落的成长，才和「世界即库存」咬合：地上的方块和背包里的方块是同一种对象；地上的镐和身上的镐也是。

模组爱加技能树、职业、法力。加完，共同语言会裂：有人点了「更好的矿工」，口述从「用钻石镐」变成「你学了哪一系」。第二作者可以违背合同。违背让合同显形。官方把配方书、进度、锻造模板加进来，仍不肯把「采矿」收成天赋。不是做不出菜单。是菜单会把那只手改成角色表。

<Callout type="warning" title="人几乎透明">
后文凡是说成长，默认问：这东西死了掉不掉、能不能放进箱子、能不能交给一个刚进来的人。掉不了、交不出，它就开始往角色上爬。爬到角色上，居住会变成养成。
</Callout>

## 网格合成：空间记忆 vs 检索菜单

2×2 在背包里，3×3 在工作台上。配方是形状，不是关键词。你记得木板在四个格里，不是在「木」字的搜索结果里。空间记忆让合成寄生在上一章的格子上：还是那把尺，只是从世界收进九格。

检索菜单更快。配方书已经把检索加回来了，尤其在触屏上，书往往先于形状。[^recipe] Java 的书可以当索引，形状仍能用手摆；Bedrock 的触控合成更常把形状收成按钮。分叉证明：官方自己也觉得形状贵。贵不是缺陷。贵换来的是可教、可误、可发明——有人摆出错的形状，做出意外的东西；检索菜单的失败是「没搜到」。没搜到不是发明。

工作台是世界上的家具，不是角色菜单。你要放下它、对准它、使用它。合成因此仍是现场动词，不是暂停页里的生产。创造模式的物品栏才更像检索。创造取消稀缺，才配用浏览器；生存把合成留在家具上，是为了让「做一把镐」仍发生在家里，而不是发生在 HUD 里。

可被证伪的说法是：配方书才是现代正确，形状是过时 UI。若有一天官方取消手动摆放、只留搜索，社区觉得更清爽而不是少了一种语言，这句话要改。至今，教程视频仍在拍那九格。九格能上镜头，因为它和房子用同一套整数。

## 物品即世界的切片

挖不是特效。挖是把某一格变成可带走的一份。物品栏是便携的小世界：64 个一份叠成一组，组进格子，格子进箱子，箱子进潜影盒。上一章的可计数在这里变成可搬。[《体素作为设计原语》](/design/voxel-primitive)

切片有厚度。方块在地上占一格；进背包变成图标。熔炉、工作台、箱子反过来：图标再变成家具，家具再占格。往返必须可逆，世界即库存才不是修辞。不可逆的东西——知识、技能点、账号成就——开始不像切片。Bedrock 的成就绑账号，Java 的进度绑世界。[^adv] 绑账号的那一份，已经有一点不像库存了。那是后文终局章的裂缝，本章先记下：物品必须能放下。

特殊容器是切片的加强，不是例外。末影箱让同一份库存跨空间出现，仍是格子。潜影盒让箱子自己变成物品。潜影盒是「世界即库存」长出的翅膀：家可以背着走。翅膀仍认 27 格，不认无限的文件夹。无限文件夹是操作系统。27 格是这款游戏。

## 成长在物上：耐久、附魔、锻造

耐久把时间写进物。镐会钝，不是因为你累了。钝了可以修，修要花材料或经验，经验来自你改过的世界。循环闭合：世界养成物，物改世界。

附魔把偶然和选择写进物。你花等级，物品长出词条。词条跟着物品走，不跟着灵魂走。铁砧可以合并、改名、付出越来越高的代价。Java 的「过于昂贵」和 Bedrock 的代价数字并不同一套；[^anvil] 两边都把成长焊在那把镐上，不焊在角色卡上。锻造模板后来把「升级」收成配方：钻石甲加模板加锭，得到下界合金。升级的是甲。人还是那个人。

武器和工具因此能成为遗产。服务器上别人用过的神器、影像里展示的附魔剑、交易里流出的村庄装备，全是可移交的强。技能树移交不了，除非你做账号系统。Minecraft 默认不做那种账号养成——Bedrock 成就是平台层的例外，不是生存循环的主路。

<Constraint name="成长可移交" verdict="地基" chain="物可变强 → 物可掉落 → 人可换手">
深度若不能交给下一个进来的人，共同作者会少一种共同财产。角色养成把财产收成隐私。物品把财产留在世界上。
</Constraint>

<Note>
Java 1.9 把副手加进物品栏，盾和箭有了第二只手；Bedrock 也有副手，能放的东西不完全同一张名单。名单分叉，不改「强在物上」。
</Note>

## 反 RPG：选择而非缺失

几乎没有职业、没有天赋、没有「你是战士所以不能挖」。这不是做不完。这是选择。选择的代价是后期像是「更好的镐」而不是「新的我」。选择的收益是：任何一个刚进来的人，捡起你的镐就能接上手。共同语言活在物上，不活在存档深处的技能 JSON 里。

经验值、饥饿、进度，都在往角色上探了一寸。探一寸可以。探成主循环，物品就变成装备栏里的加成，世界就变成刷经验的地图。刷经验的地图很多。它们不需要一米格。Minecraft 需要一米格，所以必须克制角色。克制看起来像穷。穷换来的是：模组可以加 RPG，正作不必先变成 RPG。第二条作者席才有结构空洞可补——那是第 13 章的事。本章只要钉死：空洞是故意的。

可被证伪的说法是：玩家已经用附魔、锻造、村民把 RPG 做完了，官方只是不好意思写技能树。若技能树进正作，社区觉得「终于有成长了」而不是「这还是不是同一只手」，这句话要改。至今，最像 RPG 的官方系统——进度、配方、村庄——仍把奖励写成物、写成地址、写成建议，而不是写成你是谁。

## 这一章留下什么

- **爱好者**：你变强，是因为你搬过世界、修过镐、附过字。人几乎透明，所以死人的箱子仍是故事，不是作废的角色卡。
- **开发者**：能抄走的是「成长写在可移交的物上」——耐久、词条、升级都跟着物品走，空间合成用形状而不是检索当主路。抄不走的是：二十年教程已经把九格和工作台教成常识；你若先做技能树再做背包，玩家会的是养成，不是搬运。菜单能做出深度。它做不出「这座山在箱子里」。

[^recipe]: 配方书在 Java Edition 1.12 加入，后与数据包中的配方数据相连。Bedrock 触控界面更常把合成收成配方按钮。见 [Recipe book](https://minecraft.wiki/w/Recipe_book)。

[^adv]: Java 进度按世界存储，可用数据包改写。Bedrock 成就按账号 / 平台记录，开作弊或创造通常使该世界无法再解锁成就。见 [Advancement](https://minecraft.wiki/w/Advancement)、[Achievement](https://minecraft.wiki/w/Achievement)。

[^anvil]: 铁砧用于合并、附魔、改名，代价随使用上升。Java 有「过于昂贵」上限；Bedrock 的经验代价规则不同。见 [Anvil](https://minecraft.wiki/w/Anvil)。
