> **本章命题**：没有结局，自愿目标才能延长。「通关 Minecraft」是一句空话：龙是仪式，末地不是最后一关。真正的后期是冰道、工厂和服务器日历，不是致谢名单。

## 问题

字幕滚过。有人关游戏。有人回主世界继续挖。两种人都可以说自己打完了。打完的是仪式。没打完的是存档。存档不认字幕。

本章要问：没有结局的游戏如何延长自愿目标？可被证伪的说法是：正式版那天已经把循环闭合，后面的村民、信标、鞘翅都是 DLC 式的添头。只要还存在打完龙之后才真正开始做冰道、才真正开始运营一座服的人，这句话就不成立——正式版并没有收束循环，这是[《Mojang 成立、Beta 与正式版》](/history/mojang-beta)里写过的判断。

末地不是最后一关。关卡有下一关。末地有返回。返回才是终局的形状。

## 「通关 Minecraft」是一句空话

空，是因为不存在最后那一步——走完它，游戏就替你把世界收走。龙可以不打。凋灵可以不召唤。进度可以不点。生存的发条——饥饿、黑夜、搬运——打完龙仍在走。仪式给外人一个句号，好让新闻稿和家长有个名词。名词不是系统。

空话仍有用。它让还没进来的人知道「有个高潮」。高潮当广告。广告不能当宪法。宪法若写成「打龙之前都是序章」，序章会吞掉十年。十年里的家、红石、服务器，才是这款游戏的税基。

仪式本身也守着这条线。打龙的结算是：一笔全游戏最大方的经验、一颗只能得到一次的蛋、一个直通主世界的出口、一段字幕。出口常开着，末地水晶还能把龙请回来，把仪式再办一次。常开的出口和可重开的仪式，都说明这不是一扇通关后熔断的门。连那段字幕都是旁证：它不大谈胜利，更像作者越过角色直接对你说话，末尾的意思接近「醒来，回去」。

速通把空话当真，做成比赛。比赛成立，说明仪式够硬、够可复述。成立之后，它仍是一种寄生：用生存和维度当赛道，不是把游戏收成赛道。赛道之外，字幕只是一次烟火。

## 维度 = 规则变体

下界和末地不是「更难的关」。它们是同一套格子上换过几条法律的地方。

下界最出名的一条法律是坐标汇率：主世界走一格，下界走八格——下界首先是交通层，其次才是险境和矿层。汇率也重写了导航文化：下界的地形大片同色，一眼难辨，玩家于是自带坐标系——记坐标、立磁石、修冰道匝道，把「迷路」当成要被基建消灭的敌人。其余法律跟着换：水刚倒出来就蒸发，床一点就炸，而下界有自己的床，叫重生锚，用荧石充能。这组对称值得多看一眼：床在主世界是存档点，带进下界是炸弹；重生锚在下界是存档点，带回主世界也是炸弹——同一件家具，过一道门就换一份法律。岩浆海替海洋，荧石替天光；猪灵认金子，见你穿金衣就让路，朝它们扔金锭能换来以物易物；这里挖的矿叫远古残骸，炼出来是下界合金。堡垒和猪灵是后来加上的名词——下界的名词也分年代：要塞是老住户，堡垒遗迹是下界更新那年搬来的。你仍挖、仍放、仍走。变的是哪一种疼、哪一种库存。

末地把地面收成岛，把虚空做成真正的掉下去，没有昼夜，把龙放在仪式中心。打完龙，中央的折跃门开，门小得只容一颗珍珠穿过——进外岛的第一步就是一个物理谜题。外岛才有内容：紫颂果吃了随机传送，潜影贝的壳攒起来合成潜影盒——终局的交通和终局的库存是同一次远征的收成；外岛末地船里挂着鞘翅，滑行加烟花，主世界的天空从此不一样。[^dim]

规则变体的好处是：学习成本低。你不必学新动词，只需要重新学这套动词在新法律下的后果。后果可口述：「下界别放床」「末地往外岛」。口述仍是格。生成器在维度里换噪声和结构；[《世界生成即内容生产》](/design/worldgen)那份合同照旧：可探索，不是可通关。

Java 与 Bedrock 的维度在生成和传送门细节上有分叉。分叉是口音。口音下面，仍是变体不是关卡：没有人在下界给你一张必做任务表，除非你自己用进度或命令写一张。

<Impl title="传送门是地址转换，不是过场">
主世界与下界的传送门按比例换算坐标；末地传送门是一次仪式性的搬家。转换失败会把你丢在怪地方。怪地方仍是格。设计上它不是过场动画，是另一份必须能住、能挖、能跑路的世界。
</Impl>

## 进度系统是建议

Java 的进度按世界走，像一棵可以折叠的建议树：根上是「石头时代」，枝上是去过、做过、看见过。解锁配方会弹提示，部分进度发经验。新人摸到的第一批进度——「石头时代」「获得升级」——其实是前一小时的教学大纲，只是用表扬的语气念出来。数据包能改它，也能另写一套——冒险地图把任务树直接写进进度，做完一步弹一条「任务完成」，官方机制成了作者的界面。它不拦你。不完成「冒险时间」，游戏不会没收夜晚——[《合成、物品与库存》](/design/crafting-inventory)里说过，进度把奖励写成建议，不写成任务。建议可以发奖励经验，可以指方向，不该把生成器改成保底机。

Bedrock 的成就按账号和平台走，开作弊往往整张世界出局。[^adv] 那是平台层的奖杯，不是这份存档的建议。奖杯会催收集。催收集，探索容易变成打卡。打卡可以很好玩。好玩的是平台。不是「同样的山可以看一辈子」那种合同。两边都叫进度或成就，职位不同：一个是世界内的建议，一个是账号上的勋章。

所以「进度系统」不要合写成一句。能合写的是：正作需要一根可以忽略的手指，给新人指一下「下面还有东西」。手指一变成铁轨，外包出去的目标就收回官方手里。收回，终局就又变成关卡。

<Callout type="warning" title="末地不是最后一关">
打完龙，外岛还在，鞘翅还没捡，主世界的家还在饿。把末地听成通关画面，会把后面十年的基础设施写成多余。它们不是多余。它们是游戏承认自己没有结局之后，玩家写的结局。
</Callout>

## 官方后期：村民、信标、鞘翅

官方延长自愿目标的方式，是给物和地址，不给人职业。

村民把交易做成可搬的系统：工作站定职业，床定户口，买卖做多了升级，僵尸村民能被治好——治好一次，折扣跟一辈子。袭击把这条经济变成需要保卫的产业：带着不祥之兆回村，掠夺者上门；守住，你就是村庄英雄，全村给你打折。图书管理员的「经验修补」是这条经济的硬通货——工具寿命的问题，最终在交易桌上解决，又绕回「成长在物上」。你在世界上养一台经济，不是在菜单里点技能。信标把一块坐标加成写成光柱：先造金字塔——矿锭一层层铺成底座，再把下界之星嵌进顶上；满级金字塔要上千块锭，它不是装备，是不动产。满级信标是几个月基建的收据，光柱是你给自家地址立的碑。鞘翅把垂直稀缺变成滑行：要你先去外岛、先闯末地船，再把烟花当推进器；鞘翅自己也会磨，修补还得回到交易桌——后期的增益全连着同一本经济账。滑行加烟花，等于给整张地图发了航空许可——而航空网是选址问题：家在哪，补给站放哪。[^late]

三样东西都可忽略。忽略了，生存仍转。拿上了，后期变成物流和选址。物流和选址是建造、红石、物品咬合出来的：不是新循环，是旧循环加长。加长成功，是因为它们仍认格、仍可掉落、仍能交给别人。

## 玩家后期：冰道、工厂、服务器活动

真正占十年的，是玩家自己写的后期。冰道把距离收成速度：一条蓝冰道、一条船，洲际旅行从几分钟变成十几秒。刷怪塔、刷铁机、农作物线把生存节拍器反过来用：原本催你的黑夜和刷新，成了资源产线——黑暗会刷怪，那就造一片可控的黑暗；恐惧催你造墙，那就造一台专门生产恐惧的机器；连上门的袭击都能反过来收割，把掠夺者接进产线。下界匝道、潜影盒物流、村庄交易所，是玩家自己写的物流栈。服务器日历把「今晚活动」写成社会终局（[《服务器即新游戏》](/history/servers)）：周年庆典、集体远征、新赛季开服。有的服务器把终局做成十几年——无政府服的地图上，几代玩家留下的废墟本身就是纪念碑，存档比很多游戏活得长。官方没有这些玩法页。玩法页从克制里长出来：世界比命长，目标外包，红石可误用，物品可移交。

玩家后期常比龙更像结局——一座服的周年、一次完成的远征、一条贯通的冰道。结局是他们立的。游戏只负责不先闭合。不先闭合，才有位置让他们立。闭合成关卡，位置会被致谢名单占掉。

模组后期是另一回事：新维度、新终极矿、新 Boss。加系统能把终局再延长，也可能把终局收回模组作者手里——你在别人的世界里毕业，毕业证是别人印的。收编原则留给第 13 章。本章只要承认：正作的终局策略是留空。留空看起来像没做完；没做完是产品策略——起源章写过，这里它再次生效。

可被证伪的说法是：给一个真正的最终 Boss、真正的新游戏+，玩家会觉得 Minecraft 终于完整。完整的游戏很多。完整往往意味着你不该再住下去。这台机器的完整，是承认自己不完整。不完整，才被居住、误用、再开发。

<Constraint name="终局留给玩家" verdict="地基" chain="仪式可忽略 → 官方只给物与地址 → 基础设施由玩家写">
没有结局，不是缺少高潮。是高潮不收回存档。收回存档，自愿目标无法延长；只给烟火，不给句号，冰道才有地方铺。
</Constraint>

<Memoir title="打完龙的那天晚上">
字幕滚完，有人在末地放床——然后床炸了。有人已经在想冰道从哪铺。仪式很响。响完，世界把时间还你。还你的那几小时，才像后期的开头。
</Memoir>

## 这一章留下什么

- **爱好者**：「通关」可以当笑话讲。讲完你还在铺路，说明结局在你手里。末地是变体，是交通，是仪式现场，不是最后一关。
- **开发者**：能抄走的是「用规则变体和可忽略建议延长自愿目标」——维度换法律不换动词，进度当手指不当铁轨，后期给物与地址。抄不走的是：玩家已经用十年把终局写成工厂和日历；你若用真正的关底把存档收回，他们会觉得被毕业，而不是被成全。没有结局好做。敢把结局留给别人，难。

[^dim]: 下界与末地是独立维度，有各自的生成、传送门与规则差异（如下界床爆炸、水蒸发）。见 [The Nether](https://minecraft.wiki/w/The_Nether)、[The End](https://minecraft.wiki/w/The_End)。

[^adv]: Java 进度按世界存储，1.12 取代成就；可用数据包改写。Bedrock 成就按账号 / 平台，开作弊或创造通常使该世界无法再解锁。见 [Advancement](https://minecraft.wiki/w/Advancement)、[Achievement](https://minecraft.wiki/w/Achievement)。

[^late]: 信标由凋灵星和金字塔激活；鞘翅在末地外岛的末地船取得。见 [Beacon](https://minecraft.wiki/w/Beacon)、[Elytra](https://minecraft.wiki/w/Elytra)。
