> **本章命题**：好模组不自动进正作。正作该吸收的是新动词和可误用物理；不该吸收的是会替换目标的文明。整合包证明策展也是设计。运行时编辑器是加系统，不是第五种游戏模式。

## 问题

「这个模组这么好，为什么不直接进游戏？」这句话每年都有人问。问的人常常已经在用：管道在替库存走路，法术在污染周围的环境，任务清单在替你排今天的活，选区在替你预览改动。好，是真的。进正作，是另一件事。

卷一把第二条作者席写成产业史：正作卖掉的是内核，收编挑的是动词（[《模组作为第二作者》](/history/mods-as-authors)）；活塞进了，电网作为主菜没有进。本章把史实收成方法。要回答：正作该吸收什么、不该吸收什么？可被证伪的说法是：社区验证过的系统，官方迟早该收编；不收是怠惰或傲慢。只要还看见收编电网会把空循环收成产线、收编编辑器会把创造收成另一款软件，这句话就不成立。好，不等于该成为默认。默认会改所有还没装这个模组的世界。

## 「好模组为什么不直接进游戏」

好，是对某一群玩家、某一份整合包、某一台创造服成立。进游戏，是对所有尚未选择的人成立。两者的主语不同。模组的成功条件是可退出：你不喜欢这套电压，卸掉那几个 jar 文件，世界还在。正作的成功条件是不可退出而不改品牌：收进主菜的东西，会成为「Minecraft 是什么」的一部分，出现在教程、课室和家长的口语里。

所以「好」测的是局部深度。「该不该进」测的是会不会替换目标。工业包在模组里可以极深，深到成为一款以产线为主菜的游戏。那一款游戏寄生在方块上，仍然叫 Minecraft 模组。一旦官方把它做成默认，空循环的出口就不再是居住和误用，而是最优工厂。居住还在，只是住的人会被产线的最优解训斥。训斥不是社区的错，是默认文明的后果。

官方已经会收。收的方式不是「投票最高的进」。收的是能回到挖、放、看上的零件：多一只手，不多一套必须学会才能玩的语言。红石能进（[《红石：把物理做成编程》](/design/redstone)整章押在这上面），是因为它是可误用物理，不是因为它先有了社区模组。活塞能进，是因为它让这份物理长出「推」。命令和数据包能进，是因为关卡作者被请回官方的河道，而新动词仍被留在加载器一侧——这笔账，[《命令、数据包与地图》](/design/commands-datapacks)已经算过。

Bedrock 的「进游戏」还多一扇货架门。附加包可以上 Marketplace，走审核、走分成，看起来像收编，但合同是商品，不是立法席（[《两条产品线：Java 与 Bedrock》](/history/java-bedrock)记过这条产品线的分叉）。不要把「能买到」听成「进了正作」。能买到，是第三条河被收成货架；正作的动词表没有变。

可被证伪的说法是：只要 API 再稳定一点，所有好模组都会变成原版。API 再稳，也改变不了主语：模组对选择负责，正作对默认负责。选择可以极肥。默认必须继续空着一块，空循环才还是空循环。

## 加系统 vs 加内容

模组的成功至少有两种，不要收成同一种「加东西」。

**加内容**换的是皮和清单：新生物、新矿物、新结构、新一季的装饰。世界更满。动词还是那几个。官方自己也做加内容：1.6 的马几乎整套来自 Mo' Creatures，官方找作者合作请进了门——加的是一种牲口，不是一套语言。资源包、许多数据包、大量附加包走的也是这条路。路很正当。正当的尽头是内容包：玩完这一季，换下一季。Minecraft 的深度不靠这一季。

**加系统**换的是世界里可以发生什么：物品如何自己走路，能量从哪来，除了红石还有没有第二种因果，人除了物品还有没有等级。系统会训练玩家。训练一旦形成最优解，目标就从玩家手里回到作者手里。工业、魔法、RPG、运行时编辑器，都属于这一侧。成功的系统模组往往比正作「完整」。完整是对空洞的回答。空洞是正作的策略，不是疏忽。

漏斗是一次干净的对照。1.5 收进原版的是一只会吸物品的方块，不是一套电压。[^hopper] 你得到物流的一个动词：让库存自己走一小段。你没有得到必须维护的电网。走一小段，误用还在——漏斗钟、物品过滤器，乃至大规模漏斗拖出来的卡顿，都是玩家后来发现的用法与代价。电网一旦成为默认，走一小段会变成「你为什么不用管道」。1.21 的合成器是同一剂量：自动合成的一格，不是工厂主菜。[^crafter] 加系统的剂量，决定还是不是同一款游戏。

<Note>
加内容可以很多而不改身份。加系统加对了是新动词；加错了是新主菜。主菜一换，模组的好会变成正作的窄。
</Note>

运行时编辑器是加系统的考题，不是内容清单上的一项。Axiom 一类工具把选区、笔刷、实时预览做进正在跑的世界，多人还可以同时看见改动。[^axiom] 创造服和地图组需要它：一支笔刷顶几个人连着垒，比每人一格一格砌快得多，而冲突仍留在同一份存档上。需要，不等于它该成为第五种游戏模式。Bedrock 的官方编辑器把话说死了：这不是新的游戏模式，是给创作者用的工具。[^editor] 创造与编辑器的边界，[《创造模式不是关卡编辑器》](/design/creative-mode)立过：创造继续寄生生存的尺，编辑器则另开窗口、写回同一套格。窗口可以很强。把窗口叫做创造，等于用效率顶替那具还在世界里走动的身体——顶替之后，协作变成专业软件的权限问题，而不再是同一把尺上的共同作者。

所以「加系统」有两种合法出口。一种进正作：变成新动词或可误用物理，所有人默认拥有。一种留在工具层：给创作者和服主，不改居民的权限包。Axiom 走后一种才成立。走前一种，等于宣布建造的正确方法是离开身体。那不是吸收模组。那是换产品。

## 整合包：策展即设计

整合包不是「很多模组叠在一起」。叠在一起会炸：能量对不上，矿物重复，第一夜长成三个教程。能玩的包，是有人决定：哪些系统共存，哪些互斥，进度从哪一晚接到哪一条产线，世界生成要不要把矿脉收紧、把稀缺换成另一种模样。决定本身是设计。设计的对象不是新方块，是一张菜单：你将住在哪几种文明的交界上。

Feed The Beast 把这件事写成公众能看见的产品。它先是一张要靠模组才能打完的地图，后来长成以包为单位的发行：装的不是某一个工业模组，是「今晚我们玩这一整份世界」。[^ftb] 今天的整合包大多还带着一本任务书，把上百个系统的入门顺序排成一课一课；只是这门课没有期末考——你可以不交作业，继续住。 玩家口中的 Minecraft，有十年时间经常是某个包的名字。Curse 上的下载、YouTube 上的系列，教的是策展过的语法。语法能教，是因为有人做了减法：不是把所有好模组都塞进去，是把能一起活的留下来。

策展回答了正作拒绝回答的问题：结构空洞同时存在时，如何不让它们互相吃掉。正作的答案是：默认不填。整合包的答案是：填，但由策展人负责节奏。两种答案都是设计方法。第一种保护空循环。第二种把空循环收成一季。一季可以极好。一季不该成为唯一的正作。正作一旦自己策展成「官方工业包」，退出按钮就消失了。

Bedrock 的货架更像单件内容的策展，不像 Java 那种多系统共存的包。件与包都是选择。选择的设计师是第二作者的第二作者：整合包作者、地图主编、Realm 模板的人。官方若只看见「模组作者」，会看丢这一层。看丢之后，收编会找错对象——去收某一个电网，而不是去理解电网为什么必须被包着才好玩。

## 结构空洞：工业 / 魔法 / RPG

空洞不是 bug 列表。空洞是正作故意不回答的结构问题。第二作者补它们，是因为问题真实。正作继续留空，也是因为问题真实——真实到一旦回答，游戏会换种。

**工业**问：世界即库存之后，库存如何自己走路，功从哪来。管子、电压、过载，是一种完整回答。完整会把「今晚干什么」收成产线。正作给过漏斗、矿车、发射器，给的是动词，不是新陈代谢。新陈代谢一旦官方化，红石会降成产线的附属线路。附属线路仍可误用，误用不再是主菜。

**魔法**问：除了红石，世界还能否有另一种传导。节点、污染、仪式，是第二种物理。第二种物理要学一门新语言。正作偶尔收单个奇观：附魔、酿造、信标。奇观仍寄生在物品和格子上，不要求你改信一种法术经济。并列两门官方语言，等于宣布有正确的第二套因果。而红石的力量恰恰在于官方不教——[《红石：把物理做成编程》](/design/redstone)整章押在这句话上。再教一门，空会少一块。

**RPG**问：人要不要从搬运工变成数值容器。任务、职业、等级会把成长从世界里的物品，收进角色表。地图和数据包已经能扮演这一套，扮演仍然骑在同一只手上（[《命令、数据包与地图》](/design/commands-datapacks)）。完整技能树一旦进正作，目标外包会被进度外包替代：你不是不知道要干什么，你是还没点完那一页。不知道要干什么，可以是好评。点完那一页，是另一款游戏的好评。

三种空洞的共同方法是：**看见空洞，先问它是不是空循环的承重墙。** 承重的空，补上会塌。装饰的空，加内容即可。工业、魔法、RPG 在模组里是承重实验。实验允许失败、允许卸掉。正作不允许卸掉而不改口语。第 15 章会把「何时停手」写成总原则。本章只要一句：空洞能被模组证明存在，不证明正作必须填。

## 收编原则

可执行的意思是：拿着一个模组、一个建议、一次「社区都在用」，能判断进不进默认。进，指写进所有尚未选择的人的口语。工具层、数据包、Marketplace 货架，都不是这一句里的「进」。

**一、加动词或可误用物理，不加新陈代谢。** 推、吸、合成自动化的一格、把信号变成手，属于动词。电压网、污染循环、职业点数，属于新陈代谢。反例：把工业电压做成官方主菜。你会得到产线游戏。产线游戏可以伟大。它不再把目标外包给今晚那座还没想好的房子。

**二、写回同一世界，不另开游戏模式。** 结构方块、填充命令、选区，合法出口是写回格子。运行时编辑器合法出口是工具层。反例：把 Axiom 一类工地收成第五种游戏模式，或者反过来，把创造模式本身改造成一台编辑器。多人实时预览、笔刷这类工地效率，是创作者和服主的需求，不是对创造权限的否定。否定发生在你宣布「居民也必须用那只笔刷，建造才算数」的时候。

**三、收数据，不收目标。** 配方、掉落、进度、结构，可以进数据包。任务线、强制主线、把「你该干什么」写进角色，不进默认。反例：官方 RPG 技能树。地图工业已经能寄生同一物理来做这事。做成默认，等于把外包收回作者。

**四、不预装同意，不并列第二套必须学会的官方物理。** 领地、锁、反作弊，留给插件立法（[《规则由谁制定》](/design/who-makes-rules)）。魔法经济若与红石对等，玩家必须先入教才能误用。反例：原版默认地皮；以及官方主菜式的节点污染法术。前者把开放世界收成公寓。后者让红石变成选修课。

四条是筛子。筛子筛掉的，往往是「最好的模组」。最好，是因为它完整回答了空洞。完整回答，正是它不该成为默认的原因。活塞通过筛子，是因为它不完整：多一只手，文明仍由你发明。漏斗通过，是同一原因。命令方块通过，是因为它把钥匙交给运营者，不把任务交给所有居民。数据包通过，是因为它温和。电网、法术经济、技能树、作为游戏模式的编辑器，过不了。过不了不是它们不好。过不了是它们会换主语。

<Constraint name="收编加手不加文明" verdict="地基" chain="局部的好 → 默认的口语 → 空循环还空着">
模组对选择负责，正作对默认负责。默认只加能被卸掉意义的零件：卸掉之后，挖、放、看和误用仍在。卸不掉的文明，留在加载器、整合包和工具窗口里。
</Constraint>

<Alternative title="若把工业做成官方主菜">
管子进创造物品栏，电压写成教程第一夜，红石降成工厂附属。你得到更现代的沙盒、更好卖的「成长」，以及一条能讲给股东听的内容管线。你失去的是：没有产线时仍然成立的居住，以及模组作者用退出按钮保护过的多样性。官方工业包会很完整。完整的代价是，再做工业模组变成在正作里重复。重复不是生态。生态需要正作继续空着那一块。
</Alternative>

可被证伪的说法是：筛子等于保守，官方因此什么都不该收。活塞、漏斗、命令、数据包已经在反驳。该收的收了。不该收的，十年仍留在院子里——留在加载器和整合包里，被愿意装它们的人养得很好。院子不是失败，是方法。下一章把目标外包和涌现连起来：空着的那一块，不是还没做完的内容包。

## 这一章留下什么

- **爱好者**：你觉得该进正作的那个模组，多半是因为它完整。完整是它留在启动器里的理由。正作若把完整收成默认，你卸不掉，别人也躲不开。整合包已经让你选择文明。选择本身，就是设计。
- **开发者**：能抄走的是收编筛子——加动词或可误用物理，写回同一世界，收数据不收目标，不预装同意、不并列第二套官方物理；以及把运行时编辑器留在工具层，不要改成游戏模式。抄不走的是：你没有一条被无偿第二作者养了十年的河，来替你做完所有完整答案，同时让正作继续空着。你若见好就收，会收成另一款游戏，只是还叫沙盒。见好不收，才是方法。
