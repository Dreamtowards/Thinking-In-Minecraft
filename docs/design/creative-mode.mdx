> **本章命题**：四种模式是同一个物理引擎上的四种权限位组合，不是四个游戏；创造模式的意义恰恰来自它寄生于生存规则——免除稀缺，不免除物理。

## 问题

一个从未打过怪的纯创造玩家，和一个从未飞过行的纯生存玩家，聊起建筑毫无障碍：同一套方块语义、同一种尺度感、同一个「好看」的标准。如果生存和创造是两个游戏，这种共同语言从哪来？

## 为什么创造模式仍像在玩 Minecraft

创造模式没有替换动词，没有替换物理。红石机器在创造里照常工作，因为模拟照跑；建筑仍然遵守重力、流体与光照，因为你仍然一格一格地放。创造免除的只有稀缺：无限物品、免伤、飞行。

这一刀切在哪里是全部的关键。切在稀缺上，创造是「同一世界的免签区」；切在物理或动词上，创造就变成另一个软件。后一种可能性有一个现成的名字：关卡编辑器。

## 创造寄生于生存规则

做一个反事实实验：如果创造模式提供编辑器能力——框选一片区域、点「生成城堡」、任意曲线建模——会发生什么？产出的东西将脱离方块语言：生存玩家看不懂、学不会、建不出。两种玩家的共同语言当场断裂，建造从「可复述的文章」退化成「孤立的展品」（第 1 章的可复述性在此兑现）。

Minecraft 的选择是让创造**寄生**于生存的规则：产出与生存产出同构，一格一格，慢，但可读、可学、可复现。寄生不是缺陷，是设计——它保证模式之间的对话永远畅通。生存玩家仰望创造玩家的城堡，回家在生存里用木材复现一个简版：羡慕有渠道变成劳动，劳动有渠道变成作品。这个「模式间搬运」是社区建筑学繁荣的隐含结构。

## 无限资源的社会意义

生存里，资源是私有的：你挖到的钻石才是你的。创造里，资源是公共空气：人人都有无限的钻石块。这个差别改变的是建造的**社会意义**。

建造动机从「拥有」变成「表达」。你的房子不再只是财产的容器，而是审美的宣言。所以创造模式天然长出展示与协作的形态：服务器大厅、主城、展示馆、建筑团队、建筑比赛。多人创造的成本里，资源摩擦被清零，剩下的全是沟通——协作建造因此成为这款游戏里最朴素的共创活动（第 11 章回到社会设计）。

## 权限模型表

把四种模式拆成权限位，图像立刻清晰：

| 模式 | 生命 | 飞行 | 挖掘/放置 | 物品栏 | 可被伤害 | 对其他玩家可见 |
|------|------|------|-----------|--------|----------|----------------|
| 生存 | 有限 | ✗ | ✓ | 有限，需采集 | ✓ | ✓ |
| 创造 | 免死（虚空与命令除外） | ✓ | ✓ | 无限，全物品 | ✗ | ✓ |
| 冒险 | 有限 | ✗ | ✗（按地图规则） | 有限 | ✓ | ✓ |
| 旁观 | — | ✓（可穿墙） | ✗ | ✗ | ✗ | ✗ |

四种模式不是四种内容包，是**同一引擎的权限位组合**。冒险模式是「读者权限」——锁掉改写世界的手，保留使用世界的手，为地图作者而生；旁观是「幽灵权限」。真正的区分维度是「你能对世界做什么」，而不是「你能玩到什么内容」。

> **Note（双版本）**：权限的语义两版一致，平台化程度不同——Bedrock 生态里权限早已是产品：Realms 的成员管理、教育版 Classroom Mode 里教师实时调整学生权限。卷四的[网络、权限与社会功能下沉](../rewrite/network-perms)会论证：这张表不该由「模式」垄断，应当推广为通用权限模型。

## 对照：Studio、GMod、关卡编辑器

<Alternative title="创作与游玩分离的谱系">
UEFN 与 Roblox Studio 是「创作即编程」：另一套工具、另一种操作形态、更陡的作者门槛。GMod 介于其间：游玩是沙盒物理玩具，创作靠生成菜单——菜单式创造仍然是一堵小墙。传统关卡编辑器（Halo 的 Forge、Mario Maker）最诚实，直接承认编辑是另一个模式。Minecraft 的独特位置：创作与游玩共享动词与物理，身份切换成本约等于零，观众到作者的流动没有闸门——这正是总命题里「再开发」的低门槛入口。
</Alternative>

诚实地记下失去的东西：精确、批量、程序化。大型工程靠第三方蓝图工具补足，而这个需求官方用一个「补而不换」的姿态回应——结构方块提供的是网格语言内的复制粘贴，不是编辑器式生成。这个姿态可以当成本章命题的试金石：官方不断给创造加辅助，但始终不给它第二套动词。

## 这一章留下什么

- **爱好者**：创造和生存说的是同一种语言——你在一个模式里练出的美学，在另一个模式里照样算数。
- **开发者**：模式是权限位，不是产品分叉；让创造寄生于生存的物理与动词，「一个游戏、多种玩法」才成立。不可迁移条件：你的动词集必须小到在免除稀缺之后仍然有意义——动词繁多的游戏一旦免稀缺，会立刻退化成摆放练习。

模式作为权限的推论——服务器立法与领地政治——在[多人是默认状态](./multiplayer)与[规则由谁制定](./who-makes-rules)展开。
