> **本章命题**：买到的是客户端，玩到的经常是服务器。同一套挖、放、看，在创造、生存、小游戏三种社会里变成三种游戏。玩家成为运营者之后，立法权离开 Mojang；2014 年的崩溃证明，支撑这些游戏的桌子，比货架上的客户端更脆。

## 问题

许多人描述自己「在玩 Minecraft」，说的其实是某一串地址。

进服之后：有的在别人划好的地皮上盖展览，有的在阵营里抢资源，有的在等待大厅里排队打下一局起床。客户端还是那个客户端，循环还是挖、放、看。规则已经换了。上一章把第二条作者席写成模组与插件；插件一旦跑在一台 24 小时不关的机器上，作者席就变成**政权**。政权有法律、有经济、有驱逐权，有时还有排队和商店。这时再把 Minecraft 说成「一款沙盒」，等于把护照说成旅行。

本章要回答的不是哪家服更好玩。要回答：为什么很大一部分游戏不在客户端里？答案很不客气——因为官方把法律写得很薄，薄到必须由别人来写，才能让一群人在同一张图上过夜而不散。薄是起源处的减法在多人上的后果。空循环可以没有任务；空法律不能没有政治。政治不在 jar 里，在 IP 里。

可被证伪的说法是：服务器只是把单人档开给朋友，玩的仍是同一款游戏。只要还存在「这个服的玩法在原版客户端里根本开不出来」——没有插件就没有这套小游戏，没有领地就没有这种生存，没有无规则就没有这种考古——这句话就不成立。

## 买的是客户端，玩的是服务器

Alpha 的生存多人已经把门票和游戏撕开过一次：你买的是进世界的资格，进门之后靠信任硬扛。[^smp] 工作室化之后，撕裂被制度化。客户端是 Mojang 的 SKU：一次买断、会更新、有龙可打。服务器是别人的进程：规则、插件、经济、地图、能不能说话、死了掉不掉东西，全可以改。同一份付款，通向无数个游戏。

「法律写得很薄」可以数得很具体。一个不装任何插件的官方服务端，拿得出手的管理工具是：server.properties 里几行开关、一份白名单、一份黑名单、几级 OP、一个封禁名单。它管得了谁能进门、谁能踢人，管不了门口的地皮归谁、箱子里的东西归谁、家被人半夜拆了找谁说理。产权、程序、货币、公共工程，一样都没有。Alpha 章说过早期多人靠信任硬扛；到成百上千人的规模，信任不够用了，薄法律就成了一张空白支票。

客户端在此降格成运行时，是有技术根据的。多人时，客户端只负责把你的点击和朝向送上去，把服务器的裁决画出来；方块被谁保护、钱记在谁的账上、谁能进哪扇门，全由服务器说了算。所以换掉裁决者不需要玩家换客户端——上一章插件河的全部可行性，就压在这条分工上。运行时越薄，服务器上能写的法律越厚。这不是 Mojang 的失职，是协议本来的样子；但设计后果归设计：薄运行时养出了厚政权。

发现层同样不在产品里。游戏内的多人界面只认你手动添加的地址；玩家真正「逛」服务器，靠的是第三方列表网站：排名、横幅、在线人数、一段简介。服主在这里像发行商，买位置、拉投票；玩家在这里像逛货架，按人气挑一个世界住。很多服务器干脆把投票做进玩法：敲一条投票命令，换几颗钻石——把分发渠道的规则内化成自己的经济。这一整套商店与营销，官方产品一概不知情。在列表里，一个服务器只有一行欢迎语和一个在线数字；那行字就是门面，门面后面是另一款游戏。

门面、账单、运行时——这些都不只是技术隐喻。对大量玩家，启动器点开之后真正的主菜单是多人列表，真正的存档是服主的磁盘。单人档当然仍在，而且很重要；它不再是产品的重心。重心跟着人走。人去哪，游戏在哪。人去 Hypixel，游戏就是大厅和队列；人去一个十人生存服，游戏就是今晚谁上线、谁的箱子还在；人去无规则服，游戏就是还能不能活着离开出生点。

服务器还是一份真实的硬件账单。原版服务端以每秒 20 刻的节拍点名，主体几乎是单线程的：多少人同时在线、视野半径开多大、实体和红石堆多密，最后都折算成一台机器的预算。运营者因此都在做玩家从不见到的取舍——限制人数、预生成地形、定时清实体、把世界分散到多台机器再由代理缝合。这些运维决定直接就是设计决定：限 50 人还是限 500 人，决定了这个社会的密度和味道。卷三会拆刻与并发的账；本章只记一件事：在客户端这边免费的东西，在服务器那边都有价格，价格会写进法律。

官方并非不知道。Realms 后来把「和朋友住在一起」收成可订阅的温顺版本，等于承认多人是需求，也承认完整的运营者不该默认交给每个买家。温顺版本解决的是家庭；解决不了三种社会。三种社会需要的不是官方代管的小房子，是立法权。立法权一旦交出，客户端就降成运行时——薄薄一层，负责把方块画出来、把点击送上去。运行时可以很赚钱。游戏在别处。

Java 之外，门票的形状也不同。Bedrock 侧的主机和手机玩家进的是「精选服务器」：一张 Mojang 审核过的名单，想被看见先要被翻牌子。Java 这边没有名单，任何服主都能在列表网站上自我陈列，边界全靠自己立法。同一个「服务器即游戏」，一边要过审，一边要自谋，说明它是这套空法律撞上的结构性空间，不是某次更新的特性。本章默认 Java：插件河在这里最深，服务器作为新游戏也最彻底。

## 三种社会

同一引擎上，至少住过三种社会。它们共用方块，不共用宪法。

**创造社会**把生存的牙齿拔掉，留下尺度和积木。地皮服、建筑服、创造大厅：资源无限或近乎无限，冲突从饥饿转到占地和审美。这是展览与公共工程。玩法是给别人看、和别人一起垒、有时是给影像当片场。创造模式自 Beta 1.8 起就是官方模式，创造服把它做成城市。工具也自成长辈：WorldEdit 一类的插件让管理员拿着一把木斧框住两个角，就能复制、粘贴、旋转整座建筑；地皮插件把世界切成一块块带道路的地皮，新人落在自己那一格，出生点于是像一座不断布展的美术馆。劳动甚至有了市场：成熟的建筑队承接委托，替商业服务器造主城和宣传地图——创造社会的产出，成了其他社会的门面。没有怪物之后，政治更干净，也更像论坛——谁的作品配留在出生点附近，谁的被清。挖、放、看还在，出口不再是「活过今晚」，是「这东西还在不在」。

**生存社会**保留牙齿，并且必须发明牙齿之外的法。原版几乎不提供领地、日志、法庭。箱子就是诱惑，墙就是宣言。于是出现插件：保护、经济、职业、传送、阵营。生存服看起来最像「还在玩 Minecraft」，结构上已经是城邦——有产权，有税收（玩法意义上的消耗与商店），有流放（封禁）。惯例老到可以按年代排：圈地插件发给玩家一把金铲，两个角一点就圈出受保护的地；基础插件给每个人回城、设家、请求传送这几条命令，多数人每天都在敲；牌子商店把「一块告示牌加一个箱子」变成柜台；查证插件能翻出「这个方块是谁、什么时候挖的」，回档把损失整段倒带。阵营插件走得更远：成员有「势力值」，死了会掉，能占多少地跟着势力值走——国境线因此是活的，外交与偷袭全在里面。有人把插件加到几乎认不出原版，有人标榜接近原版、只加防熊。光谱的两端玩的都不是客户端里那份默认法律，因为默认法律就是几乎没有法律。Alpha 夜里靠信任；信任扩不进几百人。扩的时候，不是游戏变了，是国家出现了。

**小游戏社会**把世界切成一局一局。大厅、队列、重置、计分。把一局切开需要一整套官方没有的基建：大厅是一台常驻机器，负责站着不动；队列决定谁跟谁玩；真正的对局发生在预建好的地图上，一局结束整张图重置，下一批人接着用。几十台这样的机器被一层代理（BungeeCord 一类）藏在同一个地址后面，玩家以为自己在进「一个服」，其实是在几十台机器之间被调度。更要紧的是存档换了地方：等级、货币、解锁的外观，不在任何一张地图里，在网络的数据库里。世界成了耗材，账号成了存档。这是三种社会里离原版生存最远的一种——远到「存档」这个词都得重新定义。2012 年《饥饿游戏》电影上映，生存竞赛插件一夜铺开，是这一社会的第一次大众化；床战一类模式后来成了整个行业的招牌，一局几分钟的胜负，背后是几台机器和一整套赛季经济。无限被关掉了。官方十年没把这些做成主菜单上的模式，它们照样成为许多人的 Minecraft。不是因为官方疏忽，是因为空循环允许把生存剥成竞技，而竞技需要重置，重置需要运营者，运营者需要一台不是「你的存档」的服务器。

三种社会可以共用一个 IP，用传送大厅假装是一个国家。那只是联邦。联邦内部，游戏不同。三种社会的分工还可以从劳动看：创造社会生产展示品，生存社会生产邻里，小游戏社会生产胜负；对应的三种劳动——建造、维护、重置——在正作里都不存在全职位置，在服务器上全是全职劳动。说「Minecraft 是平台」的人，指的往往是这一点：引擎之上的三种社会，各自养活了一整层没有名目的职业。评测哪家大厅更花，没有意义；有意义的是：同一套挖、放、看，被三种宪法写成三种游戏。客户端对此几乎无言。无言就是把设计权交给运营者。

## 极限样本：Hypixel 与 2b2t

两个极限，各把一种政治拉到不能再装成「只是多人」。

**Hypixel** 把小游戏社会做成产业。2013 年 4 月 13 日公开，起点却是冒险地图和 YouTube：两个人做地图给人看，服务器本是展览的附属，大厅里的小游戏是排队时的消遣。消遣反过来吃掉了主菜。[^hypixel-wiki] 地图作者变成发行商，等待变成产品。这是设计史上很狠的一次翻转：内容（地图）输给了循环（再来一局），循环必须靠运营而不是靠官方更新。客户端在这里薄得像播放器。真正的游戏设计发生在插件、匹配、经济、赛季和商店政策上。2017 年 7 月 7 日 Guinness 记下同时在线 64,533 人；后来高峰还更高。[^hypixel-gwr] 数字只说明体量。体量证明的是：有人用 Minecraft 当引擎，做出了 Mojang 没做的那款多人游戏，并且做成功了。称它为「Minecraft 服务器」已经词不达意。它是寄生在门票上的另一款游戏。寄生不是贬义。空循环允许寄生，允许到这种程度，才叫媒介。

寄生的深度可以再量一层。在 Hypixel，你的「进度」不是一张地图，是账号数据：等级、货币、解锁的外观、连胜纪录。地图一局一换，账号十年是你。2019 年上线的网络版空岛生存更进一步，把持久岛屿、生产链和玩家交易做成一个挂在 Minecraft 引擎上的经济模拟，上线后长期占着全网最大的在线份额——官方十年没做大型多人在线，社区用官方的引擎把它做进了服务器。卷三会写这一切靠多少台机器和多少工程勉强撑住；这里只记设计事实：当「存档」被搬进服务器数据库，客户端就彻底只是播放器。

**2b2t** 把生存社会的法律抽到接近零。2010 年 12 月就出现的无政府服，几乎不立法：破坏、欺骗、修改客户端，只要不把服本身玩崩，多半算玩法。[^2b2t] 出生点是废墟，远行是政治，历史是谁还记得哪座基地的坐标。不要把它写成猎奇景点。它是一场持续十几年的实验：**把官方那套空法律当真，世界会变成什么。** 答案不是自由的乌托邦，是记忆本身成为战场——能留下的东西必须藏、必须骗、必须离出生点足够远。Grief 在 Alpha 里是事故，在这里是气候。

气候也有自己的基础设施史。2016 年，一位 YouTuber 的探访视频带来几倍于原人口的涌入，这台从不排队的服第一次排起长队；管理员随后做出无政府史上最讽刺的一笔——排队本身可以付费插队。被拒绝的秩序，以基础设施的名义回来了。同一时期，复制漏洞让一些「本不该存在」的物品流入世界，成为老玩家的硬通货和身份记号；出生点的废墟一层压一层，像地层一样记录每一波人的来去。这个实验还顺带控了变量：同样的引擎、同样的空法律，只撤走运营者——撤走的不只是保护，还有时间感。没有备份和回档，损失就是永久的，「远行」「藏匿」「口口相传的坐标」因此全部获得重量。这些不是花边：无规则服证明的恰恰是，哪怕拒绝一切法律，人口压力也会逼出制度——只是制度长在队列、客户端和废墟的形状里，而不在规则条款里。有人把无规则玩成自我神话，那是他们的事。对本书，2b2t 只提供一个对照：Hypixel 把立法权用到极限，做出新游戏；2b2t 把立法权弃到极限，让旧世界露出骨头。两边都不是原版。两边都比原版更能说明多人是什么。

两个样本都依赖第二作者：一边是海量插件与自制玩法，一边是反作弊缺席和社区客户端。没有 Bukkit 那条河，Hypixel 长不成这样；没有「官方不管」的缝，2b2t 也活不成这样。极限不是例外，是光谱的两端。中间那些中型生存服、创造服、家族服，只是把立法调在不同刻度上。

## 玩家成为运营者

服务器把一种官方没写进教程的职业生产了出来：服主。

服主手里是 OP、控制台、插件文件夹、备份、名单。这不是「高级玩家」。这是立法、司法、财政，有时还有城市规划。插件是法典：WorldGuard 一类的东西把方块变成可登记的财产，权限插件把人分成能进哪里、能用哪条命令。经济插件把钻石从物品变成货币。排行榜把时间变成荣誉。封禁是流放。回档是时间旅行当司法工具——这比原版任何一条命令都更像「管理一个地方」。

文官制度也随之自发形成。多数中型服务器有一套没人写进章程却彼此相似的官制：服主之下是管理员，管理员之下是志愿的巡查；新人先跟几周取证记录，学怎么跟刚被拆家的玩家说话。职务是志愿的，账单是真金白银的——主机按月付费，流量和备份都是钱。于是运营者的另一副面孔是商人：投票奖励换活跃，商店卖外观、卖会员，在 2014 年之前也大量卖直接影响对局的东西。这套半志愿半生意的结构，就是后来 EULA 风暴打中的那个东西。

这门手艺也写进了简历。一代服主从中学管到成年：招人、排班、调解纠纷、看账、应付托管商和广告商——没人给他们上过管理课，插件文件夹就是教材。头部插件在分发平台上的下载量以百万计，每个数字背后都是某台服务器把它装进法律的那一刻。官方从未认可过这门职业，也从未否认过；它只是庞大到无法假装不存在。

于是出现官方设计从未承担的问题：谁来写公平，谁来抽成，谁来处理半夜把别人家夷平的人。有人写成家庭公约，有人写成公司规章，有人写成无规则。无论写成什么，设计者都不再坐在斯德哥尔摩。设计者是那个付主机账单、被玩家在论坛上骂、决定明天还开不开机的人。Cave Game 把关卡设计师的位子交给每个拿镐的人；服务器把国家设计师的位子交给愿意运维的人。人数一过信任半径，拿镐的人必须服从运维的人，否则社会散掉。这不是背叛沙盒，是沙盒在多人里活下来的方法。

运营者还会变成商家。门票是 Mojang 的；服里的通行证、称号、箱子钥匙，是服主的。2014 年 Mojang 收紧 EULA、限制用 Minecraft 卖会改变玩法的道具，直接打在这个新职业的钱包上。[^eula] Hypixel 一类网络改过商店结构，把优势往外观和便利上挪。[^hypixel-eula] 细节留给灰色经济那一章。这里只要看见权力：官方一旦想起门票之后还有游戏，第一反应是立法限制运营者，而不是把运营者做进正作。限制是承认。承认服务器上跑着另一款会赚钱的游戏。

可被证伪的说法是：服主只是技术客服，不参与设计。只要还存在「换服等于换游戏」——同一账号、同一客户端、不同宪法——服主就是设计师。客服不写宪法。

## Bukkit 危机：基础设施比游戏脆弱

2014 年秋天，第二游戏的桌子塌了一角。

EvilSeph 宣布难以继续维护 Bukkit，理由包括法律灰区和 EULA。Dinnerbone 说 Mojang 拥有 Bukkit，且它不是官方 API。然后 Wesley Wolfe 的 DMCA 把 CraftBukkit 及其衍生从网上掀走。上一章写过这条法律死结：GPL 劳动缠着专有服务端。[^bukkit-dmca-ch4] 本章要写的是后果。插件河不是锦上添花。它是成千上万个「真正的游戏」的运行时。运行时一停，大厅不能开局，领地插件不能编译，生存城邦的法律编译不过去。货架上的客户端还在卖，龙还能打。新游戏先死。

塌的方式值得细看。下架的不是一个游戏，是整片多人生态的共同地基；插件作者一夜之间发现自己站在没有产权证的土地上，几万个服的升级路径同时断掉。倒是网络的门面层最先恢复常态：BungeeCord 一类的代理是独立写成的代码，没有缠进那份许可死结，大厅照常把人分进后端——世界的入口没事，世界的法律没了。

这就是脆弱：官方产品是一个会更新的 jar；社区产品是一叠没有合法继承结构的叉子。Spigot 后来用绕开直接分发的办法把桌子重新支上——构建工具让每一位服主在自己的机器上把官方文件和补丁组装起来，成品不经过任何人的网盘；Paper 继续往性能里走。[^spigot] 同期还有 Sponge 等重新起稿的 API 尝试，说明社区已经不指望那张许诺过的桌子，开始自己画图纸。它们救的不是情怀，是已经住进去的社会。社会比客户端贵，因为社会里有人的夜晚、箱子和赛季。官方当时拿不出替换用的第一公民 API——2012 年许过。许诺空窗期，社区用非法学上拧巴的方案填上；拧巴被揭穿，空窗变成停电。

把 2014 年只写成「开源纠纷」，太小了。它是一次压力测试：**媒介的一半不在公司的构建流水线里。** 测试结果是：这一半可以在几天内从公共互联网消失，而正作的 SKU 不受伤。对玩家，受伤的是他们正在玩的那款游戏。对本书，证据齐了——很大一部分游戏不在客户端里，所以客户端还在的时候，游戏仍可以停。

下一章离开进程，去影像那一章（[《影像、教育与一代人的媒介》](./media-education)）。服务器是人住的地方；视频是人学会住进去之前，以为 Minecraft 长什么样的地方。两者都在正作之外写游戏。

## 这一章留下什么

- **爱好者**：你若主要在某服上线，你玩的就是那服的宪法，不是货架说明书写的那种生存。原版多人只是缺省的无政府雏形；有人把它做成大厅，有人把它做成废墟，有人把它做成十人晚饭。三种都是 Minecraft 被允许长成的样子。
- **开发者**：能抄走的是「门票与游戏分离」——运行时可以薄，政体必须有人写。抄不走的是：你可以靠无偿运营者和一条许可拧巴的插件河，把内核做成上万人同时在线的另一款游戏，直到 EULA 和 DMCA 同一年打过来。若你的设计把多人当成「把单人档开给朋友」，你设计的是 Indev 的盒子，不是这个媒介。真正的多人从立法开始。立法不在客户端里。
