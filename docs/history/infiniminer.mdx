> **本章命题**：Cave Game 的关键操作不是「加上了方块」，而是丢掉了目标、过重模拟和作者关卡，只留下可破坏、可放置的空间。挖、放、看已经是一个完整循环；未完成是产品策略，不是缺陷。

## 问题

2009 年 5 月，Notch 在论坛上放出一段能跑的东西，自己都管它叫 Infiniminer 的克隆。体素、第一人称、能挖、能建——旁观者看一眼，分类就结束了：又一个矿工游戏。

这个分类后来变得很碍事。它让人以为 Minecraft 的起源问题已经有了答案，剩下的只是「克隆得更成功」。可同年 Infiniminer 源码泄露之后，克隆并不稀缺。它们大多原样保留了比赛、队伍和「把矿挖出来就是赢」。没有第二个变成后来那种东西：一个可以住进去、误用、再开发的世界。

所以真正要问的不是「方块从哪抄来」。要问的是：它从哪些既有形式里长出来，又丢掉了什么？丢掉的那一批，比保留的那一批更能解释它后来变成什么。

## 「抄了 Infiniminer」为何解释力不够

Infiniminer 是 Zach Barth 做的一款团队挖矿游戏。地形是体素，可以打穿、可以垒墙，矿物有价，队伍有分，一局有胜负。它证明了一件非常具体的事：**把三维世界切成可破坏的块，战斗和建造可以发生在同一套空间里。** 这不是小发明。Minecraft 确实从这里拿走了手感的第一口：第一人称、方块、镐。

但 Infiniminer 的体素是为比赛服务的。地形是赛场，矿物是分数，建造是工事。赛场可以改，改的目的仍是赢下一局。源码泄露之后，沿这条路走下去的克隆，几乎都停在「更好的矿工比赛」附近。它们把方块抄对了，把比赛也抄对了，于是发明结束了。

Notch 自己用「克隆」当简介，是当时最短的句子，不是最准确的句子。准确的说法更别扭：他拿走了赛场，丢掉了比赛。没有胜负的体素世界，看起来像少做了半个游戏。少做的那一半，后来变成了产品。

如果「抄了 Infiniminer」足够解释 Minecraft，我们会看到一丛彼此相似的矿工游戏，而不是一个被模组、服务器和十年存档反复再开发的媒介。解释力在减法上，不在外观上。

## 前史：可破坏空间，以及目标

体素沙盒不是 2009 年才有祖先。几条更老的河已经把「可破坏的空间」玩过了，只是各自绑着很重的目标。Cave Game 几乎是沿着这些河往回走，把绑在空间上的目的一件件卸掉。

**Infiniminer：空间是赛场。** 上面说过，它的可破坏性服务于一局游戏。你挖穿一座山，是为了更快摸到矿、或者给对方制造麻烦。空间有记忆，记忆的单位是「这一局」。局结束，记忆作废。Minecraft 后来让记忆活过引擎、活过版本、活过十年，那是后话；在起源处，它先做的决定是：不要局。

**Dwarf Fortress：空间是模拟。** Toady One 的要塞把世界当成一台几乎不肯停的机器——地质、液体、温度、历史、每个矮人的脾气。可破坏、可建造，只是模拟的皮肤。玩家的目标很硬：让这台机器别把自己玩死，顺便长出故事。「Fun」是反话，也是设计：失败是内容。Minecraft 拿走了「世界自己会出事」这个气味——重力、熔岩、黑夜后来都是这个气味的薄版本——但丢掉了过重模拟。没有一百个 dwarves 的需求列表，没有把文明史生成当作主菜。它付不起、也不想付那笔认知税。DF 把深度做进模拟器；Cave Game 把深度留给玩家在空规则里发明。

**Roguelike：空间是地下城。** 网格、程序生成、死亡很疼、下去是为了更深。房间也许不是关卡编辑器里摆出来的，生成器却仍在扮演关卡设计师：它给你一条可以「通关」的路径，一套成长，一个底。可破坏性在这类游戏里常常是局部的——挖墙有时可以，世界并不因此变成你的仓库。Minecraft 拿走了网格和「每次进去都不一样」的许诺，丢掉了地下城作为主目标。没有下一层等你去赢。死了掉东西，世界还在。这一点后来被生存模式写得很清楚；在 Cave Game 里，它已经是缺省：这里没有地牢的底。

还可以再点一个 Notch 自己背上的包：**Wurm Online**。那是更早的持久世界，技能、研磨、领地，目标又密又长。Cave Game 不是从零发明「能住的世界」，它是从太重的世界里逃出来。持久可以留下，研磨和任务树先卸掉。

三条河加自己的旧作，卸掉的是同一类东西：

1. **目标。** 比赛、要塞胜利、通关、技能成长。不给「你应该做什么」。
2. **过重模拟。** 不为了真实去生成一整台世界机器。规则要少，少到能被误用。
3. **作者关卡。** 不要设计师摆好的房间，也不要生成器扮演设计师。空间先空着。

留下的也是同一类东西：可破坏、可放置、人站在里面。形式祖先提供的是这种空间的可能性；Minecraft 的起源动作是拒绝为这种空间配上剧本。

可被当场反驳的说法是：Cave Game 其实有隐含目标，只是没写在屏幕上——「活下去」「建房子」「挖到最底层」。玩家后来确实给自己写了这些。那是玩家干的，不是游戏发的任务。游戏若在第一天就用任务、分数、关卡把这些写死，后面的居住和误用会窄一圈。窄到什么程度，是可以争的；「从来没有卸过目标」则与当时能玩到的东西不符。

## Notch 的工作方式

这一节只取对起源有用的部分，不当传记写。

他用 Java，是因为那是他能在很短时间里交出一个能跑的 3D 程序的语言。LWJGL 把窗口、输入和 OpenGL 接到手边。语言选择在这里是工期选择，不是美学选择。后来有人把 Java 说成 Minecraft 的命运，那是把 2009 年的便利写成了本质——卷四会拆这件事。起源处只需要承认：周末能见着方块在动，比「将来要优雅」更先决定形态。

失败作和游戏 jam 训练的是同一种肌肉：先让循环转起来，再决定它是不是游戏。Cave Game 看起来像随手一扔，其实符合这个节奏——先有挖和放，没有数值表，没有任务机，没有「内容」。Jam 的习惯也解释了为什么它敢公开：半成品本来就是工作单元，不是见不得人的中间态。

从 Wurm 里他已经见过持久世界一旦目标密起来，会变成一份多重的工作。Cave Game 往相反方向走：同一类空间，少到几乎不像产品。这不是突然的天才，是做过重活的人在卸货。

## 最小循环：挖、放、看

Cave Game 能玩，是因为三件事已经闭环。

**挖。** 世界的一部分离开原位，变成你能带走的东西。破坏不是特效，是搬运的开始。

**放。** 你手里的东西回到世界，成为别人（或过一会儿的你）还能再挖的东西。建造没有单独的编辑模式，没有「现在进入创造」的仪式。手还是那只手。

**看。** 第一人称把空间当成风景，也当成可操作的对象。看不是过场。阳光、洞穴、自己刚垒的两块方块，已经构成反馈。没有任务栏在告诉你这景色值多少分。

三件事合在一起，是一句更硬的话：**世界即库存。** 地上的方块和背包里的方块是同一种实体的两种位置。你不是在「收集资源去升级角色」，你是在把世界从一个地方挪到另一个地方。角色几乎透明——没有技能树可长，没有职业可点。强是因为你改过地形，不是因为你升过级。

这就是为什么「少了目标」没有让循环空转。循环的产品是一块被改过的地。改过的地可以再改。再改不需要游戏承认你赢了。卷二会把网格写成度量衡、把动词写成杠杆；起源章只需要记下：这些后来被分析成设计原语的东西，在 Cave Game 里已经是能玩的最小集，而且是靠减法得到的。

对照很清楚。Infiniminer 也挖也放，但循环的出口是比分。DF 也挖也建，循环的出口是要塞的生死。Roguelike 也走网格，循环的出口是下一层或死亡。Cave Game 的出口是还在那里的世界。你合上游戏之后，它并不把这局作废。

## 「未完成」是产品策略

Cave Game 公开的时候，缺的不是润色，是一整类通常用来定义「游戏」的部件：结局、关卡、任务、数值成长、甚至明确的失败。按产品清单看，它没做完。按循环看，它已经完整。

把未完成当成缺陷，后面的故事只能写成「然后他们把游戏做完了」。这与事实相反。正式版是仪式，系统并没有在某一天闭合。真正被保住的，是起源处那个决定：先让人进到一个能改的世界里，剧本以后再说——而「以后」可以无限延后，延后本身变成了玩法。

公开，是这个策略的另一半。半成品放在别人眼前，别人会开始往空规则里填目标。填的过程就是共同作者，不必等工作室开会批准。下一章会写 Alpha 如何把这件事收成周更和付费；在 Cave Game，它还只是一个姿态：能跑就给人玩，玩的人会告诉你这是什么游戏。

可被证伪的说法是：未完成只是没钱、没时间的权宜，一旦有了 Mojang 就会把目标补回去。后来确实补过——饥饿、进度、终点龙。每一次补，都引发「这还是不是那个游戏」的争吵。争吵本身证明：空着不是空窗期，是产品的一部分。若没有人在意目标被补回去，起源处的减法就只是工期。

## 丢掉的三样，留下的一件

从 Infiniminer、Dwarf Fortress、Roguelike 和 Wurm 里，Cave Game 没有发明可破坏空间。它发明的是一种更窄的用法：空间还在，剧本卸掉。

丢掉的是目标、过重模拟、作者关卡。留下的是挖、放、看，以及「世界即库存」。未完成不是没做完的羞耻，是让后两样能继续空着的策略。

以后所有「Minecraft 是不是游戏」的争论，都从这里分叉。说它是玩具的人，看见的是被卸掉的目标；说它是媒介的人，看见的是被留下的空间。本书站在后一边——但后一边必须先承认，前一边描述的减法是真的。没有那次减法，克隆只是克隆。

## 这一章留下什么

- **爱好者**：它不是「方块版的某款矿工游戏」。你熟悉的那种没事可做、只好自己找事做，不是内容没做完，是起源处就把事从游戏里拿掉了。
- **开发者**：抄体素很容易，抄「不要目标」很难——因为产品清单会逼你把目标加回去。能抄走的是最小循环；抄不走的是敢把比赛、模拟和关卡同时卸掉、还公开让人玩。下一问是：这个空循环，怎样靠更新把自己活成产业。
