这一卷先不急着总结“Minecraft 为什么成功”。成功这个词太容易把结果倒写成原因。

更值得追的是另一条线：2009 年的 Cave Game 为什么没有停在一个有趣原型？公开开发、Alpha 玩家、模组、服务器、视频、Mojang、微软、Java 与 Bedrock、Marketplace……这些东西并不是一开始就设计好的统一蓝图，却一步步把 Minecraft 推出了普通产品的边界。

所以这一卷讲的是 **Minecraft 如何从一个游戏长成一个世界**。这里的“世界”既指玩家真正住进去、留下建筑和记忆的存档，也指围绕它生长出来的社区、工具、服务器、商业与文化生态。

## 四部地图

**第一部 · 起源（2009–2011）。**从 Infiniminer、Dwarf Fortress 与 Cave Game 开始，看一个极小的原型怎样通过公开开发、付费 Alpha 与不断试错长成产品。入口是[《从 Infiniminer 到 Cave Game》](/history/infiniminer)。

**第二部 · 成为文化（2011–2014）。**模组、服务器与影像开始成为“第二作者”。Minecraft 不再只是 Mojang 发布什么，玩家就在玩什么。入口是[《模组作为第二作者》](/history/mods-as-authors)。

**第三部 · 被收购之后（2014–）。**微软收购、Java / Bedrock 双线、版本治理与平台化，让“继续发展 Minecraft”逐渐变成一个长期治理问题。入口是[《微软收购》](/history/acquisition)。

**第四部 · 商业与遗产。**收入、Marketplace、服务器经济、竞争者与数字保存放在一起看：一个开放生态怎样赚钱，又为什么有些最重要的价值偏偏最难被平台完整捕获。入口是[《收入结构》](/history/revenue)。

## 怎么读这卷

本卷不是版本年表，也不是商业案例合集。历史材料的作用，是帮助我们区分三件事：哪些东西来自时代窗口，哪些来自具体设计，哪些是社区后来长出来的结果。

如果你更关心游戏设计，可以重点看第 4、5、6、12 章；如果更关心产品与商业，可以从第三、四部读起。真正重要的不是记住每个版本，而是看清：**Minecraft 不是在某一天突然“成为 Minecraft”的，它是被开发者、玩家、社区和平台共同推到今天这个位置的。**
