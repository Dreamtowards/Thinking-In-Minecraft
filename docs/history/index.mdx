description: 从 2009 年的 Cave Game 到全球性的游戏与创作生态，追踪 Minecraft 如何在开发、社区、平台与商业化中不断改变自己的边界。
---

如果把 Minecraft 的历史写成一张版本表，我们会得到一条很整齐的时间线：加入生存、加入下界、正式版、微软收购、Bedrock、Marketplace……但这些更新本身并不能解释，为什么一个如此简单的方块原型，最后会同时长出长期存档、模组生态、服务器社会、视频文化、教育产品和庞大的商业体系。

更值得追的是：**2009 年的 Cave Game 为什么没有停在一个有趣原型？Minecraft 又是在什么时候，不再只是 Mojang 手里的一款游戏？**

这卷关注的不是“每个版本增加了什么”，而是 Minecraft 的边界如何不断向外生长。最初，开发者决定世界里有什么；很快，玩家开始通过建筑、模组与服务器定义新的玩法；再后来，视频作者、平台、商业规则、微软与不同版本的治理，又继续改变什么能被创造、传播、交易和长期保存。

商业因此也不是历史最后突然出现的一章。从付费 Alpha 开始，Minecraft 就一直在回答同一个现实问题：一个开放、不断变化、越来越依赖社区的世界，要怎样成为可以长期维护的产品，又怎样在商业化时不把它赖以生长的东西一起收走。

所谓“从游戏到世界”，也有两层意思。一层是玩家真正进入、改造并留下记忆的存档；另一层则是围绕 Minecraft 生长起来的社区、工具、服务器、内容、规则与经济。前者让玩家可以在里面生活，后者让这个游戏不断拥有新的作者。

## 四部地图

**第一部 · 起源（2009–2011）：** 一个极小的原型怎样变成产品？从 Infiniminer、Dwarf Fortress 与 Cave Game 开始，看公开开发、付费 Alpha、玩家反馈和工作室化如何共同塑造早期 Minecraft。入口是[《从 Infiniminer 到 Cave Game》](/history/infiniminer)。

**第二部 · 成为文化（2011–2014）：** 当作者不再只有 Mojang，会发生什么？模组改规则，服务器改游戏，影像改传播；Minecraft 开始明显地在客户端之外生长。入口是[《模组作为第二作者》](/history/mods-as-authors)。

**第三部 · 平台化与治理（2014–）：** 一个已经属于全球玩家的游戏，要怎样继续变化？微软收购、Java / Bedrock 双线、跨平台、版本治理与 Marketplace，让开发逐渐从“继续加内容”变成长期的产品与生态治理。入口是[《微软收购》](/history/acquisition)。

**第四部 · 产业与遗产：** Minecraft 创造的价值最终流向哪里，又有哪些价值根本很难被平台完整捕获？收入结构、服务器经济、竞争与模仿、数字保存放在一起看，商业问题最后会重新变成一个历史问题：什么东西会留下来。入口是[《收入结构》](/history/revenue)。

## 怎么读这卷

按顺序读，你会看到一个原型怎样一步步扩大自己的边界；跳着读也完全可以。关心设计，可以重点看模组、服务器、影像与竞争者怎样改变“谁在设计游戏”；关心产品与商业，则可以从收购、双版本、Marketplace 与收入结构进入。

这卷不会试图找出一个足以解释 Minecraft 成功的单一原因。更重要的是看清：**Minecraft 的历史并不是一件作品越来越完整的历史，而是越来越多的人、工具与制度参与定义“Minecraft 是什么”的历史。**
