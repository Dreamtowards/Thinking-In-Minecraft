如果把 Minecraft 的历史写成一张版本表，我们会得到一条很整齐的时间线：加入生存、无限世界、正式版、微软收购、Bedrock、Marketplace……但这些节点本身并不能解释，为什么一个如此简单的方块原型，最后会同时长出长期存档、模组生态、服务器、视频文化、教育产品，以及庞大的商业与创作者生态。

**从 2009 年的 Cave Game 到全球性的游戏与创作生态，Minecraft 究竟是怎样一步步长成今天这样的？**

这一卷不寻找一个事后看来完美的“成功公式”，也不会把后来发生的一切倒写成 Notch 早已想好的蓝图。我们更关心这些东西是在什么时候、因为什么条件出现的：公开开发怎样让玩家提前进入未完成的游戏，模组和服务器怎样继续扩展它，影像怎样参与传播和记忆，平台与商业又怎样随着规模扩大而改变产品的边界。

商业也不是历史最后突然附加的一章。Minecraft 很早就开始收费，后来又有服务器、Realms、Marketplace、教育许可、区域发行和 IP 授权。这里真正值得看的，不是“商业有没有污染游戏”，而是一款持续十几年、又允许大量创作和交易发生在官方之外的游戏，最终形成了怎样的产品与经济结构。

所谓“从游戏到世界”，也并不是说 Minecraft 后来就不再是一款游戏。变化在于，玩家投入进去的东西开始拥有远超一次游玩的寿命：世界可以保存多年，服务器形成自己的历史，模组和工具继续改写玩法，视频又把这些经验传给从未进入过那个存档的人。围绕客户端生长出来的东西，逐渐和客户端本身一样值得写进 Minecraft 的历史。

## 四部地图

**第一部 · 起源（2009–2011）：** 一个极小的原型怎样变成产品？从 Infiniminer、Cave Game 和早期公开开发开始，看生存、合成、无限世界、多人、付费访问与工作室化怎样逐渐出现。入口是[《从 Infiniminer 到 Cave Game》](/history/infiniminer)。

**第二部 · 成为文化（2011–2014）：** Minecraft 正式发布以后，游戏并没有只沿着 Mojang 的更新日志继续生长。模组扩展系统，服务器重新组织玩法，视频负责教学、叙事和记忆；大量玩家认识的 Minecraft，从一开始就比原版客户端更大。入口是[《模组作为第二作者》](/history/mods-as-authors)。

**第三部 · 平台化与治理（2014–）：** 一个已经拥有庞大玩家与社区历史的游戏，要怎样继续变化？微软收购、Java / Bedrock 双线、跨平台与长期更新，让“继续开发”越来越需要同时面对平台差异、兼容成本和玩家已经投入其中的世界。入口是[《微软收购》](/history/acquisition)。

**第四部 · 产业与遗产：** Minecraft 创造的价值怎样在官方产品、社区服务器、模组平台和 IP 之间流动？后来者又分别继承了什么？当这些问题一路追到停服、旧版本和数字保存时，商业问题最后会重新变成一个历史问题：**什么东西会留下来？**入口是[《收入结构》](/history/revenue)。

## 怎么读这卷

按顺序读，会看到一个原型怎样逐渐变成产品、文化、跨平台品牌和长期生态；跳着读也完全可以。

如果你更关心**游戏与社区为什么会一起长大**，可以重点读模组、服务器和影像三章；如果关心**产品与商业**，可以从微软收购、Java / Bedrock、收入结构和灰色经济进入；如果正在思考下一代沙盒，竞争与遗产两章会把历史问题直接带向第四卷 Reinvention。

这一卷最后不会证明“Minecraft 成功是因为某一个秘密”。它更想留下一个历史上的事实：**很多今天看起来理所当然属于 Minecraft 的东西，在最初都不存在；它们是在开发、玩家实践、技术限制、商业扩张和时间积累中逐渐长出来的。**
