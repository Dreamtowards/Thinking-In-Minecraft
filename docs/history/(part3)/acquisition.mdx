2014 年 9 月 15 日，微软宣布以 **25 亿美元**收购 Mojang 和 Minecraft。消息很容易被压缩成一个戏剧性的画面：一个从独立开发者电脑里长出来的游戏，五年以后被世界上最大的科技公司之一买走。[^ms-announce]

对玩家来说，真正紧迫的问题却很朴素：

**明天打开 Minecraft，会有什么不一样？**

短期答案其实是：没有那么多。

Java 版继续更新，PlayStation、iOS、Android 和 Xbox 上的版本也没有被撤下。Jeb 早在 2011 年就已经接过 Minecraft 的主导开发，收购并没有在一夜之间把设计工作从 Notch 手里交给微软——那次交接三年前就发生了。

真正立即改变的是另一件事：Mojang 换了所有者，三位创始人离开，而 Minecraft 从此进入了一个拥有 Windows、Xbox、Azure、全球商店、账号体系和教育业务的大公司。

这两个尺度需要分开看。否则很容易把后来所有喜欢或不喜欢的变化，都简单归到“微软收购”四个字上。

## 为什么会卖

收购前的 Minecraft 已经远远超出早期小团队的规模。它有 PC、手机和主机版本，有庞大的服务器、模组和视频社区，也已经成为 Mojang 最重要的产品。

Notch 对自己的退出给出的解释很个人。他在收购公布后写道，自己并不想成为某种巨大文化符号，也不想承担这样规模的责任；交易完成后，他会离开 Mojang，回去做小项目和实验。他把理由概括成心理负担，而不是继续经营一家越来越大的公司。[^notch]

这并不意味着 25 亿美元无关紧要，也不意味着收购只是“创作者累了”这么简单。公司的其他股东、微软的战略判断、Minecraft 已经形成的商业价值当然都构成交易的一部分。

但它至少提醒我们，不必把这段历史写成一个简单的道德故事：独立作者原本纯粹，后来被金钱诱惑。

到 2014 年，Minecraft 早已不是一个人可以凭兴趣随时停掉的项目。它有员工、有合作伙伴、有不同平台上的玩家，也有一个围绕它工作的庞大社区。收购首先是一家已经成熟起来的公司的所有权变化。

## 微软看中了什么

微软自己的收购公告很值得读。

公告当然强调 Minecraft 是一个非常成功的游戏，但它同时把 Minecraft 称为一个由活跃社区推动的 **open world platform**，并特别提到微软在云、移动和跨设备连接上的能力。公告还明确表示，Minecraft 会继续出现在 PC、iOS、Android、Xbox 和 PlayStation 等平台上。[^ms-announce]

这和“微软买下一款 Xbox 独占游戏”的逻辑很不一样。

2014 年的 Minecraft 本来就已经跨平台。Pocket Edition 在手机上发展了几年，Xbox 和 PlayStation 版本也已经存在。微软买到的不是一个等待被移植出去的 PC 游戏，而是一个已经证明自己可以跨设备存在的品牌与产品体系。

<Note title="收购前已经发生的事">
移动版、主机版、社区服务器、模组生态和 YouTube 文化都早于微软收购。理解后来的变化时，最好区分“微软买下以后才出现”和“微软接手了一个已经在发生的方向”。
</Note>

因此，25 亿美元究竟“值不值”，不能只拿 Minecraft 2014 年客户端里有多少方块来衡量。微软得到的是 Mojang、Minecraft 品牌、已有产品的收入，以及以后继续开发、发行和扩展这个品牌的权利。

而那些无法直接写进资产负债表的东西——服务器社区、模组作者、视频创作者、玩家自己的世界——当然不会因为公司换了所有者就自动归微软所有。

这也是 Minecraft 收购最有意思的矛盾之一：**公司可以买下产品和品牌，却不能买下玩家已经围绕它形成的全部文化。**

## 最初几年，连续性比剧变更明显

如果只看游戏设计，收购之后最初一段时间其实没有发生一次清晰的“微软式转向”。

Jeb 和原有团队继续开发 Java Edition。2016 年的 Combat Update 引发了很大争议，但把攻击冷却、盾牌或鞘翅直接解释成微软收购的结果，并没有足够证据。Minecraft 在收购以前就已经从个人项目变成团队开发，Beta 时代也经历过大幅度的规则变化。

同样，跨平台也不是微软凭空发明的。真正值得注意的是：微软没有把 Minecraft 收回自己的平台，反而延续了 PlayStation、移动设备等既有版本。收购宣布时，这一点就被公开写进承诺。[^ms-announce]

这在大型第一方收购里并不是一个无关紧要的选择。Minecraft 的价值已经和“到处都能玩”联系在一起，如果突然切断其他平台，微软买到的反而会是一个被主动缩小的社区。

所以最早可以观察到的，不是“设计风格突然改变”，而是**Minecraft 作为跨平台产品继续被维持，同时逐渐接入微软自己的发行与服务体系。**

## Windows 10 Edition：新的发行路径出现了

2015 年 7 月，Windows 10 上线的同一天，**Minecraft: Windows 10 Edition Beta** 进入 Windows Store。已有 PC 版玩家可以免费领取，其他用户则可以通过微软的新商店直接购买。[^win10]

它并不是 Java Edition 的简单改名。

Windows 10 Edition 和 Pocket Edition 属于同一技术谱系，随后还开始支持彼此联机。微软因此在自己的桌面操作系统上拥有了一条不同于传统 Java 版的新路线：可以进入 Windows Store，可以使用 Xbox Live，也更容易和移动版靠拢。[^win10-crossplay]

这一变化很容易被写成“微软开始替换 Java”，但当时实际情况要复杂得多。Java Edition 并没有停止开发，Windows 10 Edition 也远没有立刻取代它。

更准确的说法是：**Minecraft 在 Windows PC 上第一次同时出现了两种不同来源的产品路径。**

一条继承早期 PC 版的历史、模组与社区；另一条沿着 Pocket Edition 的代码和微软商店体系向跨设备发展。

它们后来会演变成 Java Edition 与 Bedrock Edition 的长期并存。为什么最终不是“统一成一份”，而是形成两个都无法轻易放弃的版本，是下一章的问题。

## 从 MinecraftEdu 到 Education Edition

教育是另一条很能说明收购后变化的路线。

Minecraft 在进入微软之前就已经被教师使用。第三方团队 TeacherGaming 从 2011 年起运营 **MinecraftEdu**，在 Java 版基础上增加适合课堂管理的工具。

2016 年 1 月，微软宣布收购 MinecraftEdu，并在同年推出新的 **Minecraft: Education Edition**。[^edu-acquire] 正式版本加入 Classroom Mode 等能力，让教师可以查看地图、管理世界设置、给学生物品和传送学生。[^edu-launch]

这件事和“给原版加几个教育功能”不太一样。

学校购买软件时面对的要求和普通玩家不同：账号怎么管理，学生怎样登录，一间教室怎样部署，教师能否控制课堂，许可怎样购买。这些都属于机构产品，而不只是游戏机制。

收购后的 Minecraft 因此开始拥有一种过去比较少见的形态：它不只卖给玩家，也可以被学校作为一项正式的软件服务采购。

这正是微软能够带来的东西之一。它未必让“挖方块”本身变得更好，却能把 Minecraft 放进原先很难靠一个独立游戏工作室长期维护的组织环境里。

## 一个游戏开始变成一组产品

到了 2020 年，Mojang 把公司名称改成 **Mojang Studios**。官方解释得很直白：公司已经成为一个拥有多个地点、多个项目的团队，除了 Minecraft 本体，还有 Minecraft Earth、Minecraft Dungeons，以及电影等工作。[^mojang-studios]

这个变化可以看作 2014 年交易长期结果的一部分，但仍然需要注意时间顺序。

Minecraft 在收购以前就已经在做移动版和主机版，电影项目也早已开始酝酿。微软没有发明“Minecraft 可以成为一个品牌”这件事。它接手的是一个已经在向外扩张的产品，然后给这种扩张提供了更大的组织和发行能力。

后来 Dungeons、Legends、Education、电影等项目说明，Minecraft 这个名字逐渐可以出现在完全不同的产品上：地牢动作游戏、战略游戏、课堂工具、电影。它们共享世界观与视觉符号，却不需要共享 Java Edition 的完整玩法。

这也让“Minecraft 到底是什么”变得更难回答。

对老玩家，它可能首先是一份能运行十几年存档的 Java 游戏；对儿童，它可能从手机或主机开始；对教师，它甚至可能先是一套课堂工具。品牌变宽以后，不同入口看到的 Minecraft 就不再完全相同。

## 收购真正改变了什么

把 2014 年之后的一切都归因于微软，解释力太弱；假装收购只是股东名字变了，同样不对。

比较可靠的变化至少有三层。

第一，**所有权和组织规模改变了。** 三位创始人离开，Mojang 进入 Microsoft Studios，Minecraft 从独立公司的核心产品变成微软长期经营的第一方品牌。交易于 2014 年 11 月正式完成。[^close]

第二，**发行与账号体系变得更重要。** Windows 10 Edition 进入 Microsoft Store，并与 Xbox Live、Pocket Edition 的跨平台方向连接起来。这条路线最终会成为 Bedrock 生态的重要基础。

第三，**Minecraft 被继续推向更多制度化场景。** Education Edition 是最明确的例子：一个社区和教师已经在做的用途，被重新做成微软可以长期销售、部署和支持的正式产品。

这些变化都比“微软开始决定加什么方块”更容易找到证据。

至于更新节奏、Java 与 Bedrock 的差异、Marketplace、账号迁移以及后来越来越明显的社区治理问题，则需要逐件讨论。它们和收购有关，但并不能只凭“发生在 2014 年以后”就自动建立因果。

## 这一章留下什么

- **爱好者**：2014 年确实是 Minecraft 历史上的巨大转折，但不是“收购当天游戏就变了”。更明显的变化发生在所有权、平台与产品边界上，而很多玩家熟悉的社区文化仍然继续在 Mojang 之外生长。
- **开发者**：收购一个成功的沙盒产品，买到的不只是代码和当年的销量，也包括品牌、分发权和继续扩展产品线的能力。但社区、服务器与创作者生态不是公司资产表上的同一种东西；规模越大，越需要分清哪些东西可以由组织统一，哪些东西只能通过兼容和关系长期维持。
