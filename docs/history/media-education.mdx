> **本章命题**：许多人不是在游戏里学会 Minecraft，是在影像里。视频把可执行的指令变成一代人的口语；课堂把它收成课程；正作很晚才用配方书和进度，去补一套自己从未维护过的说明书。媒介先于教程。

## 问题

有一种很常见的入门：还没买，已经会。

小孩在平板上把别人的第一夜看完，知道要挖方块、要做工作台、天黑了要躲。家长听得懂「去我世界里看看」，听不懂合成表。同学之间传的是种子、是某集实况里的房子，不是官方手册第几页。游戏还在加载界面，语言已经在教室和客厅里转起来了。

上一章说很大一部分游戏不在客户端里，在服务器上。还有一部分更早就离开了客户端：它在播放器里。传播不是周边。对整整一代人，传播是入口，是教材，是「Minecraft 长什么样」的第一份记忆。本章要问：它如何从游戏变成通用语言？答案不是「因为火」。火是结果。原因是：这套规则碰巧能被口述、被录像、被照着做——Alpha 里已经兑现过的整数格子，在镜头前变成了可教学。卷二会把最小动词和世界生成拆开写；本章只要史实：能上镜头的规则，才会先变成口语。

可被证伪的说法是：影像只是把已经会玩的人的乐趣录下来，教学仍发生在游戏内。只要还存在「先看后玩」这条路，而且路上的人多到可以构成默认入门，这句话就不成立。Wiki 和视频一旦缺席，早期原版几乎不会教你熔炉旁边那一格该放什么。那不是玩家笨，是游戏把说明书外包了。

## 很多人是在视频里学会玩的

Minecraft 在烂画质下仍然可读。方块是整数，动作是「对着那一格」，失败是洞没挖对、门没封上。教程不必靠精致镜头。240p 的第一夜和 4K 的第一夜，教的是同一套指令。这不是美学附赠，是体素作为度量衡在传播层兑了现：可复述的建造，变成可转发的建造。

于是出现一种颠倒。通常游戏先有系统教学，再有社区发明。Minecraft 反过来：系统几乎不教，社区用影像把发明写成课程。合成是 3×3 的记忆术，记忆术的标准答案在浏览器第二标签页，或在某个正在说话的人的屏幕上。游戏默认你已经有老师。老师不是 NPC，是陌生人。

YouTube 后来用自己的数字承认这件事。2019 年平台统计里，Minecraft 相关视频约 1002 亿次观看，高于同期 Fortnite。[^yt-2019] 再往后，YouTube 把累计播放说到万亿量级。[^yt-trillion] 数字不当排行榜用。它只说明：有一个游戏的说明书，长成了互联网上最厚的那一层影像。厚到可以脱离「会不会玩」独立存在——有人看 Minecraft 像看烹饪节目，自己不一定下厨。观看即参与的一种。参与过语言，不等于进过存档。语言仍然是 Minecraft 的。

第一夜是这套口语里的公共仪式。几乎每个系列都会拍一次：砍树、做台、挖洞、封门、听外面的东西。仪式不在游戏流程里——生存没有强制教程，死了也不结束世界。仪式在影像的语法里。小孩学会的不是「通关」，是一套可以在任何种子上重演的句子。种子本身也是口语：一串数字，就能把别人的山和别人的村借走。世界生成因此不只是内容生产，是可转发的地点。地点能被说出，语言才算完成。

这也解释了为什么改手感、改合成、改世界生成会引发「你改了我的游戏」：许多人的游戏，是某一季视频里的游戏。官方客户端只是那一季的其中一个版本。传播层有自己的版本号，叫爆款和系列。手感一变，教程里的节奏就假了；生成一变，种子作为地名就失效了。官方在改产品，观众在护一部已经看过的教材。冲突看起来像怀旧，结构上是两个版本号抢释义权。

## 实况、教程、动画、音乐、梦核

影像不是一种。几种类型分担了不同的教学和政治，列频道名没有意义，列职责才有。

**实况**把居住拍成连续剧。没有主线的世界，被说话填上主线：今天挖到什么、邻居做了什么、这栋房子为什么丑。Let's Play 不是攻略，是把空循环重新装进「下一集」。观众学到的往往不是最优解，是一种被允许的过法——可以闲，可以瞎，可以把游戏当房间。早期有人用连载把沙盒讲成史诗，那是类型能力，不是某张脸的功劳。[^yt-story]

**教程**把误用写成步骤。红石门、生存第一夜、某座建筑的逐块摆法。步骤有毒，也有功：毒在把发明收成标准答案，功在让远方的人真能复现。没有教程，第二作者的系统传不出去；有教程，正作更可以继续不写说明书。外包是互相的。Java 侧的教程长期教模组和指令；手机和主机侧的教程教触控、市场包、Realm。镜头前已经是两个游戏，公众口语却还叫同一个名字。后文的双产品线不是从收购才开始分裂，影像里先分裂过一次。

**动画**把方块当成剧组。表情、分镜、村民的滑稽，让不玩游戏的人也能看懂「这是那个方块世界」。语言离开操作，进入可看的故事。游戏变成布景。布景一旦成立，IP 就可以离开客户端——电影、周边、校服上的苦力怕，都在用动画教过的那种可读性。

**音乐**给空循环一种天气。C418 的专辑把洞穴和夜晚收成可以单独听的东西；后来的二次创作歌曲把游戏里的事件收成可以跟唱的东西。[^c418] 声音不是系统，是记忆的钩子。一代人说起 Minecraft，先响起的往往不是镐，是那几条循环的旋律。旋律比版本稳定。稳定的东西会变成故乡。

**梦核**是后长出来的一种读法：空荡的走廊、错误的光照、没人的服务器大厅、远地附近那种不对。它不教你玩。它教你：这套规则留下的空间，本身可以当情绪。居住不必热闹。空着可以吓人，也可以安心。起源处卸掉的剧本，在这里变成审美。审美反过来要求正作别把每一寸地填满——填满了，梦核就死了。世界生成若越来越像主题公园，口语里的「那个空荡荡的 Minecraft」就会变成一种过期方言。这和「向游戏收敛」之间的张力，后面版本政治还会再碰。不是所有影像都在教你怎么玩；有一类影像专门教你怎么怀念一种已经不太空的空。

类型会汇流。剧情 SMP 把实况、服务器和政治搅在一起，观众比进服的人多。那不是奇迹，是三条前史叠在同一镜头里：空循环、第二作者、可转发的指令。不要把汇流写成某几年的网红现象。现象会过。结构还在。

## 儿童、家庭、「安全的创造」

语言一旦离开操作，就会进家庭。家长不必会玩，只要认得方块是「那个比较安全的游戏」。暴力被抽象成方块，血液几乎没有，创造被理解成乐高。分级和广告商都吃这套可读的無害。[^yt-2019] 「安全」于是不再只是口碑，是分发条件：能进客厅，能进学校，能被品牌部门保护。

保护会改游戏。聊天要管，皮肤要管，陌生人服务器要吓一跳。儿童入口把「谁可以当第二作者」往回收——不是收模组的技术权，是收谁能碰到谁。家庭友好与创作自由的摩擦，后文会当成遗产和治理来写。本章先记下起点：影像把 Minecraft 教成儿童语言之后，官方就很难再把产品只当成给论坛老用户的工地。工地上可以脏话和崩坏；客厅里不行。1.0 的仪式已经在对家长说话；影像把家长变成了长期客户。

「安全的创造」还有一层设计含义。创造模式、教育世界、不会死的课堂模式，让建造从生存里分离，变成可以给小孩的活动。分离是权限，也是承诺：这东西主要是用来造的，不是用来伤害的。承诺一旦被市场听成性格，生存里那些会咬人的部分就变成可选。可选不是消失。可选是：默认的 Minecraft 在公共想象里，越来越像一本可以画画的练习簿。练习簿很强，强到可以进课表。强也会窄：窄掉 2b2t 那种实验，窄掉工业模组那种新陈代谢，直到它们被说成「不是给孩子的」。不是给孩子的，仍然是 Minecraft。公共语言不管这一句。公共语言认练习簿。

## 教育版：谁的 Minecraft

课堂比客厅更进一步：它把游戏收成制度。

MinecraftEdu 早在 2011 年就以第三方形态进学校，TeacherGaming 把课堂管理焊在 Java 版上。微软 2016 年 1 月收购这条线，同年 11 月推出 Education Edition：教师端、传送、发放物品、课程与许可按人头按年卖。[^edu-ms][^edu-launch] 当时口径是已有四十多国、七千多间教室在用。数字会变。不变的是方向——承认孩子们已经在用这套语言学别的东西：历史现场、细胞模型、协作和所谓数字公民。

这里有一刀必须按版本切开。MinecraftEdu 是 Java 的模组；Education Edition 建在 Bedrock 上。旧课室世界进不去新课室。[^edu-bedrock] 学校里的 Minecraft 因此不是「正作加老师」，是换引擎、换账号、换分发、换作者席。模组河被留在门外：课堂要的是可管控的设备矩阵，不是 Forge 那种共同立法。一年后 MakeCode 和 Agent 再把学生从「住在世界里的人」改成「给代理下指令的人」。[^makecode] 挖、放、看还在，主语换了。主语一换，误用的位置就变——卡住不再是红石那种值得保护的意外，是课时事故。

教育版改写的是**谁的 Minecraft**。课室里的世界有人能传送你、能看见你在哪、能把资源发到你手上。空循环还在，立法者换成老师。老师不是服主那种夜间政权，是国家允许的白天政权。学生玩的是被管理过的居住。于是出现两种 Minecraft：一种在周末服务器上发明法律，一种在周一上午被用来走完课时。共用方块。不共用作者权。也不共用引擎。

把教育版写成「游戏变严肃了」太浅。它是媒介被学校征用，并且征用时选了更好管的那条产品线。征用证明语言已经通用：课程不收小众爱好，收大家都听得懂的东西。征用也会反向塑造正作——更干净的账号、更可管控的多人、更像教材的进度。收购之后这些会加速。本章只取教育这一刀：刀落下时，Minecraft 不再只属于工地里的共同作者。它属于课表。课表选中的，是 Bedrock 这一支。

## 正作还教什么

游戏内教学长期缺席，不是因为官方谦虚。是因为外包好用。Wiki、论坛、影像把说明书养得比任何新手引导更厚。厚到 1.12 才用配方书和进度系统，把「你现在能做什么、你做过什么」收进客户端。[^recipe] 那不是突然关心新手。那是承认：内容已经多到民俗教不过来，第二标签页不能永远当 UI。

配方书是对教程的迟到补课。补课改变政治。以前合成是秘密和记忆，秘密构成老玩家的作者权；现在合成是解锁和检索，作者权往系统里挪。有人觉得这是变简单，有人觉得这是把工地改成博物馆导览。两边说的是同一件事：当传播层已经把语言教给全世界，正作必须决定还要不要维持「不会查就玩不了」的门槛。门槛曾是过滤器，过滤出论坛上的共同作者。过滤器拆掉之后，进来的是家庭和课堂。进来的人没有错。过滤器也不是错。错的是假装正作一直会教。

进度系统更像建议，不像任务。建议仍然是一种教：官方终于肯指一下「你可以去看看这个」。指过之后，无限世界上重新出现路标。路标与梦核、与空循环，又是一次左右互搏——和 Beta 1.8 同一类，只是这次对手是视频里已经教过的世界。视频教的是民间路标；进度教的是官方路标。两种路标会打架。打架时，输的往往不是视频。视频可以不更新。正作每个版本都要解释自己。

所以：当传播发生在影像里，正作还需要教什么，变成设计问题，不是 UI 问题。教多了，像不信任已经存在的语言；教少了，新入口只认得练习簿，认不得误用。教育版选择教管理。配方书选择教检索。实况选择教居住。教程选择教步骤。没有一种能单独代表 Minecraft。通用语言是它们叠出来的，叠出来之后，没有人——包括 Mojang——还拥有全部释义权。

第二部在这里收束。模组写系统，服务器写法律，影像写口语。正作主持过仪式，没主持过这三种写作。下一部资本进场，要保护的已经不只是客户端，是这套被一代人说会的语言。保护会变成治理。治理会碰到双版本、货架和更新投票。那是另一张桌子。

## 这一章留下什么

- **爱好者**：你若是看着别人的世界学会造自己的，你不是旁门。你走的是正门——只是正门开在播放器上。课室里的 Minecraft 也是真的；它换了立法者，也换了引擎。周末的 Java 工地和周一的 Bedrock 课表不必互相取消，也不要假装是同一个作者席。
- **开发者**：能抄走的是「可复述才能被影像教会」——度量衡一旦能上镜头，说明书就可以外包，外包会变成比游戏更厚的媒介。抄不走的是：你可以十年不写新手引导，靠一代人的视频把产品做成通用语，然后必须用教育版和配方书去追认；追认时还会丢掉 Java 那条第二作者河，选更好管的引擎。你若在做沙盒，先问说明书在哪；在游戏里，还是在别人的频道里。在别人频道里的那部分，你治理不了，却会被它反过来治理。治理一旦开始，课堂会要求你交出误用。
