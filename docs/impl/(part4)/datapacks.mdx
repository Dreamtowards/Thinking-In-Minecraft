> **本章命题**：官方扩展面停在新动词之前。数据包能让你在不改 jar 的情况下当关卡设计师，不能让你长出新的手。边界不是文档没写完，是收编：把温和的第二作者请回世界目录，把加系统的人留在加载器那一侧。

## 问题

有人用原版做出 RPG，进门不用装模组。出门发现职业是计分板，任务是函数，掉落是战利品表。[《命令、数据包与地图》](/design/commands-datapacks) 看起来像模组。它骑在同一套物理上。要回答：官方扩展面的边界在哪？可被证伪的说法是：数据包再长几年，就能替代 Forge；边界只是暂时的工期。只要还存在「能改配方不能改挖掘成为另一种动词」、只要还存在自定义物品仍要靠现有组件拼、只要 Bedrock 的行为包进不了 Java 加载器那条河，这句话就不成立。

上一章把注入写成未承认 API。[《模组与插件架构》](/impl/mod-architecture) 数据包是承认的那一层。承认了，就有边界。边界要画成能核对的表，不能画成情怀。物品那一章已经预告过：JSON 能立法的是形状和结果，不是新家具以外的动词。[《物品、库存与合成》](/impl/items)

## 为什么有了数据包还是要写 Java

因为数据包改的是数据，不是程序。数据能说：这个形状产出这把剑，这张表掉这个战利品，这只进度何时触发，这片噪声长成哪种地形。程序才能说：世界上多一种会自己走路的方块行为、多一种窗口、多一种不在现有组件里的因果。命令和函数把运营者变成关卡设计师。关卡设计师调度已有动词。调度不是发明。发明要进类加载那一拍。

1.13 把数据包做成世界里的文件夹，原版自己也是一份内置包。[^dp] 这是政治上的让步：以前要模组才能改的掉落和配方，现在随世界走，不随启动器走。让步很实。让步的尽头写在同一份产品里——实验性功能常常再塞一份包，仍加不出「挖」的第二种手。组件化让物品结果更富，数据包能往结果上贴官方组件。[《物品、库存与合成》](/impl/items) 贴的是模式内的字段。模式外的动词，还是要写系统。系统在 jar 里。jar 属于加载器河。

所以「有了数据包还要写 Java」不是程序员恋栈。是两层作者席。一层住在 `data/`，热重载友好，崩溃域小。一层住在字节码，能加骨头。骨头不能热。官方把第一层做成产品承诺，把第二层继续留作未承认。承诺与未承认之间，就是边界。

边界还能从崩溃域反着读。数据包写错一张表，世界可能加载失败，卸包往往能回到昨天。模组切错一个方法，进程拒绝启动，卸模组仍可能留下半份映射、半份 mixin 配置、半份「我以为已经兼容」。失败可逆，是官方愿意把数据层做成产品的原因之一。失败不可逆，是系统作者必须进版本夜的原因。可逆与不可逆，比「JSON 好写、Java 难写」更接近边界。好写是表面。崩溃域才是政治。

Bedrock 的行为包看起来更宽：JSON 能定义实体行为，脚本 API 能跑 JavaScript。[^bp] 宽，仍是沙盒。沙盒进不了任意渲染后端，也进不了 Mixin 那种切口。不要把行为包听成 Forge。听成温和模组的另一张护照，才对得上后文的货架。

## 命名空间世界

扁平化把数字号收成名字。名字带命名空间：`minecraft:stone` 是第一作者的石头，`我的包:铜锭` 是第二作者的铜。[^ns] 冲突从「87 号是谁的」变成「这个前缀是谁的」。前缀能热更新，所以数据包能活。前缀要登记，所以两个包抢同一名字仍会炸——炸在加载，不在运行到一半才发现 17 号被占用。炸得早，是进步。进步没有取消政治：谁拥有 `minecraft:` 之外的那些词。

标签把名字收成组。`#minecraft:logs` 是官方的「所有原木」。模组曾经用矿辞做这件事。正作把矿辞的职责收成标签，是追随。[《物品、库存与合成》](/impl/items) 追随之后，数据包能说「配方吃所有原木」，不必列举每一种。列举是内容。组是立法。立法仍停在「哪些现有对象算一类」，不是「世界上多一种对象种类的物理」。

命名空间也训练作者怎么吵架。以前抢数字号，吵架发生在加载之后的世界里：箱子里突然变成另一件东西。现在抢前缀，吵架提前到进世界之前。提前是文明。文明没有取消产权：`minecraft:` 仍是第一作者的词根，自定义前缀仍是一张没有中央登记处的口头契约。口头契约能活，因为社区小的时候撞车少。撞车多了，就会出现「请改你的 id」这种外交。外交是数据包河的政治，比 Mixin 外交温和，仍是政治。温和，因为改 id 不必切开方法。仍是政治，因为两张图想进同一世界时，名字就是边界。

世界生成后来也进了数据包：噪声、生物群系、结构配置。进了，不等于你能写一个新的洞穴算法引擎。你在调官方管线的旋钮。[《世界生成管线》](/impl/worldgen-pipeline) 旋钮很深。深，仍是数据。数据换不了「必须走哪几个 Status」这份程序。程序一换，那是模组或正作自己的版本夜。

包格式号是这条河的版本字段。号一涨，旧图要翻译。翻译比 Mixin 轻，仍能让一份 CTM 卡在某一版。轻，是政治上的优待：优待关卡作者，不优待加系统的人。优待要写进边界，免得「数据包每年都更强」被听成「边界在消失」。更强的是旋钮。旋钮拧尽，管线还在。管线在程序里。

## 能做 / 必须写代码 对照表

表是验收，不是百科。能，指官方数据层在不改程序的前提下够用。必须写代码，指要新骨头、新切口、或新的网络形状。

| 你想做的事 | 走哪一层 |
| --- | --- |
| 改配方、战利品、进度、谓词、物品标签 | 数据包 |
| 换贴图、模型、声音、语言、部分着色器 | 资源包 |
| 用函数和命令方块做任务、副本、倒计时 | 数据包 + 命令（仍是调度已有动词） |
| 调噪声、生物群系、结构放置的数据 | 数据包（调管线，不换管线） |
| 给物品贴上已有组件（食物、工具规则、自定义数据） | 数据包能贴；新组件类型要写代码 |
| 新的方块 tick 行为、新的碰撞形状合同、新的红石元件 | 必须写代码 |
| 新的窗口、新的协议字段、新的预测规则 | 必须写代码 |
| 改更新顺序、改渲染批处理、改主循环班次 | 必须写代码（常是 Mixin） |
| 领地、权限、小游戏重置、进服法律 | 服务端插件（仍是法律，不是新物理） |
| 任意新动词（第二种挖、第二种手） | 必须写代码 |

对照不是羞辱数据包。对照是：温和模组已经很宽。宽到能养地图工业。宽到替代不了加载器。替代不了，是产品选择。选择让没装模组的人仍能打开 RPG 图。打开的那一刻，品牌还在。骨头还是官方的。

1.20.5 之后组件更富，表的中缝会往下移一格：更多「物品长什么样、吃起来怎样」能进 JSON。中缝移了，底线还在。底线是动词。动词在类里。类不进 `data/`。

函数看起来像程序。它是命令的批处理：按拍调用已有动词，改计分板，传送，给物品。批处理能做出倒计时和职业。批处理加不出「这把镐的挖掘走另一套硬度公式」——除非公式已经是组件。组件是正作收编过的字段。未收编的行为，函数只能模拟：用粒子假装，用传送假装，用替换方块假装。假装是地图工业的美德。美德到头，就是表上必须写代码的那些行。假装被玩家拆穿的时候，他们会去装模组。装模组，不是数据包失败。是边界被摸到了。

## 资源 vs 数据

资源包改看见和听见。数据包改规则和内容表。分工是故意的。看见可以关，规则关了世界会换法律。于是资源包最容易进货架、进课室、进「安全的 UGC」；数据包次之，因为它能改掉落和配方，已经开始碰财产；模组最危险，因为它能改下一拍。危险不是道德。危险是崩溃域和审核域。

同一件事会跨两包。自定义方块若只换脸，资源包够。若要让脸对应一种新的熔炉行为，数据不够，必须写代码，再让资源包去画。跨包是完整模组的日常。官方把两包拆开，是为了让只换脸的人不必进版本夜的矩阵。拆开成功。成功的代价是：玩家口语里的「资源包」常常被拿去形容一切 UGC。形容错了，边界会糊。糊了，有人会以为装一个包就能加电网。加不了。电网是系统。系统在上一章。

资源包还能换核心着色器和音效事件名。换，仍是皮肤：石头碎的声音可以变成玻璃，挖掘公式不变。数据包能改这格石头掉什么。掉什么是财产规则。财产规则已经比皮肤硬，仍不是新的挖。硬和骨头之间，就是官方愿意收回的最大半径。半径内，世界目录是作者席。半径外，启动器才是作者席。半径画清楚，地图工业才知道自己在哪条河。河混了，整合包会把数据包当模组卖，玩家会在崩溃日志里找不到 Mixin——因为根本没有切口，只有一张写错格式号的包。

Java 的包格式号两边分别涨。涨一次，旧包要翻译。翻译按文件计费，比物品迁移轻，仍会让地图工业卡在某一版。Bedrock 把资源和行为做成附加包配对，进 Marketplace 还要过审核。配对不是 Java 的两文件夹。配对是另一条产品线的扩展面。合写的是：皮肤和规则分开，比混在一个 jar 里更可分发。分写的是：谁有权分发。

<Note>
资源包能让石头长成另一副面孔。数据包能让这副面孔掉另一张表。面孔和表都换不了挖。挖还是那只手。
</Note>

## 政治含义

数据驱动是温和模组的政治。政治有两面。一面给地图作者官方河：世界目录里就能立法，玩家不用改装客户端。一面把加系统的作者席明确关在门外：你要新骨头，去加载器，去版本夜，去兼容矩阵。门外不是惩罚。门外是：默认世界必须仍能被没选择电网的人打开。默认一肥，空循环会变成产线。[《模组作为设计方法》](/design/mods-as-method)

官方因此可以收编而不提供真正的模组 API。收编配方、进度、世界生成旋钮，看起来每年都更开放。开放的是数据。数据越开放，越能证明「你们要的内容已经能做」。证明会挡住那句「请给稳定模组 API」。挡住，对正作是迭代速度。对第二作者是：温和的人被请进屋，激烈的人继续切口。切口即 API。API 未承认。未承认的利息上一章写过。

实验性数据包把政治写得更直：新功能先以包的形式进来，开关在世界里。开关能关，说明还不是默认骨头。变成默认之前，可以撤回。撤回对数据作者是版本风险。风险比 Mixin 小，因为包可以卸。卸不掉的是期待——期待「再过几年包能加动词」。期待落空，不是工期。是边界。边界在表里。表上必须写代码的那些行，就是官方扩展面的墙。

墙还有教学上的用处。教程可以说「不用模组也能做 RPG」，把新玩家留在官方河里。留，是品牌。留，也会训练错一种期待：所有好想法都应该能进 `data/`。好想法若是新的手，进不去。进不去时，社区会发明更多假装。假装堆厚，性能和可维护性会先垮，然后有人写模组把假装收成真骨头。收成真骨头，正作偶尔再收编一勺——漏斗、合成器。一勺是动词。一勺不是电网。电网留在门外，空循环才还是空循环。

<Constraint name="扩展面停在动词前" verdict="地基" chain="数据可热更 → 程序才有新骨头 → 官方只承诺数据层">
抄走命名空间、标签、配方 JSON，丢掉「新动词要写系统」，你会得到能换内容的演示，失去十年地图工业与模组河并存的产品。温和是收编。收编不是 API。API 若十年稳定，正作会变慢。变慢可以。变慢是另一份合同。这份合同把骨头留在门外。
</Constraint>

<Memoir title="不用模组的 RPG">
进门没有加载器。职业是计分板。出门仍是那只手。口令「原版能做」能当广告，因为广告说的是调度。调度很强。强，不等于墙上多了一只新的挖。
</Memoir>

<Alternative title="若数据包能注册新的方块行为类">
地图和模组的边界会再糊一截。热重载会碰到类加载。崩溃域变大，审核会变难。你得到更完整的官方河。你失去的是：没装系统的人仍能安全打开任意世界目录。安全是政治。政治选择了窄门。
</Alternative>

下一章把镜头对准这扇门为什么是 Java 写的：2009 年的正确选择，如何同时卡住性能与发布。语言是历史偶然。偶然能证明可移植与模组性，不能证明必须永远用它。

## 这一章留下什么

- **爱好者**：数据包能改掉落、配方、任务，改不了「挖」变成另一种游戏。资源包换脸。换脸的世界仍是同一只手。原版 RPG 是调度，不是新骨头。
- **开发者**：能抄走的是命名空间加标签、数据与资源分家、把温和扩展做成可随世界分发的包。能一起抄走的还有：对照表——内容与规则走数据，新动词、新窗口、新因果走代码。抄不走的是扁平化之后的包格式号、Java 包与 Bedrock 附加包的审核域；以及地图工业已经把函数当关卡语言。你若宣称数据层能替代模组 API，是在把调度说成发明。调度可以很强。发明仍在类加载里。

[^dp]: Java 1.13 引入数据包，用于进度、配方、战利品、函数、标签等；原版自身以数据包形式加载。见 [Data pack](https://minecraft.wiki/w/Data_pack)、[Java Edition 1.13](https://minecraft.wiki/w/Java_Edition_1.13)。

[^bp]: Bedrock 行为包用 JSON 定义实体与世界规则，并可包含脚本 API 的 JavaScript。见 [Behavior pack](https://minecraft.wiki/w/Behavior_pack)；Microsoft Learn，《Differences between Bedrock and Java》，<https://learn.microsoft.com/en-us/minecraft/creator/documents/differencesbetweenbedrockandjava>。

[^ns]: 扁平化之后，方块与物品使用 `命名空间:路径` 标识符。见 [Java Edition 1.13](https://minecraft.wiki/w/Java_Edition_1.13)、[Resource location](https://minecraft.wiki/w/Resource_location)。
