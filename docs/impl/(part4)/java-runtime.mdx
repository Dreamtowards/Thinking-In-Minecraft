> **本章命题**：Java 证明了「一份字节能在多家操作系统上跑、并且能被第二作者切开」。它卡住了启动、停顿、以及发布必须拖着一台虚拟机。语言是 2009 年的正确选择，不是格子、动词和权威服务器的本质。不得从这一章读出「必须用 Java」或「必须立刻换语言」。

## 问题

有人说 Minecraft 卡，是因为 Java。有人说 Minecraft 能被模组，也是因为 Java。两句都听过，都不能当结论。要回答：Java 证明了什么、卡住了什么？可被证伪的说法是：这款游戏的味道等于这门语言；换语言要么背叛本质，要么立刻解放一切。只要还存在 Bedrock 用 C++ 做成另一个游戏、只要还存在 Sodium 在 Java 里把帧救回来、只要还存在模组河靠字节码切开而不是靠官方 API，这句话就不成立。

上一章把官方扩展面停在动词前。[《数据包、资源包与数据驱动》](/impl/datapacks) 动词在类里。类在这台虚拟机上跑。跑的税，和切开类的自由，是同一枚硬币。卷一写过可移植如何变成产业。本章写成运行时：税开在哪，偶然如何被说成本质。

## 2009 年的正确选择

当时要的是：在 Windows、Mac、Linux 上交出一份能跑的客户端，作者一个人能迭代，玩家能下载一个 jar 就进世界。Java 带着虚拟机和现成的游戏库（LWJGL 那一层）走进来。[^lwjgl] 可移植是真的。发布是真的——不必为每个操作系统养一条编译流水线。模组性是副作用，后来变成资产：字节码能被反编译、能被变换、能被加载器改写。副作用不是 Notch 的产品说明书。说明书要的是能跑。能跑，先卖。[《从 Infiniminer 到 Cave Game》](/history/infiniminer) 那一章的原型逻辑，在语言选择上又演了一次。

正确，相对于 2009 年的约束。约束包括作者会什么、玩家电脑上有什么、小团队付不起三套原生客户端。正确不等于永恒。永恒是格子还能指、世界还能改、拍还在服务器上。那些不写在 `.java` 文件头上。写在设计合同里。合同换语言可以还在——Bedrock 证明「可以另写」。另写之后合同分叉，证明的是产品线，不是「C++ 更本质」。

可切开还有一层教学：大学课室、模组教程、反编译入门，都因为字节码够软而降低门槛。门槛低，第二作者变多。变多，矩阵变大。矩阵变大，维护变难。难，是证明题的另一半：同一选择既养出生态，也养出末日。你不能只要生态不要末日，除非第一作者把 API 签上十年。十年签名，正作会变慢。变慢可以。变慢不是本章命令。本章只把因果写全：可移植和可拆是真的；真的东西带着税。

所以 2009 年证明了三件事：可移植能让独立游戏活到跨系统；虚拟机分发能让版本以 jar 和启动器为中心；可切开的字节让第二作者河成为可能。三件事都是历史答案。历史答案能被后来的约束改写。改写不是背叛。改写要另付语义税。语义税在 Bedrock 那一章。

## 运行时税：GC、热路径、启动

虚拟机收三种明显的税。

**GC。** 分配快，回收会停。停可以很短，也可以在万人服的某一拍里变成看门狗认识的那种长。长停不是「Java 不能做游戏」。长停是：主循环把模拟锁在约 50 毫秒里，回收若闯进来，TPS 先告状。[《游戏循环与刻》](/impl/tick) 告状的是共享真实，不是语法。G1、ZGC、调堆，是运维层的减税。减税不是换语言。减税是承认税在。

**热路径。** JIT 会把烫的代码变快，冷启动那几分钟却更像解释。进世界、加载模组、第一次看见新区块，卡的常常是还没烫。烫了之后，实体 AI、区块转换、红石更新仍可能是 Java 热路径上的账单。账单有一部分是语言，有一部分是算法写在主线程上。优化模组改算法和提交方式，帧能回来，证明税不全在语言。

热路径还有一层容易被骂错的地方：分配。每一拍若 new 出一堆短暂对象，GC 会来收；收的时候主循环正在守 50 毫秒。于是「Java 卡」有时是「这一拍分配太多」。太多，能在 Java 里改成复用和更少的装箱。改完，语言还在，卡少了。少了，不能写成「所以必须用 Java」。只能写成：托管语言把分配税摊在明处，原生语言把同一笔税藏进碎片和生命周期。明处好骂。好骂不等于本质。本质仍是主循环能不能在一拍里做完点名。

**启动。** 虚拟机起来、扫描 mods 文件夹、应用 Mixin、冻结注册表，标题页之前已经立法一回。启动器再把「哪一个 jar、哪一个 Java 版本」隔开，避免 1.8 的世界被 1.21 的运行时咬碎。隔离是资产：版本能并存。隔离是税：每一次玩都像重新安装一小次。原生客户端可以更快进门。更快进门，往往更难让玩家在磁盘上并排放二十个版本的第二作者。并排，是模组河活下来的条件之一。

```java
void boot() {
  startVm();
  loadMods();     // 扫描与切口
  jitWarmup();    // 前几分钟不像产品宣传
  tickLoop();     // 50ms 里还可能撞上 GC
}
```

示意。税要分开写：GC 撞的是拍；JIT 撞的是前几分钟；启动撞的是进门。三笔税都能在 Java 里减。减完仍可能觉得慢。觉得慢，下一步是换算法、换提交、换调度——或换语言。换语言是后文的考试题，不是本章的命令。

<Callout type="warning" title="不要单边结论">
「必须用 Java」把偶然写成本质。「必须立刻换语言」把 Bedrock 的分叉当成免费午餐。两句都不许从本章出去。
</Callout>

## 性能史

早期的正确是「能跑」。能跑的世界变大之后，性能史几乎是一部民间官方实现史。OptiFine 先改看见。Sodium、Iris 改网格与光影。[《客户端与渲染》](/impl/client-render) Lithium 改逻辑热路径，还要把更新顺序当 ABI。[《红石的实现》](/impl/redstone) Paper 改服务端的区块与实体政策。[^perf] 史的形状是：正作把规模拖进不可能，社区把税一项项减。减税的人没有官方职称。职称在启动器里叫模组，在服里叫核心。

这部史不能读成「Java 失败所以必须走」。它也能读成「Java 足够开放，所以债能被别人还」。开放是 2009 年那枚硬币的另一面。硬币立着：同一份可切开的字节，让优化成为可能，也让每个大版本的优化包要重做切口。性能模组同样活在兼容矩阵里。矩阵税上一章写过。性能史是矩阵税的特例：玩家为了帧，愿意先付适配。

官方还债慢，还有一层产品理由：每一笔渲染和循环上的改动，都可能掀翻资源包合同、掀翻「低配机器仍能进世界」、掀翻模组已经焊死的提交顺序。掀翻可以。掀翻是立法。立法按墙上的时间和整合包日历计费。民间优化包付的是切口税，换来的是今天能玩。正作付的是全产品税，换来的是明年仍叫 Minecraft。两笔税不要收成「谁更勤奋」。勤奋解决不了合同范围。范围一宽，慢是结构。结构能解释为什么 Sodium 像选举。选举不能解释成换语言的公投。公投若发生，要另写语义测试集——下一章才是那次已经发生的公投。

专用服务端也在同一台虚拟机上跑。万人网络的卡，有人同样怪 Java。怪错的比例更高：点名策略、实体税、红石钟，常常比 GC 先把 50 毫秒买光。[《服务端与规模》](/impl/servers) 后文会写裁切。本章先不许把「服卡了」写成换语言的证据。证据要能拆开税单。拆不开，就还是人格。人格不能当验收。

<Impl title="税单要拆开写">
GC 停顿打在拍上。JIT 打在进世界后的前几分钟。启动打在标题页之前。网格提交打在帧上。实体 AI 打在主循环上。五笔能叠在同一句「卡」。叠在一起，才会跳到必须立刻换语言。拆开，才知道哪一笔能在 Java 里还。
</Impl>

官方也在还：从即时模式到批处理，从强制 VBO 到 OpenGL 3.2 核心配置，从更认真的剔除到后来的渲染实验。还债的速度慢于民间。慢，是因为官方还要保资源包合同、保「看起来像原版」、保低端机器。慢不是罪恶。慢让 Sodium 成为选举。选举证明债在。证明债在，不等于证明语言必须换。换语言而丢掉切口，优化可能要等官方自己写完。官方自己写完，可能又是另一个十年。

## 原生库与渲染后端

Java 客户端从第一天就不是纯 Java。三角形交给 OpenGL，窗口和输入交给 LWJGL，声音走原生。语言边界在模拟与提交之间。边界让「Minecraft 是 Java 游戏」这句话从一开始就半真：拍和物品在虚拟机里；看见在驱动里。半真很重要。它阻止把帧数差全部记在 GC 头上。网格编得蠢，原生再快也救不回提交次数。提交次数是算法。算法能在 Java 里改，也能在 C++ 里改。Bedrock 改了，语义跟着分叉——那是下一章。本章只要：原生后端从来不是「换语言之后才有的未来」。未来已经焊在 2009 年的客户端里。

启动器是另一块原生现实。它隔离 Java 版本、下载匹配的运行时、把模组文件夹指到某一份游戏。隔离让意外的语言选择变成可管理的发布：玩家不必先理解虚拟机。不理解也能玩。不理解也导致「Java 很卡」成为一种人格——人格把启动器、模组矩阵、视距和 GC 搅成一个词。本章把词拆开。拆开之后，还能不能恨 Java，是自由。自由不要建立在搅在一起的税单上。

发布税还有一笔：游戏要跟某一代 JDK 走。从 8 到 17 到 21，每一次都是「你的启动器先下载另一台虚拟机」。模组要声明自己的语言级别，Mixin 要认新的 class 文件。声明失败，崩溃发生在标题页之前。这不是格子的本质。这是托管语言的发布合同。合同可以换。换的时候，第二作者又要付一晚矩阵。矩阵税和 GC 税不是同一张单。单写在启动器日志里的那一行 `IncompatibleClassChangeError`，玩家会念成「Java 又坏了」。念错科室，就会得出单边结论。本章把科室钉回去：那是发布代际，不是体素。

代际还会改变「可移植」的含义。2009 年的可移植是一份 jar 对三家操作系统。后来的可移植还要加：哪一代虚拟机、哪一份模组、哪一套原生库。加完，启动器比语言本身更像产品。启动器把偶然收成可点的列表。可点，玩家不必懂 VM。不必懂，骂会更整。整句骂进不了验收。验收仍要拆税单。

## 偶然 vs 本质

偶然：这门语言、这台虚拟机、这一套 class 文件、这一条启动器河。本质候选：格子可指、世界可改、模拟有拍、权威在服务器、扩展面允许第二作者。候选要到卷四才考试。本章禁止提前判毕业。禁止的理由很具体：Bedrock 已经用另一次实现证明，换掉 Java 不会自动保住同一份红石、同一份模组河、同一份存档。换掉也证明，换语言能换到跨平台和另一套性能曲线。两边都是证据。证据指向「语言不是本质」，不指向「明天必须迁」。

迁的成本不在语法。成本在语义测试集：墙上的飞行器、十年箱子、加载器矩阵、Paper 事件。测试集比虚拟机大。虚拟机可以换。测试集换一次像立法。立法按墙上的时间计费。那句话在红石章。运行时章要加一句：语言选择会进入测试集，一旦进入，就不再是「偶然所以免费可抛」。可抛，但抛的时候要另写兼容层。兼容层是卷四的题。本题只把偶然从本质里松开，不把松开写成开工令。

松开的读法有两种错误。一种把偶然写死：Minecraft 若不用 Java 就不是 Minecraft。Bedrock 已经在收银台打这份错误。一种把偶然写轻：换掉虚拟机，模组河会自动搬过去。切口河不会自动搬。不会，是因为河水认的是 class 文件和加载器，不是「我们也有扩展面」这句品牌。扩展面在数据包和附加包。切口在 Mixin。两层不要收成一层。收成一层，才会从「卡」跳到「立刻换」。跳过去的人，往往还没付测试集的账。

<Constraint name="语言是偶然不是骨头" verdict="待定" chain="2009 可移植 → 可切开的字节成为模组河 → 性能税与发布税同在">
Java 证明了可移植与模组性。它卡住了启动、停顿和「必须带着 VM 发布」。抄走虚拟机分发和可变换字节码，丢掉二十年切口，你会得到更干净的原生客户端，失去这条第二作者河的一种活法。干净可以。干净不是命令。命令要等考试。考试不许从「卡」直接跳到「换语言」。
</Constraint>

<Memoir title="怪 Java">
视距拉满，模组装一打，分配器在扫。口令「Java 不行」能当情绪。情绪里混着 GC、网格、加载器和一台十年前的核显。拆开之后，有的税在语言，有的税在合同。合同不写在 JDK 发行说明里。
</Memoir>

<Alternative title="若 2009 年选了静态编译的原生语言">
启动可能更快，模组河可能更窄——切开会更像破解。你得到另一份性能曲线。你失去的是：jar 加加载器这种低门槛第二作者席。门槛低不是本质。门槛低是那一年的正确。正确已经开花。花能不能移植到另一片土壤，要另考。
</Alternative>

下一章看已经换过语言的那一次：Bedrock。另一次实现不是移植。语义分叉比跑得快更致命。Marketplace 会反过来决定能做什么。

## 这一章留下什么

- **爱好者**：卡不一定是「因为 Java」。模组能存在，有一部分确实因为字节能被切开。换语言已经有一条产品线在做，做完不是同一份红石，也不是同一份模组。
- **开发者**：能抄走的是可移植分发、版本隔离启动器、把模拟留在托管语言并把提交交给原生、允许字节码变换从而养出第二作者。能一起抄走的还有：GC / JIT / 启动是三笔不同的税，别搅成一句骂。抄不走的是二十年加载器矩阵和「怪 Java」的口语；以及 Bedrock 已经用另一次实现证明换语言不等于换本质。你不得从本章带走「必须用 Java」或「必须立刻换」。本质候选在格子和权威上。语言在偶然那一栏。偶然很贵。贵，仍不是骨头。

[^lwjgl]: Java 版长期通过 LWJGL 调用 OpenGL、输入与窗口。见 [Java Edition](https://minecraft.wiki/w/Java_Edition) 技术概述；[LWJGL](https://www.lwjgl.org/)。

[^perf]: 客户端优化模组（如 Sodium）与服务端核心（如 Paper）被广泛用作原版性能路径的替代实现。见 [Sodium](https://modrinth.com/mod/sodium)、[Paper](https://papermc.io/)。
