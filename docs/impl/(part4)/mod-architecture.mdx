> **本章命题**：模组比引擎更难维护，不是因为第二作者更笨。引擎只有一个供应商；模组挂在从未承诺稳定的字节上。没有稳定 API 时，注入就是 API。升级变成政治。

## 问题

大版本发布夜，整合包作者不先打龙。他们先看崩溃日志：映射断了，Mixin 打不进，Forge 与 Fabric 各出一轮「请等」。玩家口令是「模组又没了」。要回答：为什么模组比引擎更难维护？可被证伪的说法是：模组难，是因为玩法每年都变；加载器只是安装器，官方一出正式 API 大家就会轻松。只要还存在每个协议号都要重挂钩子、只要还存在同一功能要出 Forge 版和 Fabric 版、只要还存在 Bukkit 事件在 Folia 上作废，这句话就不成立。

卷一把第二条作者席写成产业史。[《模组作为第二作者》](/history/mods-as-authors) 三条河：客户端模组、服务端插件、资源包。本章写成实现：河岸上的挂钩子怎么打，打完为什么比正作难养。上一章把手感写成先演的谎。[《音频、粒子与手感谎言》](/impl/feel-client) 谎可以换实现。换实现的人，要先活过版本夜。

不要安装步骤。不要加载器评测。Forge 与 Fabric 写成加载哲学，不站队。站队会把政治听成信仰。政治是：谁有权改下一拍。

## 为什么每个大版本都是模组的末日

正作改的是自己的程序。模组改的是正作的程序。正作没有把「改哪里」印成稳定合同，模组就只好认方法名、认字段、认调用顺序。名字来自映射：混淆名每年一换，民间映射跟，官方映射后来也来了，跟的仍是「这一版长什么样」。长什么样变了，挂钩子的点就消失。消失不是玩法变了。消失是接头被拆。

协议那一章已经写过一半末日：包的形状是未承认的 API。[《网络协议》](/impl/protocol) 另一半在进程里。客户端模组要改渲染、改方块行为、改 GUI；服务端插件要改进服、改伤害、改区块票。两边都没有官方说「这些事件保证十年不变」。于是注入成为 API：在类加载时把别人的方法切开，插进自己的代码。切开能活。切开没有版本协商。官方改一行，切口对不上，游戏拒绝启动。拒绝启动，就是末日口令。

引擎难维护，难在规模：区块、实体、红石、二十年存档。模组难维护，难在乘法：版本 × 加载器 × 彼此。引擎乘的是自己的子系统。模组乘的是别人的子系统，外加所有同场的切口。同场两个 Mixin 打同一处，崩溃日志会变成侦探小说。侦探小说没有官方作者。正作可以不读它。第二作者必须读。读完还要等下一个快照。

所以末日是结构，不是懒。结构是：完整产品住在内核加第二作者里，第一作者却只对内核的版本号负责。负责范围一窄，外面的人就要用注入补责任。补责任的工具越强，升级越政治——谁先适配、谁冻结旧版、谁宣布「本包只支持这一加载器」。政治不是论坛脾气。政治是兼容矩阵当生存条件。

映射税写在同一结构里。混淆名每年一换，民间 Yarn、官方 Mojmap，都是在给切口做词典。词典越官方，切口越好写。词典再官方，也不是稳定 API：方法被删掉时，词典只告诉你它不在了。不在了，仍要改 Mixin。所以「有了官方映射，末日就会结束」不成立。结束的是猜名字。没结束的是认形状。形状在协议章是包。形状在这里是方法和字段。两处都未签名。

## 客户端模组河

这条河改物理：世界上可以发生什么。新方块、新维度、新的手。它必须进客户端，常常也要进服务端，否则你看见的机器别人进服看不见。早期是把改过的 class 塞回 jar。两个人改同一处就炸。加载器的第一份工作不是「更好玩」，是让多模共存从缝合变成加载。[^forge]

后来的哲学分成两口，不要选边。一口把加载器做成带电池的平台：事件总线、注册表、跨模组协议、一堆「你应该走这里」的门。Forge 这条路长，工业包能对上电和流体，常常因为门已经被立法。另一口把加载器做成薄的启动器：先让你进来，API 另装，Mixin 自己选切口。Fabric 这条路短，优化模组和数据包向的模组爱它，是因为短意味着少替你做决定。[^fabric] NeoForge 从 Forge 分出，证明平台本身也会裂——裂的不是方块，是谁有权定义下一扇门。[^neo]

Mixin 是两边后来都在用的刀。刀来自 Sponge 那条河，把「在运行时改字节码」收成可复述的注入点。[^mixin] 刀让模组不必整类替换。刀也让兼容从「谁覆盖谁的 class」变成「谁的注入先执行、LVT 还认不认」。执行顺序是隐式 ABI。红石那一章把更新顺序写成社区 API。[《红石的实现》](/impl/redstone) 模组把方法内的顺序写成另一份社区 API。两份都没有印刷说明书。两份都会在快照里被「修复」成另一台 CPU。

资源包是第三条河，最安全，也改不了这一层。换皮不进末日的中心。进中心的是加系统。加系统必须碰程序。碰程序，就没有温和升级。

Fabric API 是模组，不是加载器。这句话要钉死，免得哲学被听成「谁的包更大」。薄加载器把电池故意卸掉，电池另装，于是 API 本身也进矩阵：某一版 Fabric API 与某一版游戏绑在一起。带电池的平台把电池焊在加载器上，矩阵少一维，多一份「你必须走这扇门」。少一维不是胜利。焊上门不是失败。两边都在为「没有第一作者签名的 API」付设计费。费的形式不同。费都比引擎的版本线长。

## 服务端插件河

这条河改法律：这台服务器上谁能进、地是谁的、死了掉什么、小游戏何时重置。理想是玩家不改装客户端。理想把作者席从「改物理的人」换成「运营者」。Bukkit 把官方服务端换成可插拔的内核，事件写给插件：进服、破坏、伤害、聊天。[^bukkit] CraftBukkit、Spigot、Paper 是同一条河上越来越像「民间官方服务端」的船。船的意义不是谁更快。是：万人网络需要的法律，原版故意写得很薄。薄，插件才成为完整游戏。

插件河与模组河不要收成一种「mod」。模组改 jar 里的物理，常常要客户端跟着改。插件尽量只改服务端，门票仍是原版客户端。门票不变，才能让 Hypixel 那种东西不必给每个玩家发一份魔改客户端。门票不变，也限制了能改的深度：没有客户端的新方块，大厅只能用原版积木加资源包演戏。演戏是设计。演戏到头，就要请模组上船，变成「必须装包才能进」的服。上船的瞬间，兼容矩阵从「插件 × 核心」变成「再乘加载器」。

2014 年 Bukkit 危机证明桌子比客户端脆。[《服务器即新游戏》](/history/servers) 脆的工程含义是：插件 API 若建立在可被 DMCA 的下游上，立法席会一夜搬家。搬家之后，事件名还在口语里，实现已经换了姓。Paper 后来把性能补丁和 API 扩展写成日常，等于承认：这条河的维护者不是 Mojang。维护者换人，API 仍是未承认的——只是承认者换成了核心团队。核心团队比正作更勤快，也更没有「十年不变」的义务。勤快，插件要跟。没有义务，插件比正作更难养。

## 类加载、事件、生命周期

没有稳定 API 时，运行时的类加载器就是议会。加载器先把正作的类读进来，再让模组的变压器动手：Mixin、核心模、访问变换。动手发生在游戏进入标题页之前。动手失败，你进不了世界，也看不见哪一格方块坏了。失败是政治的第一种声音：启动即立法审查。

事件总线是第二种声音。方块被放、实体受伤、玩家进服，正作若调用总线，模组就不必切开方法。总线是温和注入。温和的前提是正作愿意举手。正作不举手的地方，仍要切开。于是同一模组里住着两种接头：官方的（其实是加载器的）事件，和非官方的 Mixin。升级夜，事件还在的先活，切口对不上的后死。活下来的人会说「我们走 API」。走的仍是第二作者的 API。第一作者没有签名。

生命周期把第三种声音写进时间。构造、注册、世界加载、每个 tick、卸载。注册发生在名称空间已经冻结的窗口。窗口关了再注册，会撞上「太晚了」。数据包可以热重载一部分数据。模组的新类通常不能在不停服的情况下变成另一种物理。物理要进进程。进程要重新立法。所以「每个大版本都是末日」之外还有「每个热重载都是幻觉」：数据能热。系统不能。系统模组的维护者付的是冷启动税，外加映射税，外加同场切口税。

插件的生命周期更像政权交接：启用、停用、重载配置。重载配置不必重切字节码，所以看起来比模组温顺。温顺有上限。上限是事件仍假设某一版核心的调度。核心一换点名策略，温顺的重载也会变成末日——只是末日发生在 Paper 版本夜，不是 Mojang 版本夜。两个版本夜叠在矩阵里。叠完，模组比引擎难养的算术又多一因子：核心版本。因子不是推荐。因子是证据。

```java
void onLaunch() {
  loadVanilla();
  applyMixins();          // 切口即 API
  fire(REGISTRATION);     // 总线是温和切口
  freezeRegistries();
}
```

示意。冻结之后，名字就是法律。法律在数据包那一章会变成命名空间。本章只要：冻结是加载器替正作执行的那一拍。拍过了，模组再想加方块，就要等下一次启动。启动比挖一格贵。贵，是因为完整产品把立法放在进世界之前。

<Impl title="注入点没有版本号">
方法名、描述符、注入的 ordinal，构成一份民间 ABI。正作重构一个方法，ABI 作废。作废没有弃用警告。作废是崩溃。崩溃把维护从「改功能」变成「先对上切口」。
</Impl>

## 兼容矩阵

矩阵至少三维：游戏版本、加载器、模组彼此。再加可选的第四维：服务端核心（原版 / Paper / 代理后的大厅）。每一格都是一份「在这一夜还能不能进世界」。引擎的版本是一条线。模组的版本是一张表。表比线难维护，因为表的作者互不隶属，却必须同场。

Forge 与 Fabric 的哲学差，会把表撕成两份。不是谁更正确。是门的形状不同：带电池的平台让工业模组少发明协议；薄加载器让优化模组少背平台税。两边都合理。两边都让「一份 jar 走遍 Minecraft」不能写进合同。NeoForge 再撕一刀，表继续长。长，不是生态繁荣的免费午餐。长，是维护者要决定支持哪几格。决定本身就是政治：放弃一格，等于放弃一群还停在那一格上的存档。

Paper 对插件是另一张表。事件若假设单线程主循环，Folia 把世界切成并行区域之后，假设作废。[^folia] 作废不是插件写得差。是「同一内核」开始拒绝同一种调度。后文服务端章会写规模。本章先钉：核心一叉，插件矩阵跟着叉。叉完，模组比引擎难养的句子有了算术：引擎维护一份因果；第二作者维护因果的笛卡尔积。

矩阵还有一笔看不见的账：文档。正作有版本说明。加载器有迁移指南。邻居模组常常只有 Discord 里一句「等我今晚」。三份时间表对不齐，整合包作者就变成议会秘书——催适配、冻依赖、写一份「已知会炸的组合」。秘书工作不是创意。创意在矩阵清零之后才开始。清零之前，引擎已经能卖下一张快照。卖得动，是因为第一作者不在这张表上签字。不签字，利息就记在第二作者夜里。

<Constraint name="注入即 API" verdict="地基" chain="无稳定合同 → 挂钩子认字节 → 版本夜政治化">
抄走事件总线和加载器，丢掉「切口没有版本号」，你会得到能热加内容的演示，失去十年工业包和生存服已经焊在某一版字节上的世界。引擎可以一年一版。模组要为这一版乘上加载器和邻居。乘法不是社区热情。乘法是完整产品把作者席留在内核外面的利息。
</Constraint>

<Memoir title="整合包的发布夜">
正作已经能进世界。整合包不能。不是方块坏了。是二十个切口里有一个对不上。口令「等适配」能当日历，因为日历写的不是龙，是矩阵。矩阵清零之前，家还在磁盘上，进不去。
</Memoir>

<Alternative title="若官方提供十年稳定的模组 API">
末日会少。正作加字段要走弃用周期，快照会变慢。你得到更像引擎中间件的扩展面。你失去的是：正作能在快照里把物品收成组件、把渲染收成新管线，而不先给第二作者开两年意见征集。快，是债。债的利息由矩阵付。
</Alternative>

下一章问官方自己划的那条温和河：数据包能改什么，为什么有了它仍要写 Java。扩展面故意停在新动词之前。停，是政治。政治在实现里叫边界。

## 这一章留下什么

- **爱好者**：模组崩了，常常不是作者放假，是正作改了从未答应稳定的接头。Forge 和 Fabric 不是两款「更好的 Minecraft」，是两扇不同的门。插件改的是这台服的法律，不必换你的客户端。
- **开发者**：能抄走的是加载器把多模共存收成启动时立法、事件总线作温和切口、注入作未承认 API、客户端模组河与服务端插件河分开。能一起抄走的还有：兼容是版本 × 加载器 × 邻居的乘法。抄不走的是二十年映射与 Mixin 生态、Forge / Fabric 的门形、Bukkit 家系的事件名；以及矩阵已经比引擎大。你若每年换私有形状还不给弃用期，第二作者会比你先死。死的不是创意。死的是接头。两边加载哲学都可以活。站队解决不了乘法。

[^fabric]: Fabric 是轻量模组加载器，2018 年起与 Yarn / Intermediary 映射一同发展。见 [Fabric](https://fabricmc.net/)。

[^neo]: NeoForge 由 Forge 生态分出，另立加载平台。见 [NeoForge](https://neoforged.net/)。

[^mixin]: Mixin 是基于 ASM 的字节码注入框架，源于 Sponge，后被 Fabric 等加载器广泛使用。见 [SpongePowered/Mixin](https://github.com/SpongePowered/Mixin)。

[^bukkit]: Bukkit / CraftBukkit 在 2011 年前后把官方服务端做成可插拔内核。见 [Bukkit](https://minecraft.wiki/w/Bukkit)；危机见本书 [《服务器即新游戏》](/history/servers)。

[^folia]: Folia 是 Paper 的分叉，按区域并行 tick，并要求插件显式声明兼容。见 [PaperMC/Folia](https://github.com/PaperMC/Folia)。
