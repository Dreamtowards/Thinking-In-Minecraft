> **本章命题**：先卖再修证明过一种很窄的活法：循环已经完整，增量看得见，作者还在回帖。它没有证明你可以没有二十年社区替你把债扛成平台。债在红石和存档上必须高于「正确」；民间官方实现不是锦上添花，是完整产品漏写的那一半。

## 问题

装上 Sodium，帧回来了。换上 Paper，TPS 回来了。Wiki 把准连接写成零件。有人于是说：原版太烂，社区真勤快。勤快是真的。把勤快听成「官方可以永远先卖」，是把利息单撕掉。

要回答：先卖再修证明了什么、没证明什么？可被证伪的说法是：Minecraft 能长成这样，是因为任何独立游戏只要尽早交货、把修的事留给以后，社区都会来擦。只要还存在飞行器停在一次「修复」上、只要还存在扁平化让工业模组变成未知方块、只要还存在万人服必须换核心才能像同一款游戏，这句话就不成立。擦得动，是因为债的形状刚好能被第二作者认成接口。认不成接口的债，只是崩溃。崩溃不会养出教科书。

卷一已经把神话钉过一次窄口。[《Alpha 的公开开发》](/history/alpha) 当时成功的是可见施工，不是卖空气。本卷前四部把债写成格式、刻、粉、协议、加载器和规模。本章收成产品策略：哪些窗口还得上，哪一种「正确」付不起，独立作者的手停在哪，民间官方实现为什么算进产品。

## 「能跑就先卖」被神话了

Cave Game 能卖，是因为挖、放、看已经是循环。循环完整，未完成才是策略：世界还可以长，家还可以搬，作者下周还可能改一格。[《从 Infiniminer 到 Cave Game》](/history/infiniminer) Alpha 把策略收成购票：你看见增量，你保自己的地，你买一张后面不必再买的票。那是一种信任。信任后来被讲成方法论：先交货，质量以后补。

方法论漏了主语。当时的主语是一个人、一个论坛、一份还没有被当成语言的物理。主语一旦换成工作室、两条产品线、墙上十年飞行器、磁盘上十年箱子，先卖不再自动等于以后能修。修要经过翻译器，要经过 Wiki，要经过整合包发布夜。修可以。修是立法。立法按已经住进去的时间计费，不按你心里的电路图计费。

**证明了的**很具体，也必须写窄。

它证明：最小循环可以先于内容量成为商品。玩家付钱买的是继续住的资格，不是通关权。公开增量能把买家收成共同作者。共同作者会写出官方没写的说明书——红石、农场、服务器法律。说明书让产品看起来比 jar 更完整。完整是生态。生态不是发行说明里的勾。

它还证明：架构可以落后于玩法，玩法仍能成立。1.3 才把单人收成服务器。[《网络协议》](/impl/protocol) 扁平化才把数字号收成名字。收成之前，游戏已经在卖。卖得动，是因为格子还能指、世界还能改、第二个人已经能进门。[《多人是默认状态》](/design/multiplayer) 工程上的「正确形状」可以迟到。迟到不是美德。迟到是：合同先成立，柜子后换。

**没证明的**更长，也更容易被做成鸡汤。

它没证明你可以没有社区替你写规格。准连接没有官方电路课，有 Wiki。[《红石：把物理做成编程》](/design/redstone) 渲染没有官方「现代提交」，有 Sodium。[《客户端与渲染》](/impl/client-render) 万人没有官方兴趣管理，有 Paper。[《服务端与规模》](/impl/servers) 拿走这三层，先卖剩下的是一个能跑的原型。原型可以感动 2010 年。原型撑不住 2020 年的居住。撑住居住的，是把债认成接口的人。

它没证明债会自己变轻。成功会让债变重：存档更长，机器更大，口令更稳，修复更像删词。它没证明大公司接手之后可以改用「正确工程」把怪癖清掉。清掉是另一场立法，立法的测试集不在 CI 里，在墙上。它没证明换语言能还债——Bedrock 换过，还的是进房间的债，欠下的是另一份因果。[《Bedrock 作为另一次实现》](/impl/bedrock) 它更没证明每个独立游戏都该学这一招。学循环完整、增量可见，可以。学「社区会来当平台组」，那是把别人的二十年夜班写进你的商业计划。夜班没有义务出现。

<Callout type="warning" title="神话的主语是社区">
先卖再修能成立，因为有人把未说明的行为读成 API，把卡读成可替换的实现，把空法律读成插件。主语不在启动器图标上。你若抄交货节奏、不抄第二作者席，你抄到的是 2009 年的那一周，不是这款媒介。
</Callout>

## 几次重构窗口

债不是不能还。还债要等窗口：玩法已经把旧柜子撑破，不换会卡住下一层；换的时候必须带着翻译器，不能宣布过去作废。

**区域文件。** 早期世界按区块落盘，文件碎。McRegion 把碎的收成区域；Anvil 再换成至今还在用的柜子。[^anvil] 窗口打开，是因为无限已经成立，I/O 必须按柱子走。窗口没有取消「世界比引擎活得久」。它把旧柱子翻译进新柜子。[《存储与序列化》](/impl/storage)

**扁平化。** 1.13 拿掉多数数字 ID，改成命名空间名字加方块状态。[^flat] 四比特元数据用尽之后，木头要拆号，模组要抢号，数据包没法按名字说话。窗口打开，是因为数据驱动已经在敲门。[《数据包、资源包与数据驱动》](/impl/datapacks) 账单按每一格计。工业包变成未知方块，不是社区矫情，是宪法换了，旧护照作废。作废可以。作废时若假装只是改名，第二作者会听见「你们的山不算数」。

**加高。** 1.18 把高度从 256 拉到 384。[^height] 设计想要更深的洞、更高的山。数据模型必须先允许。允许的代价是旧柱子补节、底下接新石头、光源和实体的范围一起胀。[《体素世界的数据模型》](/impl/data-model) 窗口证明：设计自由有时要等柜子改尺寸。等，不是无能。等，是承认无限的代价单位是区块。

**组件化。** 物品侧的任意 `tag` 扛不住数据驱动和同步。1.20.5 把非结构化树收成有模式的字段。[^comp] 窗口打开，是因为口袋已经是财产的主要载体，财产必须能对账。[《物品、库存与合成》](/impl/items) 账单按每一件物品计。剑比山疼，因为剑总在加载范围内。疼，说明窗口选对了对象：财产不能靠「以后再说」活过下一层协议。

**看见与拍。** 客户端从即时模式走到批处理，服务端从「视距即模拟」走到模拟距离这把独立的尺子。[《游戏循环与刻》](/impl/tick) 窗口更碎，更常被民间先还。官方还得慢，因为还要保资源包合同、保低端机器、保「看起来仍像原版」。慢让选举发生：装谁，等于选哪一份民间官方实现。选举不是道德剧。选举是窗口尚未被第一作者占满。

共同形状是：窗口为下一层玩法开门，翻译器为上一层时间买单。DataFixerUpper 把买单写成库。[《存储与序列化》](/impl/storage) 库可以抄。抄不走的是那张按版本号串起来的梯子。梯子必须一级级走。能跳的改革，会把十年箱子收成空气。空气很干净。干净等于宣布过去作废。

```mermaid

  P["玩法把柜子撑破"] --> W["窗口"]
  W --> T["翻译器"]
  T --> N["下一层合同"]
```

Bedrock 的窗口不是同一张年历。它没有 Java 那种「扁平化仪式」，存档走 LevelDB，物品字段是另一份 schema。合写的是：改革按已经写下的对象计费。分写的是：哪一年换哪一种护照。删掉产品线，账单句子常常还在；年历句子会断。

## 何时兼容必须高于正确

有两处，电路图上的正确是错的产品。

**红石。** 准连接是检查函数看远了一格。按电学，它该收短。按已经起飞的那一层，收短是删词。MC-108 标成 Works as Intended，不是承认电路课，是承认墙上的测试集比快照说明大。[《红石的实现》](/impl/redstone) 1.16 让粉的看见和说话对齐，随后用圆点把一条旧语义补回来。对齐是诚实。补回是兼容。两笔都是立法。立法时若只说「我们修了 bug」，聊天会把修听成革命。革命的判据很硬：稳定、可复述、写进教科书的行为，就是社区 API。API 可以改。改的时候必须付语言税。付不起，就不要装成擦灰。

Lithium 把更新顺序当 ABI。[《Java 版运行时》](/impl/java-runtime) 优化模组若为了快而换班次，灯会换口型。口型一换，它就不再是民间官方实现，而是另一款游戏的模拟器。民间官方的纪律和正作同一句：兼容高于这块的正确。正确可以另开一条新积木——观察者、合成器。新积木是加法。加法不自动注销旧 opcode。

**世界格式。** 存档是玩家时间，不是客户端缓存。读不起旧档，就是宣布过去作废。作废对关卡游戏像赛季。对这款游戏像拆迁。扁平化和组件化贵得正确，正因为它们选择翻译而不是清空。清空会让迁移很便宜。便宜的是养成。贵的是居住。居住把时间写成格子和栈，格子和栈就必须能被下一版认回来。认回来的路上，有些「正确的新表示」必须让路：未知方块占着位置，总好过空气假装什么都没发生。

协议是第三处亲戚。包形状从未签名，却被 ViaVersion、加载器、反作弊当成公共 API。[《网络协议》](/impl/protocol) 每个快照都可以「修正确」。修完，接头全断。断，是模组末日的一半。另一半在字节码切口上。两半都在说同一句产品策略：被用成接口的形状，兼容必须进范围。不进范围，你得到干净的内部重构。干净的内部重构，会把完整产品的另一半写死。

<Constraint name="被当成语言的债按语言还" verdict="地基" chain="稳定可复述 → 社区 API → 修复即立法">
抄走「先交货」，丢掉墙上的测试集，你会得到能跑的演示和一次诚实的电路。演示卖得掉。电路教得会。你会失去飞行器和十年箱子同时活过下一版的那种产品。那种产品把兼容写成伦理，不是写成特性开关。
</Constraint>

Java 与 Bedrock 在这里再次分叉。Java 把一份怪癖升成 WAI，Bedrock 从未签署。兼容高于正确，在两边各有一份清单：一边是墙上的 VM，一边是跨设备存档和主机认证。不得把 Java 的准连接当成全品牌的「必须保留」。合写只剩判据：哪一种错误已经被当成语言。语言在哪一边，哪一边的正确就要让路。

## 独立开发者的限度

一个人能交出完整循环。一个人交不出完整产品。

完整循环是挖、放、看，外加一份能存盘的世界。Notch 交过。限度从循环变成媒介的那一天开始：无限要流式加载，多人要权威，红石要一份从未写完的 VM，模组要切开字节，万人要切开拍。每一项都是「能跑」之后才长出来的不可能。不可能不是骂人。本卷的命题就是：一个能跑的原型被拖进不可能的规模。拖的人后来不只是官方。

限度有三条，不要收成情怀。

第一，时间表。独立作者可以周更一格新东西。他不能同时维护 DataFixer 梯子、映射词典、事件总线和一份万人点名策略。梯子和词典出现之后，周更会变成立法窗口。窗口一变成立法，一个人的直觉就不够当测试集。测试集在墙上、在整合包、在 Paper 的 issue 里。

第二，责任范围。第一作者对内核的版本号负责。完整产品住在内核加第二作者里。[《模组作为第二作者》](/history/mods-as-authors) 范围一窄，外面的人就要用注入补责任。补责任的工具越强，独立作者越不能「以后再做成正式 API」而不掀桌子。桌子掀得起，是因为 2010 年还没有桌子。2018 年已经有工业包焊在某一版字节上。

第三，两种债务不能互相还。Java 的债是可切开、难优化、升级政治化。Bedrock 的债是可进房间、难切开、货架反向约束能写什么。一个人换语言，还不了另一边的利息。工作室换语言，也还不清——已经换过一次。限度在这里变成组织限度：微软可以买下品牌，买不走墙上的 VM，也买不走 Marketplace 不肯上架的系统模组。买下之后，民间官方实现没有解散。没有解散，说明限度不是「穷」。限度是产品边界：官方永远只签其中一层。

<Memoir title="发布夜还在别人家里">
正作能进世界。整合包不能。服核心在等映射。优化模组在重打 Mixin。口令「等适配」能当日历。日历写的不是龙。日历写的是：先卖的那一半已经交货，后一半仍在夜间施工。施工队没有编制。
</Memoir>

可被证伪的说法是：团队变大之后，限度消失，民间实现会自然失业。只要还存在 Sodium 当默认客户端、Paper 当默认核心、Wiki 当红石规格，这句话就不成立。失业没有发生。发生的是分工被做成产业。产业不是失败。产业是限度被承认之后的形状。

## 民间官方实现

民间官方实现的意思是：它替正作还债，还不能改合同。改合同，它就变成另一款游戏。不还债，正作在这一层会不像现代软件。不像，玩家会用脚投票——投票发生在启动器里，不发生在收银台。

客户端这一层，OptiFine 曾经把「能看」收成默认。Sodium、Iris 后来把网格和光影写成可替换实现，目标仍是「这一格看起来还是那一格」。服务端这一层，Paper 把点名策略写成日常，目标仍是同一套挖和放，只是 50 毫秒里少买一些不该买的鸡。逻辑这一层，Lithium 改热路径，公开纪律是行为仍像原版。协议这一层，ViaVersion 把未承认的 API 翻译成多版本入口。数据这一层，Wiki 和原理图工具把未印刷的指令表发行出去。

这些东西不是外挂滤镜，也不是安装推荐。它们是证据：官方把规模、看见、规格和接头拖进了自己签不完的范围。签不完，不是偷懒到可以骂完就结束。签不完，是范围包含一种故意的空——空循环、空法律、空 API。[《服务器即新游戏》](/history/servers) 空要由别人填。填的人没有职称。职称在文件夹里叫模组，在服里叫核心，在浏览器里叫 Wiki。

Bedrock 的民间官方实现更窄。附加包和脚本走审核友好的河，切不进活塞检查。窄，证明民间官方不是宇宙常数。它依赖可切开的运行时和未被货架收编的作者席。Java 把切开做成资产，于是民间能还渲染和拍的债。Bedrock 把切开收走，于是债换了一种：能进房间，进不了同一台隐式 VM。两边都有债。债的搬运工不同。搬运工不同，完整产品的形状就不同。不得把 Java 的 Sodium 选举安到主机启动器上。

<Alternative title="若官方把民间实现全部收编进正作">
帧会更高，核心会更像万人引擎，说明书会更像第一方。你得到更少的选举。你失去的是：正作能在快照里改内部形状，而不先给第二作者开两年意见征集。收编是加法。加法会把利息记回第一作者。记回去可以。记回去之后，先卖再修的窗口会变窄。窄，是因为主语终于写全了。
</Alternative>

民间官方实现还有一句反话要挡住：它们证明原版「失败了」。失败的读法假定完整产品等于官方仓库。本卷不认这句。完整产品从第一天起就包括第二条作者席。作者席把债扛成平台，平台让先卖成为可能。可能，不是神话。可能是分工。下一章把分工收成产品定义：游戏、协议、数据、工具链必须当成同一个东西来写。不当成同一个东西，你手里只剩一个客户端。

## 这一章留下什么

- **爱好者**：卡了去装优化、红石「修坏了」、升级后箱子变成未知——这些不是三件杂事。它们是同一张利息单：先卖出去的循环，要靠别人把债读成接口，世界才能继续被住。接口一旦被读出来，再谈正确，就要先谈会不会删掉一种已经会说的话。
- **开发者**：能抄走的是窗口模型（玩法撑破柜子 → 翻译器买单 → 下一层合同）、以及两处「兼容必须高于正确」（被当成语言的模拟怪癖、比引擎活得久的存档）。能一起抄走的还有：民间官方实现是范围漏写的那一半，纪律是还债但不改合同。抄不走的是二十年测试集、Wiki 当规格、Paper / Sodium / 加载器矩阵；以及「社区会来当平台组」这份没有合同的劳动力。先卖再修证明过循环完整、增量可见的独立游戏可以活。没证明你可以没有人替你扛债。没有人，你卖的是原型。有人，你才卖得出媒介。媒介的下一句是：可被模组的引擎，才配叫完整产品。
