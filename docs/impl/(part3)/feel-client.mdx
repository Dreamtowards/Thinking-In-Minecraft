> **本章命题**：手感很大一部分不是世界先算完再播给你。它是客户端先演一截，等权威盖章。挖的停顿、受伤的红、碎掉的粒子，是反馈。反馈可以关、可以骗，不能另写一份物理。

## 问题

你按住左键。石头上先出现裂痕。咔。碎块迸出来。手有一下停顿，才轮到下一格。服务器可能还在几十毫秒外。你已经「挖到了」。[^break]

要回答：手感有多少是模拟，有多少是反馈？可被证伪的说法是：手感就是物理，客户端只是摄像机；裂痕、粒子、受伤闪红都在服务端那一刻里算完。只要还存在 Java 挖碎一格之后那段约 6 刻的固定死等、只要还存在受伤后客户端先闪红再等对账、只要还存在把粒子关掉世界照样挖，这句话就不成立。

卷二（[《最小动词集与手感》](/design/verbs-feel)）把手感写成规则的时间形状；本章写成实现：这个时间形状有多少是客户端先演出来的。上一章（[《网络协议》](/impl/protocol)）把权威放在协议上：谎发生在盖章之前。盖章之后，洞要么留下，要么补回去。留下，谎就升级成真实；补回去，谎被揭穿，你嘴里骂的是橡皮筋。

至少要能指三件可感知的事：挖掘停顿、伤害闪烁、方块破碎。指得着，才不是氛围散文。

## 挖一下、挨一下，服务器还没说话

**挖。** 裂痕是画在那一格上的客户端进度条：按住左键，客户端按方块硬度、手上工具、附魔效果一格格涨进度，公式与玩家可观察的行为大致对得上，但这段动画不必等服务器逐刻确认。服务器在另一头同样跟踪这份进度，并核对你的目标、距离和权限——你松手或改挖别处，进度作废重算。两边对上的那一刻，包到了，说破了，格子变成空气，碎屑粒子才名正言顺地迸出。包到了，说没破——工具不对、别人先放了方块、冒险模式禁止破坏——裂痕会消失，格子还在，而挖掘途中那几声碎响你已经听见了。咔是谎。Java 在非瞬间破坏之间还卡着约 6 刻的固定死等：这一格碎了，下一格的进度要等一截才开始走。[^break] Bedrock 的连续输入没有把这截死等焊成同一个形状，跑图的人能感到两边节奏不同——不同的是客户端节拍器，不是「那边没有挖」。创造模式把这段时间删成瞬间，生存模式把时间还回来：权限改的是反馈，不改格子。

**挨。** 屏幕一红，镜头一歪，身体闪一下无敌的样子。红和歪可以在客户端先响，用来告诉你「打中了」；生命值以服务端为准。对不上，你会看见自己已经红了、心却没少，或者反过来。1.19.4 之后，Java 把镜头晃动收成可调的「伤害倾斜」滑条。[^tilt] 可调，证明它是反馈不是物理：物理不能让你把重力滑到 0 而世界仍在掉。挨打之后还有一个默认约半秒（10 刻）的无敌时间，同一只手在这截时间里打不出第二下有效伤害——这是模拟，这一截里你真的少挨打。受伤闪烁是反馈：让你看见这截保护还在。两件事叠在同一下挨打里，口语才会把它们收成一个「手感」；拆开，才问得出哪一半能关。

**GUI。** 鼠标滑过槽位发亮，是本地的；点下去换东西，要走窗口协议。亮错了，只是皮肤；换成空气，是权威拒绝。创造模式的检索栏看起来像浏览器，仍是先演后问。本章不教点法，只要一句：界面上「已经发生」的事，常常还没在服务器上发生。

准星描边的那一格，也是谎。描的是你的视线钉回离散地址——服务器还不知道你在看哪，直到你挖、放、用。描边服务于「看」这个动词，不服务于权威。关掉描边，格子还在，手会钝一截：钝的是反馈，不是世界。攻击冷却条同样：Java 1.9 之后满格才是一击，条画在客户端，冷却走在模拟里。[^combat] 条可以当成谎言的刻度；刻度对不上，你会空挥。空挥是手感，伤害仍以盖章为准。

三件事共用同一个形状：动词先在手上完成一截，完成的证据是声、光、粒子、镜头。证据服务于「我抓得住格子」，抓得住，家才改得动。证据若全部改成「等包再给」，格子会变成网页按钮——按下，转圈，再变。Minecraft 不转圈；不转圈，就要说谎。

## 位置音频

声音不是背景带。它告诉你事情在哪。苦力怕在背后嘶，水在左边流，矿车在头顶的隧道里走。位置音频把空间收成左右和远近。关了立体声，世界少一维信息。这一维不在调色板里。它在客户端的听者坐标上：你的头在哪，衰减怎么走。[^sound]

资源包能换音效，1.9 之后更是事件名加 JSON。换的是皮肤，事件仍从模拟里冒出来：活塞动、方块碎、生物受伤。有的反馈能先响：挖掘途中那一串碎响是客户端本地播放的，权威若拒绝，响已经出去了，收不回来。最终的破碎音和碎屑粒子倒是盖章之后才来——所以假挖骗得过耳朵的前半段，骗不过最后那一声。音频比粒子更像谎：粒子还可以不画，一声咔会留在记忆里。

音符盒、唱片机是把声音做成世界里的物。物能被红石驱动，能被位置听见。听见是空间信息，不是电影配乐。电影配乐跟镜头。位置音频跟格子。跟格子，失聪的玩家会少一条侦测。少一条，就要在无障碍那一节补字幕。字幕不是礼貌。字幕是把这一维信息搬到眼睛上。

Bedrock 的听感和 Java 的衰减、分类滑条不是同一份。合写的是：声音占空间。分写的是：哪一种立体声、哪一种滑条、手机扬声器怎么骗方向。删掉产品线，苦力怕在背后那句仍成立。成立的是合同：手感包含「事情在哪」，不只「事情发生了」。

<Note>
位置音频是信息通道。把它当装饰关光，你会少听见背后的爆炸，不是少听见配乐。
</Note>

## 粒子是反馈

粒子不是过场。过场会劫持镜头，告诉你「现在请看剧情」。Minecraft 的碎块、烟雾、水花、暴击星，是动词的回声：你做了这件事，格子或身体给出一小撮可见的账。方块破碎粒子从那一格的贴图里裁，所以高清包会让碎块变漂亮——仍是反馈，不是另一份物理。物理是格子变成空气。碎块是空气刚发生时的谎，谎的内容是「这里曾经是石头」。

粒子可以关。关了，挖还在，伤还在，熔炉还在烧。关得掉，就不是模拟；模拟关了，炉子会停。于是粒子预算是客户端税：雨、喷溅、传送门、烟花，能把帧买光，而不买走 TPS。渲染章里的优化模组有时连粒子也管——管的是看见的预算，权威不签名。

粒子也会骗人。你看见末影人的粒子，人已经走了。你看见传送门漩涡，另一端的区块还在雾里。骗，是把「快要发生或刚刚发生」做成可见。不要做成电影：电影有剪辑点。反馈没有剪辑点。它跟着那只手走，手停，粒子停。手还在挖，裂痕和碎块还在。这是同一套动词的皮肤，不是过场编辑器。

传送门的紫、溺水的气泡、着火的冒烟，把状态做成包围你的谎。状态本身在模拟里：你在传送门里、你在水里、你在烧。包围是客户端把状态画到镜头上。关掉「扭曲效果」，世界仍传送，镜头少一截晕。关得掉的是谎。关不掉的是你已经进了另一维度。无障碍那一节会把这只开关当成证词：设计已经知道谎会伤人，于是允许少谎一点。少谎一点，信息还在不在，要看有没有第二条通道。

<Impl title="破碎粒子跟贴图，不跟硬度公式">
硬度决定要挖多久。粒子决定碎的时候看起来像哪种方块。两件事能分开调。分开，正是反馈与模拟的边界。
</Impl>

## 客户端预测

预测是把上一章的协议缝变成手感。本地先走，先挖，先挥。服务端盖章。盖章合，谎就消失在连续里——你不会感到自己在撒谎。盖章不合，谎变成橡皮筋、幽灵方块、飞回的物品。

挖掘停顿是预测里的节拍器：客户端按刻把进度加满，再插入那 6 刻死等。伤害闪烁是预测里的旗帜：先告诉你挨了，再等心的数量。方块破碎是半步预测：你能先演的只有裂痕和挖掘碎响，真正的碎屑粒子跟着服务器的确认一起来——确认合，粒子、空气、掉落物在同一次盖章里落地。盖章之后，模拟接管：空气法律、伤害数值、掉落实体。掉落实体一旦出现，税就从反馈转到实体章的名单上。

GUI 的预测更日常。拖着半组东西走，光标上那一格已经是谎——服务器可能还认为它在槽里。窗口关闭，谎必须落地：进背包，或掉成实体。落地失败，财产裂开。本章和物品章在这里焊死：流畅来自先演，居住来自对账。

预测的极限是延迟。局域网里，谎短得像没有；跨洋服上，谎长得像另一种物理。另一种物理会教坏你的手：你学会提前挥，学会给打空做补偿。补偿是玩家替客户端圆谎。官方若把预测收得更紧，高延迟的人会感谢，近战竞技会变成另一份口令。Java 与 Bedrock 的战斗手感分叉，一半写在冷却条上，一半写在这一截先演里。不要站队，要承认：手感谎言是产品线护照的一部分。

自动跳跃是另一种谎：客户端帮你迈那半格，免得你每次按跳。迈的是碰撞合同已经允许的台阶（[《实体与碰撞》](/impl/entities)）。谎的是「我好像会自己上台阶」。关了自动跳，合同还在，手要自己记得。无障碍和手感在这里抢同一只开关：有人需要它当辅助，有人觉得它把走变得假。假，正是本章的词。假得有用，就留下；假得挡信息，就该能关。

<Memoir title="咔了但没碎">
音出去了。裂痕走完了。格还在。下一秒粒子没有迸。不是你听错。是先演的那一截没有被盖章。口令「假挖」能当笑话，因为真挖和假挖在手上是同一套动画。
</Memoir>

<Alternative title="若全部手感等服务端包">
挖会变成按下、等待、再裂。高延迟的诚实会上升，手会变钝。你得到更难作弊的近战。你失去的是：格子在手指下立刻有重量。重量是谎养出来的。
</Alternative>

## 无障碍

无障碍不是一袋开关的名字。它问两件不同的事。第一，反馈能不能关——因为有人会被晃、闪、晕。第二，信息能不能换通道——因为有人听不见背后的苦力怕。关反馈，是承认手感是谎，谎可以少一点。换通道，是承认谎里其实夹着模拟信息，信息不能只活在一种感官里。

伤害倾斜、扭曲效果、屏幕晃动，是第一类。Java 把伤害倾斜做成滑条，默认仍是满。[^tilt] 满，说明设计仍把「挨打要晃」当手感合同；能滑到 0，说明合同允许改写。字幕、旁白，是第二类。字幕把声音事件写成字，显示在屏幕上；[^sub] 旁白把菜单和聊天读出来。[^narrator] 字和读不是把游戏变成另一种物理，它们是把「事情发生了、在哪一类」搬到眼睛和语音。搬得越完整，位置音频就越不像唯一通道。搬不完整，失聪的玩家就少一条生存信息——那是债。债的意思是：空间音已经当设计用了，设计却没有把同一份信息写成默认可见。

自动跳跃刚才写过：有人当辅助，有人当假。假得有用，就该是选项，不该是无法关闭的性格。字幕默认关闭，则是另一种性格：听见的人先得到完整信息，看不见字的人要自己打开通道。默认写给谁，就是设计站在哪一边。站在听见的人一边，多年以后再补字幕，补的是债。债可以还。还清的标志是：空间里那一声，眼睛也能读到同类事件，而且不必先翻两级菜单。还不清，信息就还活在谎里。

粒子闪烁也会碰到光敏：屏障一类方块用闪烁粒子标记存在，工单里有人把它标成无障碍问题。[^flash] 标了不等于修好；没修好，就是这一层把反馈写得比信息更急——急着告诉你「这里有屏障」，急到用闪。急是设计本能，本能会伤人，伤人时债和设计叠在同一处。

Bedrock 的字幕、文本转语音、主机辅助，不是 Java 那一页选项的复制。合写的是：手感必须允许关，信息必须允许换通道。分写的是：哪一年做成滑条，哪一种闪还在。不要写成功能清单，清单 Wiki 有。本章只要一句判断：无障碍做对的时候，是在承认谎言可以调、信息不可以只活在谎里；做错的时候，是把闪光当通知，把旁白当事后补丁。

<Constraint name="手感是先演的谎" verdict="地基" chain="权威在服务端 → 客户端先演声光 → 对账失败则揭穿">
挖的停顿、受伤的红、破碎的粒子，主要是反馈；位置音频夹带空间信息，关掉会丢侦测。抄走预测，丢掉「可关的晃、可换的通道」，你会得到更诚实的摄像机，失去抓得住格子的那只手。诚实可以，诚实是另一款网页。这款游戏用谎养重量：谎要对账，对账在协议，重量在手上。
</Constraint>

第三部到此收住。看见是网格，接头是协议，手上的重量是谎。下一部把镜头转到谁能改引擎：模组、数据包、两套运行时。权威仍在这一刻上。能改刻的人，才是完整产品的另一半作者。

## 这一章留下什么

- **爱好者**：裂痕和咔可以发生在洞还没被服务器承认之前。粒子能关，挖还在；立体声关了，背后的苦力怕会变小。字幕不是多余，是把耳朵的那一维写给眼睛。
- **开发者**：能抄走的是先演后对账——挖掘进度、受伤反馈做在客户端，破碎粒子等服务端确认；位置音频当空间信息；粒子当可关的反馈。能一起抄走的还有：无障碍要分「可关的谎」和「可换通道的信息」。抄不走的是 Java 那 6 刻死等对 Bedrock 的连续挖、伤害倾斜滑条的年份、两边字幕和旁白不是同一页；以及二十年手已经记住的重量。你若等包再裂石头，格子会变成按钮；你若把闪光当唯一通知，信息会伤人。谎要可调，账仍在服务器。

[^break]: 挖掘时间按刻计算；Java 在非瞬间破坏之间约有 6 刻间隔。见 [Breaking](https://minecraft.wiki/w/Breaking)；手感合同见本书 [《最小动词集与手感》](/design/verbs-feel)。

[^combat]: Java 1.9 为近战加入冷却；冷却指示画在 HUD 上。见 [Java Edition 1.9](https://minecraft.wiki/w/Java_Edition_1.9)；对照见本书 [《最小动词集与手感》](/design/verbs-feel)。

[^tilt]: Java 23w06a / 1.19.4 将伤害倾斜加入无障碍选项。见 [Options](https://minecraft.wiki/w/Options)、[Java Edition 23w06a](https://minecraft.wiki/w/Java_Edition_23w06a)。

[^sound]: 声音事件可带位置并随距离衰减；资源包可覆盖音效。见 [Sound](https://minecraft.wiki/w/Sound)、[Resource pack](https://minecraft.wiki/w/Resource_pack)。

[^sub]: Java 1.9 加入字幕，把声音事件显示为文字。见 [Subtitles](https://minecraft.wiki/w/Subtitles)、[Java Edition 1.9](https://minecraft.wiki/w/Java_Edition_1.9)。

[^narrator]: Java 无障碍设置中的旁白可朗读菜单、聊天或全部文本；快捷键 Ctrl+B（macOS 为 ⌘B）。见 [Options](https://minecraft.wiki/w/Options)。

[^flash]: 屏障、光源方块等粒子被报告为对光敏不友好。见 Mojira [MC-221686](https://bugs.mojang.com/browse/MC-221686)。
